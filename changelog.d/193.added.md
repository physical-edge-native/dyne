`dyne-mjcf` (crates/dyne-export): writes the room shape computed by the devices (the `.vti` or `shape.csv` input of `dyne-foam case --shape`) as an MJCF file for MuJoCo, with static boxes merged from the grid, a floor plane in the frame of the USD export, and a JSON list of the free floor for robot spawn points; checked byte for byte and loaded in MuJoCo in CI (#193).
