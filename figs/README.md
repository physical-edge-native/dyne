# figs/ — 実測の図(発表・資料用の正本)

安定領域の掃引・補完測定・ナッジング等の**実測値の図**。2026-10-04の発表で使用し、
今後のスライド作成でも再利用する。各図は .dat(データ)+ .gp(gnuplotスクリプト)+
.png(出力)の3点セット。

- **データの出所**: recovered/(会話記録から復元した実測。recovered/README.md)と、
  一部は報告書の表からのスクリプト抽出(fig08=docs/2026-09-21-order5-report.md §4-7)。
  手転記は使っていない。
- **fig05・fig06 は判定(3色)のみの地図**: 安定セルの誤差値が復元不能のため、
  誤差の大きさで塗る熱図は作れない(再実行すれば作れる)。
- **PNGも追跡する理由**: 作図には gnuplot(pngcairo、日本語フォント Noto Sans JP)が
  必要だが、この開発機には常設されていない(発表時はポータブル版を一時使用)。
  元データ消失の事故歴もあるため、成果物の画像自体を残す。
- 再生成: `gnuplot figNN_*.gp`(gnuplot 5.4以降、figs/ 内で実行)。
- 理論値の図(transparent_rho.png・nudging_boundary.png)は reference/stability_figs/ にある。

| 図 | 内容 |
|---|---|
| fig01_mapA | 分割数×r の安定地図(幅16・反復5) |
| fig02_error | 最大誤差と r(分割数ごと) |
| fig03_r041 / r100 | 幅×反復回数(4分割、r=0.41 / 1.00) |
| fig04_sub | 16分割: 評価点の取り方(格子点のみ/中点も)の比較 |
| fig05_n16 | 補完測定の16分割: 判定の地図(6パネル) |
| fig06_small_n | 補完測定の1台・4・8分割: 全セル安定 |
| fig07_counts | 16分割の劣化・発散の件数(幅×評価点) |
| fig08_long | 劣化セルの300↔1000ステップ比較 |
| fig09_seeds | NN初期値の乱数6通り |
| fig10_width | 幅と発散境界の区間 |
| fig11_exp1_temps | 実験1(2026-10-08): 4台のDHT20の補正後温度の時間変化(配置後〜run4終了) |
| fig12_exp1_holdout | 実験1: 各runの保留ノード位置での実測・モデル予測・単純平均(4パネル) |

fig11・fig12 は例外として **gnuplot ではなく matplotlib**(Python)で作図した(開発機に
gnuplot が無いため)。.gp の代わりに生成スクリプト fig11_exp1.py を置く。データの出所は
measured/2026-10-08-exp1/(実機の実測CSV)。再生成: `python figs/fig11_exp1.py`(リポジトリ直下で)。
