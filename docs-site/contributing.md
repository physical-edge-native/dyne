# Contributing

Work starts from a GitHub Issue, goes to a branch named `<issue>-<short-description>`, and is merged through a
pull request when CI (Linux, macOS, Windows) is green. See
[CONTRIBUTING.md](https://github.com/physical-edge-native/dyne/blob/main/CONTRIBUTING.md).

## Questions, ideas and bugs

- **Questions** about using Dyne: [Q&A](https://github.com/physical-edge-native/dyne/discussions/categories/q-a) in GitHub Discussions.
- **Ideas** for new features: [Ideas](https://github.com/physical-edge-native/dyne/discussions/categories/ideas).
- **Something you built or tried** with Dyne: [Show and tell](https://github.com/physical-edge-native/dyne/discussions/categories/show-and-tell).
- **Bugs**: open an [Issue](https://github.com/physical-edge-native/dyne/issues).
