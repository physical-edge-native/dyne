## 0. 全体の設計思想

5冊を並べると、**合意制御・定常反復法・熱方程式の陽的差分・領域分割法(Schwarz法)が、
同じ数学構造(行列 I − εL の反復)でつながる**。この一本の線を第1〜2週で確立し、
第3週で推定(A3)を、第4週で最適化(A7・A1)を載せる。

### 次へ進む条件(自分の言葉で説明できること)
- [ ] 離散時間の合意 x(k+1) = (I − εL)x(k) が、グラフ連結かつ ε < 1/最大次数 で平均値へ収束し、
      その速さが「1の次に大きい固有値の絶対値」で決まること
- [ ] Jacobi法を x(k+1) = Mx(k) + c と書き、収束条件が**スペクトル半径**
      (固有値の絶対値の最大値)< 1 であること
- [ ] 上の2つが同じ構造であることを一文で言えること

### 理論課題 T1(A7・A6との橋)
状態: `未着手`

### 次へ進む条件
- [ ] 熱方程式を**流束**(単位時間に境界を通る熱量)の保存則から導出し、界面で
      「値の連続」と「流束=勾配の連続」の両方が必要な理由を説明できること
      (現行の界面フォーマット=値+勾配の理論的根拠)
- [ ] 陽的差分 u(n+1) = u(n) + r(2階差分) がパスグラフ上の合意 (I − rL)u そのものであり、
      安定条件 r ≤ 1/2 が合意の条件 ε < 1/最大次数(=1/2)と一致すると確認できること
- [ ] **最良近似誤差**(関数族の中で最も良く近似したときの誤差)の定義と、
      関数族を大きくすると単調に減ることを説明できること

### 理論課題 T2(A4・E3)
状態: `未着手`
