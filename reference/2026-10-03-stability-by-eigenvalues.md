本文で使う言葉の約束:

- **担当計算機**: 本プロジェクトでは、区間 [0, 1] をいくつかの部分区間に分け、各部分区間を別々の小型計算機が受け持って計算する。この計算機を担当計算機と呼ぶ。差分法で計算するものと、ニューラルネットワークで計算するもの(学習型の担当計算機)がある。
- **境目**: 隣り合う部分区間の接する点。
- **陽的・陰的**: ある時刻の値を、前の時刻の値だけから直接計算するのが陽的、新しい時刻の値どうしの連立方程式を解いて求めるのが陰的。

## この文書の対象範囲

**区間 [0, 1]** は、計算の対象とする領域全体である。すべての担当計算機が受け持つ部分区間を合わせたもの、あるいは1台で全体を計算する場合の全体にあたる。

**境界条件**には2種類あるので区別する。

- 前半の第1節〜第11節の「両端で温度0」は、計算の対象とする問題そのものの端の条件(本プロジェクトの基準問題の物理的な端)である。
- 担当計算機が置かれていない区間との境目の条件は、第12節と後半5〜7で扱う。観測している区間が [a, b] で、その外側に担当計算機がない場合は、[a, b] を区間とみなせば前半と同じ解析ができる(格子点の数が変わるだけ)。

**分割による影響**:

- 差分法の担当計算機を並べた場合、各担当計算機は隣の端点の値を受け取って同じ式で計算するので、演算の手順は全体を1台で計算する場合と同一になる。更新行列も同一なので、前半の結果がそのまま当てはまり、**分割による新たな不安定は生じない**。
- 学習型の担当計算機を並べた場合は、境目の扱いによって新たな不安定が生じる。これを扱うのは後半4だけで、学習型の担当計算機だけを並べた場合に限られる。
- 後半7(透過境界条件)と後半8(ナッジング)は、差分法の担当計算機を前提にしている。
- 次の場合はこの文書では扱っていない: 差分法と学習型の担当計算機を混在させた場合、学習型の担当計算機にナッジングや透過境界条件を組み合わせた場合の理論、担当計算機の間で計算の歩調をそろえない(非同期の)場合。

# 前半: 導出の筋道

## 1. 問題設定

区間 [0, 1] の熱方程式

  ∂u/∂t = α ∂²u/∂x²

を考える。u(x, t) は位置 x、時刻 t での温度、α は熱拡散率である。両端の温度は 0 に固定する(ディリクレ境界条件)。初期条件 u(x, 0) は与えられているとする。

## 2. 連続の解: 変数分離法

u(x, t) = X(x)T(t) と置いて代入し、両辺を αXT で割ると

  T'(t) / (αT(t)) = X''(x) / X(x)

左辺は t だけ、右辺は x だけの関数なので、両辺は定数でなければならない。これを −λ と置くと、2つの常微分方程式に分かれる。

- X'' = −λX、X(0) = X(1) = 0 から、X = sin(kπx)、λ = (kπ)²(k = 1, 2, 3, …)
- T' = −αλT から、T = e^{−α(kπ)²t}

よって一般の解は

  u(x, t) = Σ_k b_k sin(kπx) e^{−α(kπ)²t}

と書ける(係数 b_k は初期条件のフーリエ正弦級数の係数)。

**読み取れること**: 各成分は時間とともに指数関数的に減衰し、k が大きい(細かく波打つ)成分ほど速く減衰する。熱方程式が解を滑らかにする性質(平滑化)の正体はこれである。

## 3. 空間の離散化: 線の方法

区間を n 等分し、格子間隔を h = 1/n、格子点を x_j = jh とする。内部の格子点 j = 1, …, n−1 での温度を u_j(t) とし、2階微分を中心差分で近似すると

  du_j/dt = α (u_{j−1} − 2u_j + u_{j+1}) / h²

となる(両端は u_0 = u_n = 0)。ベクトル u = (u_1, …, u_{n−1}) を使うと、連立常微分方程式

  du/dt = Au

に帰着する。A は対角成分が −2α/h²、その両隣が α/h² の三重対角行列である。空間だけを離散化して連立常微分方程式にするこの方法を、線の方法という。

本プロジェクトの基準問題は n = 64(格子点65個)である。

## 4. 行列 A の固有値と固有ベクトル

k = 1, …, n−1 について、成分が sin(jkπh) であるベクトル v_k を考える。θ = kπh と置き、三角関数の加法定理を使うと

  (Av_k)_j = (α/h²)[sin((j−1)θ) − 2sin(jθ) + sin((j+1)θ)]
       = (α/h²)(2cosθ − 2) sin(jθ)
       = −(4α/h²) sin²(θ/2) · sin(jθ)

となる。両端の条件 sin(0) = sin(nθ) = 0 も満たされている。よって v_k は A の固有ベクトルで、固有値は

  λ_k = −(4α/h²) sin²(kπh/2)

である。

**読み取れること**:

- v_k は連続の解の sin(kπx) を格子点で見たもの。つまり固有ベクトルによる分解は、変数分離法の離散版である。
- すべての固有値は負の実数で、互いに異なる。A は実対称で負定値である。
- k が小さいとき sin(kπh/2) ≈ kπh/2 なので、λ_k ≈ −α(kπ)²。連続の解の減衰率と一致する。
- 最も細かい成分(k = n−1)の固有値は約 −4α/h² である。

**最も細かい成分の形(隣り合う格子点で符号が交互に変わる成分)**: k = n−1 のとき、v_k の j 番目の成分は

  sin(j(n−1)π/n) = sin(jπ − jπ/n) = (−1)^{j+1} sin(jπ/n)

となる。(−1)^{j+1} の因子によって、隣り合う格子点で符号が交互に入れ替わり、その振幅はゆるやかな山形 sin(jπ/n) で変化する。n = 8 の例では、j = 1, …, 7 の成分は

  0.38, −0.71, 0.92, −1.00, 0.92, −0.71, 0.38

で、格子点ごとに正負が入れ替わる鋸歯状の形をしている。格子で表せる最も細かい波で、連続の世界では波長が格子間隔の2倍の波にあたる。

## 5. 連立常微分方程式の解

A の固有ベクトルは互いに直交するので、初期値を u(0) = Σ c_k v_k と分解すると

  u(t) = Σ_k c_k e^{λ_k t} v_k

となる(行列の指数関数 e^{tA} を固有ベクトルの方向ごとに計算したもの)。すべての λ_k が負なので、各成分は減衰する。

## 6. 時間の離散化と増幅因子

### 6.1 なぜ1ステップの更新が φ(ΔtA) の形になるのか

時間刻みを Δt とし、時刻 t_m = mΔt での近似値を u^m とする。ここで扱う解法は、いずれも次の2つの性質を持つ。

- 方程式 du/dt = Au の右辺が u について線形なので、解法の中で使う量はすべて「u^m や途中の値に A を掛けたものの線形結合」になる。
- 陽的な解法では、A を何回か掛けて足し合わせるだけなので、u^{m+1} は ΔtA の**多項式**を u^m に掛けた形になる。陰的な解法では、新しい値についての連立方程式 (I − cΔtA)u^{m+1} = (…)u^m を解くので、逆行列 (I − cΔtA)^{−1} が現れ、ΔtA の**有理関数**を u^m に掛けた形になる。

いずれも u^{m+1} = φ(ΔtA)u^m と書ける。φ は解法ごとに決まる多項式または有理関数である。

さらに、A の固有ベクトル v_k について A^p v_k = λ_k^p v_k、(I − cΔtA)^{−1}v_k = (1 − cΔtλ_k)^{−1}v_k が成り立つので、

  φ(ΔtA) v_k = φ(Δtλ_k) v_k

となる。つまり行列の関数を固有ベクトルに当てると、固有値を代入した数が掛かるだけである。よって固有ベクトルの方向ごとに見ると、成分 k は1ステップごとに

  φ(z_k) 倍、 z_k = Δt·λ_k

される。この φ(z_k) を増幅因子という。

### 6.2 代表的な解法の φ の導き方

**前進オイラー法**: 時刻 t_m での傾き Au^m で1ステップ進む。

  u^{m+1} = u^m + Δt A u^m = (I + ΔtA)u^m  →  φ(z) = 1 + z

**後退オイラー法**: 新しい時刻での傾き Au^{m+1} で1ステップ進む。

  u^{m+1} = u^m + Δt A u^{m+1}  →  (I − ΔtA)u^{m+1} = u^m  →  φ(z) = 1/(1 − z)

**クランク・ニコルソン法**: 両端の時刻での傾きの平均を使う(台形公式)。

  u^{m+1} = u^m + (Δt/2)(Au^m + Au^{m+1})  →  (I − ΔtA/2)u^{m+1} = (I + ΔtA/2)u^m  →  φ(z) = (1 + z/2)/(1 − z/2)

**ホイン法**: 前進オイラー法で仮の値 ũ = u^m + ΔtAu^m を作り、両端の傾きの平均で進む。

  u^{m+1} = u^m + (Δt/2)(Au^m + Aũ) = (I + ΔtA + (ΔtA)²/2)u^m  →  φ(z) = 1 + z + z²/2

**古典的な4次のルンゲ・クッタ法**: 同様に途中の段を展開すると

  φ(z) = 1 + z + z²/2 + z³/6 + z⁴/24

ホイン法とルンゲ・クッタ法の φ は e^z のテイラー展開を途中で打ち切ったもので、打ち切る次数が精度の次数に対応する。

### 6.3 安定の条件

**すべての k で |φ(z_k)| ≤ 1 なら、どの成分も増大しない(安定)**。無次元量

  r = αΔt / h²

を導入すると、z_k = −4r sin²(kπh/2) なので、z_k は区間 [−4r, 0) に並ぶ。A が対称で固有値が実数なので、実軸上で |φ(z)| ≤ 1 となる範囲(絶対安定区間)に [−4r, 0) が収まるかを見ればよい。

| 解法 | φ(z) | 絶対安定区間 | 熱方程式での条件 |
|---|---|---|---|
| 前進オイラー法(陽的) | 1 + z | [−2, 0] | **r ≤ 1/2** |
| ホイン法(陽的) | 1 + z + z²/2 | [−2, 0] | r ≤ 1/2 |
| 古典的な4次のルンゲ・クッタ法(陽的) | 1 + z + … + z⁴/24 | 約 [−2.79, 0] | r ≤ 約0.70 |
| 後退オイラー法(陰的) | 1/(1 − z) | 負の実軸全体 | **r によらず安定** |
| クランク・ニコルソン法(陰的) | (1 + z/2)/(1 − z/2) | 負の実軸全体 | r によらず安定 |

後退オイラー法とクランク・ニコルソン法の違いは z → −∞ での振る舞いで、後退オイラー法は φ → 0(細かい成分を強く消す)、クランク・ニコルソン法は φ → −1(細かい成分をほとんど消さず、符号を反転させて残す)。

### 6.4 A安定だと何が嬉しいか

左半平面のすべての z で |φ(z)| ≤ 1 となる解法を A安定という。後退オイラー法とクランク・ニコルソン法は A安定である。A安定の利点は次のとおり。

- **時間刻みを安定性ではなく精度だけで選べる**。陽的な解法では、物理的にすぐ消えて重要でない最も細かい成分のせいで時間刻みが制限される(第8節の硬い問題)。A安定な解法ではこの制限がないので、知りたい緩やかな成分を十分な精度で追える範囲で、時間刻みを大きくできる。
- **設定を誤っても発散しない**。時間刻みや格子間隔の組み合わせが想定外でも、解が爆発しない。

ただし代償もある。

- 毎ステップ連立方程式を解く必要があり、計算量が増える。さらに区間を複数の担当計算機に分けている場合は、新しい時刻の値が区間全体で連立するので、担当計算機どうしが協調して解く必要がある(後半2)。
- A安定は「増大しない」ことを保証するだけで、精度を保証しない。大きな時間刻みでは、細かい成分の減衰の速さは正しく再現されない(クランク・ニコルソン法のように符号を反転させて残すこともある)。

### 6.5 連続の減衰との比較

基準問題 h = 1/64、r = 0.4 での増幅因子:

| 成分 k | 前進オイラー法の φ | 連続の1ステップの減衰 e^{λ_k Δt} | 後退オイラー法の φ |
|---|---|---|---|
| 1 | 0.999036 | 0.999037 | 0.999037 |
| 8 | 0.939 | 0.940 | 0.943 |
| 32 | 0.200 | 0.373 | 0.556 |
| 63 | −0.599 | 0.022 | 0.385 |

緩やかな成分では、どの解法も連続の解をよく近似する。ずれるのは細かい成分である。

## 7. 不安定はどう見えるか

前進オイラー法で r を大きくすると、最も細かい成分の増幅因子 1 − 4r sin²(…) ≈ 1 − 4r が、r > 1/2 で −1 を下回る。するとこの成分は、**隣り合う格子点で符号が交互に変わる形(鋸歯状)のまま、1ステップごとに符号を反転しながら増大する**。差分法の計算が発散するとき、解がギザギザに振動するのはこのためである。

安定条件とは、「本来すぐに消えるはずの細かい成分を、数値解法が正しく消せるか」という条件だと言える。

## 8. 硬い問題

固有値は、最も緩やかな成分(約 −απ²)から最も細かい成分(約 −4α/h²)まで広がっている。比は h = 1/64 で約1700倍である。前進オイラー法の時間刻みは、物理的にはすぐに消えて重要でない最も細かい成分に合わせて制限される。固有値の大きさが大きく異なる成分が混在し、陽的な解法では時間刻みが不必要に小さく制限される問題を、硬い問題という。格子を細かくすると時間刻みの上限が h² に比例して小さくなるのは、このためである。

## 9. 一般の更新行列: スペクトル半径

第6節は、A が実対称であることを使っていた(固有値が実数で、固有ベクトルが直交する)。対称でない場合も含めて一般に言うと、1ステップの更新を

  u^{m+1} = G u^m

と書いたとき、G の固有値の絶対値の最大(**スペクトル半径**)が1以下であることが、ステップを重ねても増大しないための条件になる。これは、離散時間の力学系の不動点が安定である条件(線形化した写像の固有値の絶対値が1未満)と同じものである。

注意: 絶対値がちょうど1の固有値が重複している場合や、G が対称から大きく外れている場合は、固有値だけでは途中の一時的な増大を判定できないことがある。

## 10. ゲルシュゴリンの定理による見積もり

ゲルシュゴリンの定理: 行列の固有値は、各行について「対角成分を中心、その行の非対角成分の絶対値の和を半径」とする円のどれかに含まれる。

前進オイラー法の更新行列 G = I + ΔtA は、各行の対角成分が 1 − 2r、両隣が r である。どの行も中心 1 − 2r、半径 2r(両端に接する行は半径 r)の円になるので、固有値はすべて区間 [1 − 4r, 1] に含まれる。絶対値が1以下になる条件は 1 − 4r ≥ −1、すなわち **r ≤ 1/2**。

この方法の利点は、**固有値を計算せずに、対称でない行列にも、境界の行を変えた行列にも使える**ことである。得られるのは十分条件(この条件を満たせば安定)である。

## 11. べき乗法: 発散する計算から読み取る

べき乗法: 任意のベクトルに行列を繰り返し掛けると、絶対値最大の固有値に対応する成分だけが生き残り、ベクトルの形はその固有ベクトルに近づき、1回あたりの拡大率はその固有値の絶対値に近づく。

更新行列を繰り返し掛けるシミュレーションは、それ自体がべき乗法になっている。したがって:

- **発散直前の誤差の形**は、絶対値最大の固有値の固有ベクトルを表す。
- **1ステップあたりの拡大率**は、スペクトル半径の推定値になる。

行列の形で書けない計算(たとえばニューラルネットワークの最適化を含む1ステップ)でも、この読み方で増幅率を実測できる。具体的な計算は後半9で説明する。

## 12. 境界条件を変えたとき

**ノイマン境界条件(断熱)**: 端で温度の勾配を0にする(熱の出入りがない)。端の外側に、内側の点の値を鏡に映して置く(u_{−1} = u_1)と、端の行は (1 − 2r, 2r) になる。更新行列は対称ではなくなるが、対角行列による相似変換で対称にでき、固有値は実数である。固有値に**ちょうど0**(更新行列では1)が現れ、その固有ベクトルは一様な温度分布である。一様な成分は減衰も増大もしないので、温度は0には近づかず、**初期の平均値で平らになる**(総熱量が保存される)。

**線形外挿**: 端の外側の値を、端と内側1点を結ぶ直線で延長して置く(u_{−1} = 2u_0 − u_1)。すると端点の差分 u_{−1} − 2u_0 + u_1 が恒等的に0になり、端点の行は「前の時刻の値をそのまま残す」行 (1, 0, 0, …) になる。この行は単位行列の行と同じで、端点は時間が経っても値が変わらない(凍結される)。熱方程式と組み合わせると、事実上「最初の値に固定するディリクレ境界条件」になってしまう。

## 13. 全体の流れ

  熱方程式
  → 変数分離法: 解は sin(kπx) の重ね合わせ、各成分は e^{−α(kπ)²t} で減衰
  → 線の方法: du/dt = Au(A は三重対角行列)
  → A の固有分解: 固有ベクトルは格子上の sin、固有値は −(4α/h²) sin²(kπh/2)
  → 時間の離散化: 1ステップは φ(ΔtA) を掛ける操作で、各成分は増幅因子 φ(Δtλ_k) 倍
  → 安定条件: すべての成分で |φ| ≤ 1(前進オイラー法では r ≤ 1/2、後退オイラー法は無条件)
  → 一般化: 更新行列のスペクトル半径 ≤ 1
  → 道具: ゲルシュゴリンの定理(計算せずに見積もる)、べき乗法(発散から読み取る)

# 後半: 実装とシミュレーション結果との対応

各項目について、「実装のどの部分の根拠か」「どのシミュレーション結果を支えるか」「支え方の程度」を書く。

## 後半1. 差分法の担当計算機の時間刻みの上限

- **根拠となる箇所**: 第6節(前進オイラー法で r ≤ 1/2)、第10節。
- **実装**: 差分法で計算する担当計算機は前進オイラー法を使う。シミュレータは、差分法の設定で r > 1/2 が指定されると実行を拒否する。
- **支える結果**: 初期の実験で、この条件を破ると発散することを確認している。
- **支え方**: 完全。

## 後半2. 陽解法と陰解法の使い分け(設計上の選択)

- **根拠となる箇所**: 第6.4節(A安定の利点と代償)、第8節(硬い問題)。
- **差分法の担当計算機が陽的な前進オイラー法を使う理由**: 前進オイラー法では、各格子点の新しい値が、自分と両隣の**前の時刻の**値だけから決まる。区間を分割していても、各担当計算機は隣の担当計算機から境目の値を1ステップに1回受け取るだけで、自分の部分区間を計算できる。しかもこのとき各格子点で行う演算は、全体を1台で計算する場合とまったく同じ式・同じ順序になるので、分割しても結果がビット単位で一致する。陰的な解法(後退オイラー法など)では、新しい時刻の値が区間全体で連立方程式として結びつくので、分割した担当計算機どうしが、1ステップの中で何度も値をやり取りしながら連立方程式を協調して解く必要がある。通信が増え、演算の順序も全体計算と変わる。そこで差分法の担当計算機は、時間刻みの上限 r ≤ 1/2 を受け入れて陽的な解法を選んでいる。
- **学習型の担当計算機が後退オイラー法の形を使う理由**: 学習型の担当計算機は、自分の部分区間の中では後退オイラー法の形の式を最適化で解いており、部分区間の中については A安定の利点(時間刻みの制限がない)を得ている。担当計算機の間の結びつきは、境目の値の目標を隣の**前の時刻の**値から作る陽的な形にしているので、区間全体での連立は生じない。つまり「部分区間の中は陰的、担当計算機の間は陽的」という構造で、この陽的な部分が、分割したときに安定性の制約を復活させる(後半4)。
- **支え方**: 設計判断の説明として完全。

## 後半3. ニューラルネットワーク1台で区間全体を計算する場合の無条件安定

- **根拠となる箇所**: 第6節(後退オイラー法は r によらず安定)。
- **実装**: 学習型の担当計算機は、各時刻の温度分布をニューラルネットワークで表し、「(新しい分布 − 前の時刻の分布)/Δt − α × 新しい分布の2階微分」を残差として、その二乗和が小さくなるように学習する(物理法則の残差を損失関数に使うニューラルネットワーク、物理情報ニューラルネットワークの一種)。2階微分を新しい時刻の分布で評価しているので、これは後退オイラー法と同じ形である。
- **支える結果**: 安定領域の掃引実験(2026-09-20実施)で、1台で区間全体を計算した場合は、r = 2.0 まですべての設定で安定だった。
- **支え方**: 最適化が十分に収束しているという理想化のもとで完全。さらに第6.3節の φ → 0 の性質から、後退オイラー法の形は、最適化で残る細かい誤差を毎ステップ強く消す点でも有利である(クランク・ニコルソン法の形ならこの効果はない)。

## 後半4. 部分区間に分けたときの不安定(詳細は別文書)

詳細は 2026-10-03-learned-stability-region.md を参照。要点:

- 学習型の担当計算機を複数並べると、境目の格子点だけが陽的に更新される。最適化が完全という理想化のもとでは1ステップが線形写像になり、その更新行列のスペクトル半径から安定限界 r = (7 − √17)/4 ≈ 0.719 が得られる(2〜8分割。16分割で 0.707、32分割で 0.500)。
- 不安定な成分は、境目に局在し、両側で逆符号で、1ステップごとに符号を反転しながら増大する。
- 掃引実験の発散の境界(4分割で 1.0〜1.5、8分割で 0.8〜1.0、16分割で 0.6〜0.8)は、理論値より上にあり、中間層の幅を広げると下がってくる。小さいニューラルネットワークが鋭い形を表現しきれないことがフィルタとして働く、という解釈で説明している。
- 16分割で r によらず現れる緩慢な劣化は、この理論の範囲外である。

## 後半5. 境界条件を切り替えても時間刻みの上限が変わらないこと、断熱境界で温度が平均値に落ち着くこと

- **根拠となる箇所**: 第4節、第10節、第12節。
- **実装**: 担当計算機が置かれていない区間との境目の扱いを、温度0の固定(ディリクレ境界条件)、断熱(ノイマン境界条件)、透過境界条件(後半7)から設定で選べるようにした。
- **支える結果**: 同じ初期分布を両端固定と両端断熱で計算した比較シミュレーションで、固定端では総熱量が減り続けて温度が0に向かい、断熱端では総熱量が保たれて温度が平均値の高さで平らになった。

**固有値との対応**:

- 両端固定では、A の固有値がすべて負である(第4節)。第5節の式 u(t) = Σ c_k e^{λ_k t} v_k で、どの成分も e^{λ_k t} → 0 となるので、温度分布全体が0に向かう。熱は端から外へ逃げ続ける。
- 両端断熱では、固有値の1つがちょうど0で、その固有ベクトルは一様な分布である(第12節)。この成分は e^{0·t} = 1 で減衰しないので、他の成分が消えたあとに一様な分布が残る。その高さは初期分布の平均値で、総熱量が保存されることに対応する。

**時間刻みの上限が変わらないことのゲルシュゴリンの定理による確認**: 内部の行はどの境界条件でも中心 1 − 2r、半径 2r である。境界に接する行は次のとおりで、どれも区間 [1 − 4r, 1] の中に収まる。

| 境界条件 | 端に接する行 | 円の中心 | 半径 |
|---|---|---|---|
| 温度0の固定 | (1 − 2r, r) | 1 − 2r | r |
| 断熱(鏡映の仮想点) | (1 − 2r, 2r) | 1 − 2r | 2r |

したがって、どちらの境界条件でも r ≤ 1/2 なら固有値の絶対値は1以下である。

**透過境界条件でも言えるか**: ゲルシュゴリンの定理による上の議論は、透過境界条件には**そのままでは使えない**。透過境界条件では、温度に加えて過去の履歴を記憶する補助変数が状態に加わり、境目の行が補助変数の列にも成分を持つからである。そこで補助変数を含めた更新行列の固有値を直接計算したところ、採用している半陰的方式の安定限界は r = 0.500 で、差分法の上限 r ≤ 1/2 に新しい制約を加えないことが確かめられた。一方、他の離散化方式では上限が狭まる(後半7)。つまり「境界条件によらず r ≤ 1/2」は、ディリクレ境界条件、ノイマン境界条件、半陰的方式の透過境界条件について成り立つ。

- **支え方**: 完全(透過境界条件については固有値の数値計算による)。

## 後半6. 線形外挿を境界条件に採らない理由

- **根拠となる箇所**: 第12節。
- **実装**: 担当計算機が置かれていない区間との境目に、線形外挿は採用しなかった。
- **支え方**: 完全。線形外挿は熱方程式の差分と組み合わせると端点が凍結し、実質的に「最初の値に固定する」条件になる。場全体が減衰しても端点だけが動かず、ずれが時間とともに増える。

## 後半7. 透過境界条件の時間方向の離散化の方式(詳細は別文書)

詳細は 2026-10-03-transparent-boundary-stability.md を参照。要点:

- 透過境界条件は、担当計算機が置かれていない区間に同じ材質が無限に続くと仮定して、境目から逃げる熱を、自分の境目の温度の過去の履歴から計算する境界条件である。
- 履歴の寄与のうち直前1ステップの分が特に大きく、その扱い方で安定性が変わる。温度と補助変数をまとめた状態の更新行列のスペクトル半径から、安定限界は**半陰的方式(採用)で 0.500、1ステップ遅延方式で 0.319、直近項を落とす方式で 0.438** と確定した。
- 後者2つの不安定は境目に局在し、1ステップごとに符号を反転する。半陰的方式で r > 0.5 に現れる不安定は内部の鋸歯状の成分で、差分法そのものの限界である。
- シミュレーション結果(半陰的方式は r = 0.49、8000ステップで安定など)と整合する。

## 後半8. ナッジングの安定性(詳細は別文書)

詳細は 2026-10-03-nudging-stability.md を参照。要点:

- 観測点の値を観測値へ割合 γ で引き寄せるナッジングを加えると、誤差の更新行列は (I − γP)G になる(P は観測点の位置だけ1を持つ対角行列)。
- 行和ノルムの評価により、r ≤ 1/2 かつ 0 ≤ γ ≤ 2 なら、観測点の配置・数・周期によらず誤差の最大値は増えない(定理)。
- γ > 2 の安定境界は配置に依存し、4分割で各部分区間の中央を観測する配置では、r ≈ 1/3 で最も高く(約7.5)、r → 1/2 で 3.41 まで下がる。
- 安定地図の60セルすべてで、固有値計算の予測と実測が一致した。予測が局所近似と食い違う2セルの判別実験でも、固有値計算の予測どおりだった。発散したセルの拡大率は、予測のスペクトル半径と0.2%以内で一致した(初期の誤差の大きさの仮定に依存するので、正確な照合には時系列が必要。後半9)。

## 後半9. 発散した計算からの増幅率と不安定の形の読み取り(具体的な計算)

### 9.1 理論の側: 更新行列の作り方と固有値の計算

1ステップの写像 F が線形なら、行列 G で表せる。G の i 列目は、i 番目の成分だけが1で他が0のベクトル e_i に F を1回当てた結果 F(e_i) である。すべての i について並べれば G が得られる。写像を式で書き下さなくても、計算の手順(プログラム)さえあれば行列が作れる。

```python
import numpy

def update_matrix(one_step, size):
    # one_step: 状態ベクトルを1ステップ進める関数(線形であること)
    G = numpy.zeros((size, size))
    for i in range(size):
        e = numpy.zeros(size)
        e[i] = 1.0
        G[:, i] = one_step(e)
    return G

eigenvalues = numpy.linalg.eigvals(G)
spectral_radius = max(abs(eigenvalues))
```

安定限界は、スペクトル半径が1を超える最小のパラメータ(r や γ)を二分法で探して求める。不安定な成分の形は、絶対値最大の固有値に対応する固有ベクトルを numpy.linalg.eig で求め、どの格子点に大きな成分があるか、隣り合う点で符号がどうなっているかを調べる。後半4、7、8の理論値はすべてこの方法で計算した。

### 9.2 実験の側: 拡大率の読み取り

**終わりの値だけから読む方法(概算)**: m ステップで誤差の最大値が E₀ から E_m になったなら、1ステップあたりの拡大率は

  ρ ≈ (E_m / E₀)^{1/m}

である。後半8の判別実験(γ = 3.5、r = 0.50)では、m = 2000、E_m = 4.4 × 10¹⁷ だった。対数をとって計算すると、

- E₀ = 1 と仮定: ln(4.4 × 10¹⁷) = 40.63、40.63/2000 = 0.02031、e^{0.02031} = **1.0205**
- E₀ = 0.05(観測ノイズの大きさ)と仮定: ln(8.8 × 10¹⁸) = 43.62、43.62/2000 = 0.02181、e^{0.02181} = **1.0221**

予測のスペクトル半径は 1.0206 である。E₀ の仮定によって推定値が 0.15% ほど変わるので、この方法での一致は0.2%程度までしか言えない。

**時系列の傾きから読む方法(推奨)**: 発散の途中の2つの時刻 m₁ < m₂ での誤差の最大値 E(m₁)、E(m₂) を使い、

  ρ ≈ exp( [ln E(m₂) − ln E(m₁)] / (m₂ − m₁) )

とする。縦軸を対数にした誤差のグラフで、直線になっている部分の傾きを読むのと同じである。初期の誤差の大きさによらず、絶対値最大の固有値の成分が支配的になった後の拡大率だけを取り出せる。そのためには、シミュレータで各ステップの誤差の最大値を記録しておく必要がある。

### 9.3 実験の側: 不安定の形の確認(後半4の予想の検証方法)

後半4の理論は、学習型の担当計算機の発散直前の誤差が「境目に局在し、境目の両側で逆符号で、1ステップごとに符号を反転する」と予想している。これを確かめる手順:

1. 発散する設定(たとえば4分割、幅32、r = 0.90)で計算し、発散する直前の連続した数ステップの温度分布を保存する。
2. 各ステップの誤差 e^m = (計算値) − (解析解) を格子点ごとに求める。
3. **符号の反転と拡大率**: 格子点ごとの比 e_j^{m+1} / e_j^m を計算する。誤差の大きい格子点で、この比がほぼ同じ負の値(−ρ)になっていれば、1ステップごとに符号を反転しながら一定の率で増大している。
4. **局在**: 境目の格子点の組での誤差の二乗和を、全格子点での誤差の二乗和で割る。理論では約9割になる。
5. **反対称**: 境目の両側の格子点の誤差を比べ、同じ大きさで逆符号になっているかを見る。

### 9.4 支え方

方法論として完全。行列の形で書けない学習型の担当計算機の1ステップについても、9.2 と 9.3 の読み方で増幅率と不安定の形を実測できる。

## 後半10. 新しい担当計算機が加わったときの乱れの減衰

- **根拠となる箇所**: 第2節(細かい成分ほど速く減衰する)、第6.5節の表。
- **実装**: 計算の途中で担当計算機が新たに加わり、その部分区間の計算が始まる。
- **支える結果**: 加わった直後、境目での両側の勾配の食い違いが平常時の66倍に跳ね上がり、9〜14ステップで平常時の2倍以下に戻った。乱れは加わった境目の近くに留まった。
- **支え方**: 部分的。加わった直後の段差は細かい成分を多く含み、細かい成分ほど速く減衰するので、乱れが短時間で収まることは定性的に説明できる。しかし、**乱れが空間的に局所に留まる**ことは、固有値(区間全体に広がる成分)の議論だけでは説明できず、空間的な伝わり方の解析が別に必要である。

## 後半11. この文書の範囲外

次の事柄は、固有値による安定性の議論では説明できない。

- 分割しても結果がビット単位で一致すること(演算の順序と浮動小数点演算の性質の問題。後半2で理由の概略だけ述べた)
- ニューラルネットワークの学習の仕組み(非線形最小二乗法、レーベンバーグ・マーカート法、条件数)
- 16分割で現れる、発散しないがゆっくり誤差が増え続ける劣化(最小二乗問題の解の不定性の問題と考えられ、機構は未確定)
- 透過境界条件が物理的に妥当である時間の範囲
- ナッジングの最適な強さ、観測値と予測値の差(イノベーション)の統計
- 担当計算機の数を大きく増やしたときの、区間全体の情報の伝わり方
- 差分法と学習型の担当計算機の混在、非同期の計算
