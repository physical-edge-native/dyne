# ニューラルネットワークで計算する担当計算機を複数並べたときの安定性——理論と掃引実験

作成: 2026-10-03。親文書「熱方程式の数値計算の安定性を固有値で調べる」(2026-10-03-stability-by-eigenvalues.md)の後半4を切り出し、理論展開と掃引実験を詳しく書いたもの。図とデータは stability_figs/ にある。

## 0. 言葉の約束

- **担当計算機**: 区間 [0, 1] を部分区間に分けたとき、各部分区間を受け持って計算する小型計算機。
- **学習型の担当計算機**: 部分区間の温度分布をニューラルネットワーク(入力1つ、中間層1層、双曲線正接関数、出力1つ)で表し、各時刻で最適化して求める担当計算機。中間層の幅を w とするとパラメータは 3w + 1 個(幅16で49個)。
- **境目**: 隣り合う部分区間の接する点。境目の両側の格子点を「境目の格子点の組」と呼ぶ。
- **r**: r = αΔt/h²(α は熱拡散率、Δt は時間刻み、h は格子間隔)。
- **最大誤差**: 解析解との差の絶対値を全格子点で見た最大値。
- **判定の区分**: 計算値が有限でない、または最大誤差が10以上なら**発散**。最大誤差が0.1以上10未満なら**劣化**。0.1未満なら**安定**。

## 1. 出発点: 1台なら r によらず安定

学習型の担当計算機は、各時刻 t_{m+1} で、ニューラルネットワークの表す分布 u_θ(x) について残差

  R(x) = [u_θ(x) − u_prev(x)] / Δt − α u_θ''(x)

の二乗和を小さくするようにパラメータ θ を最適化する(u_prev は前の時刻の分布)。最適化にはレーベンバーグ・マーカート法を使い、前の時刻のパラメータを初期値にする。

2階微分を**新しい時刻の分布**で評価しているので、これは後退オイラー法と同じ形である。後退オイラー法の増幅因子は 1/(1 − z) で、すべての成分について r によらず 0 と 1 の間に入る(親文書 第6節)。よって、最適化が十分に収束しているなら、区間全体を1台で計算する場合は r によらず安定である。

## 2. 境目の扱いが陽的な要素を持ち込む

複数台で計算する場合、各担当計算機は自分の部分区間だけを最適化する。部分区間の端(境目の格子点)の値は、次のように作った**目標値**に合わせるよう、損失関数に項を加える。

  目標値 = u_p + r(u_{p−1} − 2u_p + u_{p+1})(すべて前の時刻の値。u_{p−1} または u_{p+1} の一方は隣の担当計算機の値)

これは前進オイラー法の式である。つまり**内部は陰的(後退オイラー法の形)、境目の格子点だけは陽的(前進オイラー法の形)**という混合の構造になる。

この作り方の理由は、各担当計算機の計算を局所に閉じるためである。境目まで陰的にすると、新しい時刻の値が区間全体で連立し、担当計算機の間で連立方程式を協調して解く必要が出てくる(親文書 後半2)。陽的な目標値なら、前の時刻の隣の値を1回受け取るだけで済む。その代わり、陽的な部分で安定性の制約が復活する。

## 3. 理論展開

### 3.1 理想化の仮定

次の2つを仮定する。

1. 最適化が毎ステップ完全に収束する(残差と目標値への差がちょうど0になる)。
2. ニューラルネットワークは、格子点上のどんな値の並びも表現できる。

この仮定のもとで、1ステップの写像は次の線形写像になる。

- 境目の格子点の組: 前進オイラー法で更新する。
- 内部の格子点: 境目の格子点の新しい値を境界値として、後退オイラー法の連立方程式 (1 + 2r)u_i − r(u_{i−1} + u_{i+1}) = u_i^{前の時刻} を厳密に解く。
- 区間全体の両端: 温度0に固定する。

### 3.2 更新行列の作り方

写像が線形なので、行列で表せる。格子点の数を63(両端を除く内部点)とし、i 番目だけが1で他が0のベクトルに写像を1回当てた結果を、行列の i 列目とする。これを63列分繰り返すと更新行列 G ができる。G のスペクトル半径(固有値の絶対値の最大)を数値計算で求め、1を超える最小の r を二分法で探す。

### 3.3 結果

| 分割の仕方 | 理論の安定限界 |
|---|---|
| 1台(分割なし) | なし(r = 5.0 でもスペクトル半径 0.988) |
| 2分割 | 0.7192 |
| 4分割 | 0.7192 |
| 8分割 | 0.7192 |
| 16分割 | 0.7073 |
| 32分割 | 0.5003 |

1台では陽的な部分がないので無条件に安定である。分割すると有限の安定限界が現れ、2〜8分割ではほぼ同じ値になる。

### 3.4 不安定な成分の形

限界の直上(8分割、r = 1.05)で、絶対値最大の固有値に対応する固有ベクトルを調べると、

- 成分の約9割が境目の格子点(全63点中14点)に集中している。
- 境目の格子点の組では、両側の値が同じ大きさで逆符号になっている(反対称)。
- 固有値は負の実数で、−1 を下回る。

つまり**境目に局在し、境目の両側で逆符号の、鋸歯状の誤差が、1ステップごとに符号を反転しながら増大する**。親文書 第7節で見た前進オイラー法の不安定(区間全体に広がる鋸歯状の成分)が、境目だけに局在した形で現れたものである。

### 3.5 安定限界の閉じた式の導出

不安定な成分が境目に局在していることを使うと、安定限界を式で求められる。1つの境目に注目し、境目の右側の格子点を位置0、内部へ向かって位置1, 2, … とする。次の形の固有ベクトルを仮定する。

- 右側: 位置 m の値が a μ^m(m = 0, 1, 2, …、|μ| < 1 で内部に向かって減衰)
- 左側: 右側と同じ大きさで符号が逆(反対称)

固有値を g とする(1ステップで各点の値が g 倍になる)。

**境目の格子点(位置0)の式**: 前進オイラー法で、左隣は −a、自分は a、右隣は aμ なので

  g·a = a + r(−a − 2a + aμ)  より  g = 1 − 3r + rμ  …(1)

**内部の格子点(位置 m ≥ 1)の式**: 後退オイラー法で、新しい値は g 倍されているので

  (1 + 2r)·g·aμ^m − r·g·(aμ^{m−1} + aμ^{m+1}) = aμ^m

両辺を aμ^m で割ると

  g[(1 + 2r) − r(μ + 1/μ)] = 1  …(2)

位置 m = 1 の左隣は境目の格子点の新しい値 g·a で、これは g·aμ^0 と同じ形なので、(2) は m = 1 でもそのまま成り立つ。

**安定限界**: 固有値がちょうど −1 になる r を求める。g = −1 を (1) に代入すると

  μ = 3 − 2/r

(2) に代入すると −(1 + 2r) + r(μ + 1/μ) = 1、つまり r(μ + 1/μ) = 2 + 2r。ここに rμ = 3r − 2 を使うと r/μ = 4 − r、すなわち μ = r/(4 − r)。2つの μ の式を等しいと置くと

  r/(4 − r) = (3r − 2)/r  →  r² = (3r − 2)(4 − r)  →  2r² − 7r + 4 = 0

  **r = (7 − √17)/4 ≈ 0.7192**(もう一つの解 (7 + √17)/4 ≈ 2.78 では |μ| > 1 となり不適)

このとき μ = r/(4 − r) ≈ 0.219 で、不安定な成分は境目から内部へ1点進むごとに約5分の1になる。境目から2〜3点でほぼ消えるので、各担当計算機の内部点が数点以上あれば、安定限界は分割数によらずほぼ一定になる。16分割では各担当計算機の内部点が2点しかなく、減衰しきらないうちに反対側の境目に届くので、限界がわずかに下がる(0.7073)。32分割では内部点がなくなり、すべての格子点が陽的に更新されるので、前進オイラー法そのものの限界 0.5 に一致する。

## 4. 掃引実験

### 4.1 方法

- 実施: 2026-09-20(主な掃引)、2026-09-21(1000ステップの追確認と補完測定)、2026-09-22(幅32の測定と初期値依存性)。
- 問題: 区間 [0, 1]、α = 1、格子点65個(h = 1/64)、初期条件 sin(πx)、両端0。解析解 sin(πx)e^{−π²t} と比較する。
- r を指定し、Δt = r·h² として計算する。300ステップで判定し、境界付近のセルは1000ステップで追確認した。
- シミュレータは差分法の設定では r > 1/2 を拒否するが、この実験のために学習型の担当計算機に限って警告にとどめた。
- 掃引のパラメータ: 分割数、r、中間層の幅、1ステップあたりの最適化の反復回数、残差を評価する点(格子点のみ、または格子の中点も追加)。

### 5.2 一致している点

- 1台では r = 2.0 まで安定(理論: 分割なしなら無条件に安定)。
- 分割すると有限の安定限界が現れ、r の大きい側から不安定になる(理論: 境目の陽的な部分が原因)。
- 16分割の実測の境界 0.6 < r ≤ 0.8 は、理論値 0.707 を含む。

### 5.3 ずれている点とその解釈

4分割と8分割の実測の境界は、理論値 0.719 より上にある。また中間層の幅を広げると、境界が下がっていく(幅16で 1.0 より上、幅24で 1.0 以下、幅32で 0.80〜0.90)。

解釈: 不安定な成分は、境目に局在した鋸歯状の、格子間隔の規模の鋭い形をしている(第3.4節)。小さいニューラルネットワークは滑らかな関数しか表せないので、この形を表現しきれない。表現できない成分は、最適化の結果に現れず、増大もしない。つまり**表現力の不足が、細かい成分を取り除くフィルタとして働き、安定化している**。幅を広げるとこのフィルタが弱まり、境界は理論値に上から近づく。分割数を増やすと各担当計算機が受け持つ格子点が減り、同じ幅でも鋭い形を表しやすくなるので、やはり境界が下がる。

この解釈から出る予想のうち、「幅とともに境界が下がる」向きは確認済みである。「十分に広い幅で理論値 0.719 に達する」ことと、「発散直前の誤差が境目に局在し、両側で逆符号で、1ステップごとに符号反転している」ことは未確認である。後者は、発散する計算の途中の温度分布を保存すれば、幅を広げずに確認できる(親文書 後半9)。

## 6. この文書で説明できないこと: 16分割の緩慢な劣化

r の小さい側でも、16分割に限って、発散はしないが誤差がゆっくり増え続ける劣化が現れる。r = 0.10〜0.60 の6値、分割数4種、幅3種、反復回数3種、残差の評価点2種の全組み合わせ432通り(300ステップ)の補完測定の結果は次のとおり。

- 安定386、劣化45、発散1。劣化と発散の46件はすべて16分割で、1台・4分割・8分割の324通りはすべて安定。
- r の方向にはほぼ一様(r = 0.10 で8件から r = 0.41 で9件)。
- 16分割の中では、幅8(劣化16、発散1)と幅24(劣化27)が悪く、幅16は劣化2件のみ。
- 格子の中点も評価に使うと、劣化は34件から11件に減り(残った11件の内訳は幅24が9件、幅16と幅8が各1件)、大きさも減る(例: r = 0.10、幅24、反復10回で 2.205 から 0.112)。
- 唯一の発散は r = 0.60、16分割、幅8、反復5回、格子点のみ(8.2e1)。

さらに、r = 0.25、16分割、幅16、反復5回、中点も使用のセルは、ニューラルネットワークの初期値の乱数を変えると結果が大きく変わった。

| 初期値の乱数 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| 最大誤差 | 5.294 劣化 | 20.23 発散 | 0.0559 安定 | 0.3685 劣化 | 0.00798 安定 | 0.00252 安定 |

この劣化は、r の大きい側から来る第3節の不安定とは性質が異なる。各担当計算機の格子点が少ないため、最小二乗問題の解が一意に定まらない方向があり、その方向に解がステップごとに漂っていく、という仮説を立てているが、機構は未確定である。固有値による安定性の議論の範囲外なので、別に扱う。

## 7. 運用への含意

- 実用上の安全な上限: 8分割以下で r ≤ 0.6、16分割で r ≤ 0.5(劣化のセルも避ける)。
- 差分法の担当計算機と学習型の担当計算機を混在させる場合は、全体が差分法の r ≤ 1/2 で運用されるので、学習型が安定性を律することはない。ただし混在させた場合の理論的な解析はまだ行っていない。
- 16分割で運用する場合は、初期値の乱数を変えた複数回の事前確認が必要である。
