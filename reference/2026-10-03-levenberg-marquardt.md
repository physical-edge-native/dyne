# 非線形最小二乗法からレーベンバーグ・マーカート法へ——導出の筋道と実装との対応

作成: 2026-10-03。前半で、学習型の担当計算機が毎ステップ解いている問題を非線形最小二乗問題として定式化し、ニュートン法からガウス・ニュートン法を経てレーベンバーグ・マーカート法までを一本の筋道として導く。後半で、その結果が本プロジェクトの実装のどの部分の根拠になり、どのシミュレーション結果を支えているかを項目ごとに説明する。

関連文書: 2026-10-03-stability-by-eigenvalues.md(安定性)、2026-10-03-learned-stability-region.md(学習型の担当計算機の安定性)。

本文で使う言葉の約束:

- **担当計算機**: 区間 [0, 1] を部分区間に分けたとき、各部分区間を受け持って計算する小型計算機。
- **学習型の担当計算機**: 部分区間の温度分布をニューラルネットワークで表し、各時刻で最適化して求める担当計算機。
- **境目**: 隣り合う部分区間の接する点。
- **r**: r = αΔt/h²(α は熱拡散率、Δt は時間刻み、h は格子間隔)。
- **最大誤差**: 解析解との差の絶対値を全格子点で見た最大値。

# 前半: 導出の筋道

## 1. 温度分布を式で表す

学習型の担当計算機は、自分の部分区間の温度分布を、次の式で表す(中間層の幅が16の場合)。

  u_θ(x) = Σ_{k=1}^{16} c_k · tanh(a_k x + b_k) + e

tanh は双曲線正接関数で、なめらかな S 字型の関数である。これは入力1つ、中間層1層、出力1つのニューラルネットワークにあたる。式に含まれる数は a_k が16個、b_k が16個、c_k が16個、e が1個の**合計49個**で、これらを1列に並べたベクトルを**パラメータ θ** と呼ぶ。中間層の幅を w とすると、パラメータの数は 3w + 1 である。

θ を変えると、S 字の位置・傾き・高さが変わり、u_θ(x) が表す温度分布の形が変わる。各時刻で θ を調整して温度分布を正しい形にすることを「学習する」と呼ぶ。

## 2. 残差: 何を小さくしたいか

時刻 t_m から t_{m+1} へ進むとき、前の時刻の温度分布を u_prev(x) とする(担当計算機は格子点での値として保存している)。熱方程式 ∂u/∂t = α ∂²u/∂x² を後退オイラー法で時間方向に離散化すると、新しい時刻の分布 u は

  [u(x) − u_prev(x)] / Δt − α u''(x) = 0

を満たすべきである。そこで、評価点 x_1, x_2, … のそれぞれで

  R_i(θ) = [u_θ(x_i) − u_prev(x_i)] / Δt − α u_θ''(x_i)

を計算する。これを**残差**と呼ぶ。さらに、部分区間の両端で満たすべき条件(端の値がある目標値に一致すること)についても、「端での u_θ − 目標値」に重みを掛けたものを残差に加える(本実装の重みの既定値は1)。

これらの残差を1列に並べたベクトルを **R(θ)**、その個数を m とする。R がすべて0なら、離散化した熱方程式と端の条件が評価点で完全に満たされている。各時刻で解く問題は

  **f(θ) = ½ Σ_i R_i(θ)² = ½ ‖R(θ)‖² を最小にする θ を求める**

である。

**残差の個数 m** は、おおよそ「部分区間の中の評価点の数 + 端の条件の数(2個)」で決まる。評価点は担当する格子点で、格子の中点も評価に使う設定にすると約2倍になる。区間 [0, 1] を格子間隔 1/64 で16等分すると、1台あたりの格子点は4〜5個なので、m は約6〜7個になる。分割数を増やすほど、1台あたりの m は減る。

## 3. 残差とその微分は正確に計算できる

u_θ(x) は具体的な式なので、x について手で微分できる。tanh'(s) = 1 − tanh²(s) を使い、t_k = tanh(a_k x + b_k) と置くと

  u_θ'(x) = Σ_k c_k a_k (1 − t_k²)
  u_θ''(x) = Σ_k c_k a_k² · (−2 t_k (1 − t_k²))

となる。右辺は θ と x から直接計算できる。差分法では2階微分を隣の格子点との差で**近似**していたが、温度分布を式で持っていれば、2階微分を**式として正確に**計算できる。

同様に、各残差を各パラメータで微分した値 ∂R_i/∂θ_a も式として計算できる。これを m 行 49 列に並べた行列を**ヤコビ行列 J** と呼ぶ。J は「各パラメータを少し動かしたとき、各残差がどれだけ変わるか」の表である。

(本実装が実際にこの式で微分を計算しているかは、資料からは確認していない。)

## 4. 線形の最小二乗問題との違い

**線形の最小二乗問題**は、行列 A とベクトル b が与えられたとき、‖Ax − b‖² を最小にする x を求める問題である。典型例は、データ点 (t_i, y_i) に直線 y = p + qt を当てはめる問題で、A の各行を (1, t_i)、x = (p, q)、b を y_i を並べたものとすれば、Ax − b が各点での当てはめのずれになる。½‖Ax − b‖² の勾配は Aᵀ(Ax − b) なので、それを0と置いた

  AᵀA x = Aᵀb  (**正規方程式**)

を1回解けば、最適な x が求まる。

一方、本問題の残差 R(θ) は、θ が tanh の中に入っているので、θ について**非線形**である。このような問題を**非線形最小二乗問題**と呼び、1回の連立方程式では解けないので、反復法を使う。

## 5. ニュートン法

関数 f の最小点を探すニュートン法は、今の点の近くで f を2次式で近似し、その2次式の最小点へ一歩で移る方法である。一歩 d は

  (∇²f) d = −∇f

を解いて求める(∇f は勾配、∇²f はヘッセ行列)。ヘッセ行列が正定値なら、この d は f が下がる方向(下り坂の方向)を向き、解の近くでは非常に速く収束する(2次収束)。ヘッセ行列が正定値でないと、下り坂の方向になる保証がない。

## 6. 最小二乗問題の勾配とヘッセ行列

f(θ) = ½ Σ_i R_i² を θ_a で微分すると

  ∂f/∂θ_a = Σ_i R_i · ∂R_i/∂θ_a

で、ベクトルでまとめると

  **∇f = JᵀR**

である。もう一度 θ_b で微分すると、積の微分で2つの項が出る。

  ∂²f/∂θ_a∂θ_b = Σ_i (∂R_i/∂θ_a)(∂R_i/∂θ_b) + Σ_i R_i · ∂²R_i/∂θ_a∂θ_b

行列でまとめると

  **∇²f = JᵀJ + Σ_i R_i ∇²R_i**

である。ニュートン法をそのまま使うと、次の2つが問題になる。

- **計算が重い**: 第2項のために、残差ごとにパラメータについての2階微分(49×49 の行列)が必要になる。
- **正定値とは限らない**: 第2項は符号が決まっていないので、ヘッセ行列全体が正定値でなくなることがある。

## 7. ガウス・ニュートン法: 第2項を捨てる

第2項を捨てて

  **(JᵀJ) d = −JᵀR**

を解くのがガウス・ニュートン法である。捨ててよい理由は2つの見方で説明できる。

**見方1(残差が小さい)**: 第2項には残差 R_i が掛かっている。解の近くでは残差が小さいので、第2項も小さい。

**見方2(線形化して線形の最小二乗問題を解く)**: 残差を今の θ の近くで1次近似すると

  R(θ + d) ≈ R(θ) + J d

である。この近似の二乗和 ½‖Jd + R‖² を d について最小にする問題は、第4節の線形の最小二乗問題で A = J、x = d、b = −R と置いたものと同じ形なので、正規方程式 JᵀJ d = −JᵀR が出る。これを解いて θ を θ + d に更新すると R と J が変わるので、また線形化して解く。**非線形の当てはめを、直線の当てはめと同じ種類の計算の繰り返しで解く**のがガウス・ニュートン法である。

**良い性質**: 任意のベクトル v について vᵀJᵀJv = ‖Jv‖² ≥ 0 なので、JᵀJ は常に半正定値である。2階微分を計算せずに、正定値に近い行列が得られる。さらに、ガウス・ニュートン法の一歩 d について

  ∇fᵀd = (JᵀR)ᵀd = −dᵀJᵀJ d = −‖Jd‖² ≤ 0

なので、Jd ≠ 0 なら d は必ず下り坂の方向である。

## 8. ガウス・ニュートン法の弱点

**弱点1: JᵀJ が特異になりうる**。Jv = 0 となる方向 v(パラメータを動かしても残差が変わらない方向)があると、JᵀJ は逆行列を持たず、一歩が1つに決まらない。

特に、残差の数 m がパラメータの数(49)より少ないときは、必ずそうなる。J は m 行 49 列なので、そのランク(線形独立な行の最大数)は m 以下であり、JᵀJ のランクも m 以下である。49×49 の行列が逆行列を持つにはランクが49必要なので、m < 49 なら JᵀJ は特異である。m = 7 なら、Jv = 0 となる方向が少なくとも 49 − 7 = 42 次元分ある。直感的には、**7本の式で49個の未知数を決めようとしている**状態で、7個の点を通る曲線を49個のパラメータで描く方法は無数にある。

**弱点2: 一歩が大きすぎることがある**。線形化は今の θ の近くでしか正しくないので、遠くへ跳ぶと f がかえって増えることがある。

## 9. レーベンバーグ・マーカート法

ヘッセ行列が正定値でないときにニュートン法を修正する方法として、ヘッセ行列に μI(μ > 0、I は単位行列)を足す修正がある。これをガウス・ニュートン法に適用したものが

  **(JᵀJ + μI) d = −JᵀR**

で、**レーベンバーグ・マーカート法**と呼ぶ。

**性質**:

- JᵀJ の固有値は0以上なので、JᵀJ + μI の固有値はすべて μ 以上になる。**常に正定値**で逆行列を持ち、一歩は必ず1つに決まり、下り坂の方向を向く。
- **μ → 0** でガウス・ニュートン法に近づく(解の近くで速く収束する)。
- **μ → ∞** で d ≈ −(1/μ)JᵀR、つまり最急降下法の小さな一歩になる(慎重だが確実に下る)。
- **μ の調整**: 一歩進んで f が下がればその一歩を採用して μ を小さくする(ガウス・ニュートン法寄りに大胆になる)。下がらなければ一歩を捨てて μ を大きくする(最急降下法寄りに慎重になる)。

**罰則つきの線形最小二乗としての見方**: 関数

  ½‖R + Jd‖² + (μ/2)‖d‖²

を d で微分して0と置くと Jᵀ(R + Jd) + μd = 0、すなわち (JᵀJ + μI)d = −JᵀR となる。レーベンバーグ・マーカート法の一歩は、「線形化した残差を小さくしたいが、一歩の大きさには罰を科す」問題の解である。これは、一歩の大きさをある範囲に制限して線形化した問題を最小化する**信頼領域法**の一歩と一致する(μ は制限の範囲に対応して決まる)。

**JᵀJ が特異な場合の振る舞い**: 第8節の弱点1で正規方程式の解が無数にあるとき、μ を0に近づけたレーベンバーグ・マーカート法の一歩は、その無数の解のうち**長さが最小の解**に近づく。残差を決める式が何も言わない方向には、パラメータを動かさない一歩が選ばれる。

## 10. 零空間の成分を持たないこと

J の零空間(Jv = 0 となる v 全体)と、J の行空間(J の行の線形結合で作れるベクトル全体)は、互いに直交し、合わせると49次元の空間全体になる。

- JᵀR は J の行の線形結合なので、行空間に入る。
- 行空間のベクトル w について、JᵀJw は行空間に入り、μw も行空間に入るので、JᵀJ + μI は行空間を行空間に写す。零空間のベクトル v については (JᵀJ + μI)v = μv で、零空間を零空間に写す。

したがって (JᵀJ + μI)d = −JᵀR の解 d は**行空間に入り、零空間の成分を持たない**。つまり**残差が θ について線形なら**、レーベンバーグ・マーカート法は「残差に影響しない方向」にはパラメータを一切動かさない。

## 11. 2階微分の項の硬さと、勾配だけを使う方法が遅い理由

### 11.1 「硬さ」とは何か

開発の過程で「2階微分の項の硬さのために一次の最適化法が収束しなかった」と記録されている。この「硬さ」は、熱方程式の数値計算で出てきた**硬い問題**(安定性の文書 第8節)と同じ意味で理解できる。

勾配だけを使う最急降下法は、一歩の大きさ(学習率)を η として

  θ ← θ − η ∇f(θ)

と進む。これは、パラメータが時間とともに勾配の逆方向へ流れていく常微分方程式(勾配流)

  dθ/ds = −∇f(θ)

を、刻み幅 η の**前進オイラー法**で解いていることにほかならない。解の近くで ∇f ≈ H(θ − θ*)(H はヘッセ行列、θ* は最小点)と線形化すると、これは安定性の文書の du/dt = Au と同じ形の連立常微分方程式で、行列 −H の固有値は −λ_1, …, −λ_n(λ は H の固有値)である。

安定性の文書 第6節の結果をそのまま使うと、

- 前進オイラー法が発散しない条件は、すべての固有値について η λ ≤ 2、すなわち **η ≤ 2 / λ_最大**。一歩の大きさは、最も急な方向(最大固有値)で制限される。
- 一方、最も緩やかな方向(最小固有値 λ_最小)では、1ステップで誤差が (1 − η λ_最小) 倍にしかならない。η ≤ 2/λ_最大 のもとでは、この方向の誤差を一定の割合だけ減らすのに必要な反復回数は、およそ **λ_最大 / λ_最小(条件数)** に比例する。

つまり、固有値の大きさが大きく異なる方向が混在すると、最も急な方向に合わせて一歩を小さくせざるを得ず、最も緩やかな方向がいつまでも収束しない。これが最適化における「硬さ」であり、熱方程式で最も細かい成分が時間刻みを制限したのとまったく同じ構造である。谷の中をジグザグに進む、という言い方もされる。

### 11.2 なぜ本問題は硬いのか

最小点の近くでは H ≈ JᵀJ である(第7節)。本問題の残差には α u_θ''(x) の項があり、第3節の式のとおり u_θ'' には a_k² が掛かる。このため、

- S 字の傾き a_k が大きい(鋭く変化する)項を動かす方向では、残差が大きく応答する。
- 傾きの小さい(なだらかな)項や、全体を平行移動させる e の方向では、2階微分の項がほとんど応答しない。

パラメータの方向によって残差の応答の大きさが桁違いに異なるので、JᵀJ の固有値が大きく広がり、条件数が大きくなる。ただし、実際の条件数の値は測定していない。

### 11.3 ガウス・ニュートン法とレーベンバーグ・マーカート法が強い理由

ガウス・ニュートン法の一歩 (JᵀJ)d = −JᵀR は、勾配に JᵀJ の逆行列を掛けたものである。最も急な方向では一歩が小さく、最も緩やかな方向では一歩が大きくなるように、方向ごとに自動で補正される。硬い常微分方程式に陰的な解法を使うと時間刻みの制限がなくなったのと同様に、曲がり具合の情報を使うことで条件数の悪さに左右されにくくなる。

## 12. 全体の流れ

  温度分布を式 u_θ(x) で表す(パラメータ θ は49個)
  → 各時刻の問題: 後退オイラー法の残差の二乗和 f(θ) = ½‖R(θ)‖² を最小化(非線形最小二乗問題)
  → 残差とヤコビ行列 J は式として正確に計算できる
  → ニュートン法: ヘッセ行列 = JᵀJ + Σ R_i ∇²R_i(重い、正定値とは限らない)
  → ガウス・ニュートン法: 第2項を捨てる = 線形化して線形の最小二乗問題を解く、の繰り返し
  → 弱点: 残差の数がパラメータより少ないと JᵀJ が特異、一歩が大きすぎる
  → レーベンバーグ・マーカート法: μI を足して常に正定値に。μ で最急降下法とガウス・ニュートン法の間を調整
  → 性質: 線形なら零空間の成分を持たない、条件数の悪さに強い

### 用語

- **分割数**: 区間 [0, 1] を何台の担当計算機で分担するか。「1台」は分割しない場合、「4分割」は4台で4等分する場合。実験で使った分割数は 1、2、4、8、16 で、格子点65個(格子間隔 1/64)を等分する。16分割では1台あたり格子間隔4つ分(格子点4〜5個)を受け持つ。
- **中間層の幅**: 第1節の式 u_θ(x) = Σ c_k tanh(a_k x + b_k) + e で、和に含まれる tanh の項の数。幅8なら8項でパラメータ25個、幅16なら16項で49個、幅24なら24項で73個、幅32なら32項で97個。幅が大きいほど複雑な形を表せる。
- **反復回数**: 1つの時刻ステップの中で、レーベンバーグ・マーカート法の一歩を何回繰り返すか。既定は5回。
- **最大誤差**: 判定の時点で、全格子点について「計算値 − 正解値」の絶対値をとった最大値。小さいほど正確。「精度が良い」とは最大誤差が小さいことを言う。
- **判定の区分**: 計算値が有限でない(数値があふれた)か、最大誤差が10以上なら**発散**。最大誤差が0.1以上10未満なら**劣化**(発散はしていないが、正解から大きくずれている)。0.1未満なら**安定**。正解値の最大値は1(初期条件 sin(πx) の最大値)なので、劣化は「正解と同じ程度以上にずれている」状態である。1000ステップの追確認では、劣化のセルは有界にとどまらず誤差が増え続けたので、劣化は「ゆっくり増大する不安定」と読むのが安全である。

### 正解値は信頼できるか

精度と安定性の判定に使った正解値は、シミュレータが計算したものではなく、熱方程式の**解析解**

  u*(x, t) = sin(πx) e^{−απ²t}

を式に代入して求めた値である。この式が熱方程式 ∂u/∂t = α ∂²u/∂x² と、両端で0、初期条件 sin(πx) を満たすことは、代入して直接確かめられる(∂u*/∂t = −απ²u*、∂²u*/∂x² = −π²u*)。したがって正解値は、シミュレータの正しさに依存せず、独立に正当である。

ただし注意点が2つある。

- **離散化の誤差を含む**: 計算は格子と時間刻みで離散化しているので、計算が完璧でも、連続の解析解との間に離散化による小さな誤差が残る。差分法で同じ問題を計算した場合の誤差がその目安で、開発時の測定の1台の最大誤差 2.5e-4 などにはこの分も含まれる。ただし劣化と発散の判定の閾値(0.1 と 10)は、この誤差よりはるかに大きいので、判定の区分には影響しない。
- **試験問題が単純である**: 初期条件 sin(πx) の解は、第4節の固有ベクトルのうち最も緩やかな成分1つだけでできている。複雑な形の温度分布に対する精度は、この試験では確かめられない。不安定は計算の過程で生じる細かい誤差から成長するので、安定性の判定にはこの単純な問題でも有効である。

なお、データ同化(観測を取り込む計算)の実験では、正解値として「同じシミュレータで、分割せず観測も取り込まずに計算した解」を使っている。こちらは解析解ではないが、分割した計算が分割しない計算とビット単位で一致することが別途確かめられているので、「分割と観測の影響だけを取り出した比較」として正当である。ただし、離散化の誤差は正解値の側にも同じだけ含まれるので、物理的な真の温度との比較ではない。物理的な真の温度との比較は、センサで実測する実験1で初めて可能になる。

## 後半1. 最適化の方法としてレーベンバーグ・マーカート法を採用したこと

- **根拠となる箇所**: 第6〜9節、第11節。
- **実装**: 学習型の担当計算機は、各時刻で、49個のパラメータについての非線形最小二乗問題をレーベンバーグ・マーカート法で解く。
- **支える結果**: 開発の初期に、勾配だけを使う一次の最適化法(確率的勾配降下法とその改良版)を試したが、2階微分の項の硬さのために収束せず、採用しなかった。
- **「2階微分の項の硬さ」の意味**: 残差に含まれる α u_θ'' の項には a_k² が掛かるので、パラメータの方向によって残差の応答の大きさが桁違いに異なる(第11.2節)。勾配だけを使う方法は、勾配流という常微分方程式を前進オイラー法で解いているのと同じなので、熱方程式の硬い問題と同じく、一歩の大きさが最も急な方向で制限され、最も緩やかな方向がなかなか収束しない(第11.1節)。
- **支え方**: 定性的に完全。ただし、実際の JᵀJ の条件数は測定していない。条件数を測れば、この説明を数値で確かめられる。

## 後半2. 1ステップあたりの反復回数と、前の時刻のパラメータからの開始

- **根拠となる箇所**: 第5節(ニュートン法は解の近くで速く収束する)、第7節(ガウス・ニュートン法は残差が小さいとニュートン法に近い)。
- **実装**: 各時刻の最適化は、前の時刻で得たパラメータを初期値にして始め、1ステップあたり5回反復する。計算開始時だけは、初期条件の分布に合わせるために20〜30回反復し、損失(残差の二乗和)を 10⁻⁹ 以下にする。
- **理論的な説明**: 時間刻みが小さければ、新しい時刻の解は前の時刻の解に近い。解の近くから始めれば、ガウス・ニュートン法に近い速い収束が働くので、少ない反復で十分になる。
- **支える結果**: 4分割、r = 0.41 での掃引実験(2026-09-20)で、反復2回では最大誤差が約 2e-2 と精度が2桁落ちたが、反復5回(幅16で 4.7e-5)と反復10回(5.6e-5)はほぼ同じだった。この結果から、計算量が半分で済む5回を既定にした。
- **支え方**: 部分的。少ない反復で足りることは定性的に説明できるが、2回では足りず5回で足りる理由の定量的な説明はない。また、安定性の境界付近では反復回数の効果が単調でない(r = 1.00、幅16で、2回は発散、5回と10回は劣化)ことは、この文書の範囲では説明できない。

## 後半3. 分割数を増やすと1台あたりの残差が減ること

- **根拠となる箇所**: 第2節(残差の個数)、第8節(m < 49 なら JᵀJ は特異)、第9節(μI があれば一歩が決まる)。
- **実装**: 区間を16等分すると、1台あたりの残差は約6〜7個で、パラメータ49個より大幅に少ない。この場合、ガウス・ニュートン法の正規方程式は解が1つに決まらず、レーベンバーグ・マーカート法の μI があって初めて一歩が決まる。
- **支える結果**: 「開発時の精度の測定」(r ≈ 0.41、幅16、反復5回、2000ステップ後の最大誤差)で、1台 2.5e-4、2分割 3.3e-4、4分割 6.1e-5、8分割 8.4e-5 に対し、**16分割だけ 2.1e-2 と約100倍悪化**した。格子の中点も残差の評価に使う(残差の個数を約2倍にする)と、16分割の最大誤差は 3.1e-5 に下がり、他の分割数と同じ水準に戻った。また「432通りの補完測定」で、劣化と発散の46件はすべて16分割で起き、1台・4分割・8分割の324通りはすべて安定だった。
- **理論的な説明**: 残差は評価点でしか熱方程式を課さないので、評価点の**間**の分布の形(特に2階微分)は残差によって決まらない。評価点が少ないほど、決まらない部分が大きい。格子の中点を評価点に加えると、点の間の形が拘束される。
- **支え方**: 部分的。16分割だけが悪いこと、評価点を増やすと回復することは説明できる。しかし、評価点を4倍にする設定ではかえって悪化した実験結果は、「点を増やすほど良い」というこの説明と矛盾し、未解明である。

## 後半4. 中間層の幅(パラメータの数)の影響

- **根拠となる箇所**: 第8節(残差の数とパラメータの数の比)、第10節。
- **実装**: 中間層の幅(第1節の式に含まれる tanh の項の数)は既定で16(パラメータ49個)。幅8(25個)、幅24(73個)、幅32(97個、実装上の上限)も選べる。

**支える結果**: 「432通りの補完測定」のうち、16分割の結果を幅ごと・評価点の取り方ごとに数えると次のとおり。各欄は「劣化または発散の件数 / 試した設定の数」で、試した設定の数は r 6通り × 反復回数3通り = 18通りである。

| 幅(パラメータ数) | 格子点のみ | 格子の中点も使用 |
|---|---|---|
| 8(25個) | 16 / 18(うち発散1) | 1 / 18 |
| 16(49個) | 1 / 18 | 1 / 18 |
| 24(73個) | 18 / 18 | 9 / 18 |

この表の読み方:

- **「幅24が悪い」**: 格子点のみでは、幅24は18通りの設定のすべてで劣化した。r にも反復回数にもよらず、幅24では誤差がゆっくり増え続ける。
- **「幅8も悪く、幅16だけがほぼ無傷」**: 格子点のみでは、幅8も18通り中16通りで劣化または発散した。一方、幅16は18通り中1通りしか劣化しなかった。パラメータの数は 25 < 49 < 73 の順に増えるのに、悪さは中央の幅16で最も小さく、両側の幅8と幅24で大きい。幅について**谷**の形になっている。
- **「回復する」**: 格子の中点も評価に使うと、幅8は劣化が16通りから1通りに減り、ほぼすべての設定で安定になった。これを「回復する」と呼んでいる。幅24は18通りから9通りに減っただけで、半分は劣化したままだった。

ここで比べているのは、劣化したかどうかの**件数**である。劣化したセルの最大誤差の大きさも、格子の中点を使うと小さくなった(例: r = 0.10、幅24、反復10回で、2.205 から 0.112 へ)。

**理論的な説明**: 16分割では、格子点のみで残差は約6〜7個、格子の中点も使うと約11個で、どの幅でもパラメータの数より少ない。パラメータが多いほど、残差が決めない方向(零空間)の次元が大きい(幅24で格子点のみなら少なくとも 73 − 7 = 66 次元)。幅24が悪く、中点を加えても半分しか回復しないことは、「評価点を増やしてもなおパラメータが大幅に余る」という第8節の見方と整合する。

**支え方**: 部分的。幅24が悪いことは説明できる。幅8が悪いことも、パラメータ25個が残差6〜7個よりはるかに多いという点では同じ見方で理解でき、中点を加えるとほぼ回復することとも整合する。しかし、**幅16だけがほぼ無傷である理由**(谷の底がちょうど幅16にあること)は説明できていない。幅16は長く既定値として使われてきたので、反復回数や最適化の細かい設定が、知らないうちに幅16に合うように調整されている可能性がある。この可能性は、幅12や幅20を試して、谷の底が幅16だけの鋭い点なのか、なだらかな谷なのかを見れば判別できる。

## 後半5. ゆっくり誤差が増え続ける劣化についての仮説

- **根拠となる箇所**: 第10節(線形なら零空間の成分を持たない)。
- **仮説**: 第10節により、残差が線形なら、レーベンバーグ・マーカート法は残差に影響しない方向にはパラメータを動かさない。それでも16分割で誤差がゆっくり増え続けるのは、(1) 残差が θ について非線形で、θ が動くたびに零空間の向きが少しずつ変わること、(2) 前の時刻のパラメータを初期値にするので、零空間に沿ったずれが時刻をまたいで引き継がれること、の2つによると考えられる。
- **予想**: 損失に「前の時刻のパラメータから離れすぎないための項」λ‖θ − θ_prev‖² を加えると、零空間の方向が固定され、劣化が止まるはずである(第9節の罰則つきの見方で、罰の中心を前の時刻のパラメータにしたもの)。
- **支える結果**: 劣化したセルの1つ(r = 0.25、16分割、幅16、反復5回、中点も使用)で、ニューラルネットワークの初期値の乱数を変えると、最大誤差が 0.0025 から 20(発散)まで大きく変わった。結果が初期値に強く依存することは、残差が決めない方向が残っていることと整合する。
- **支え方**: 仮説の段階で、予想は未検証である。

## 後半6. 境目の条件を残差の1つとして課すこと

- **根拠となる箇所**: 第2節(端の条件を残差に加える)。
- **実装**: 部分区間の端の値は、隣の担当計算機の前の時刻の値から差分法の式で作った目標値に一致させる。この条件は残差の1つの成分として加わり、ヤコビ行列 J の1行になる。担当計算機の置かれていない区間との境目に透過境界条件を使う場合も、同じく端の値の目標を作って残差に加える。
- **支える結果**: 透過境界条件を学習型の担当計算機に課す際、補助変数(過去の履歴の記憶)を「目標値」の変化で更新していたのを、「最適化の結果として実際に得られた端の値」の変化で更新するよう修正したところ、最大誤差が 1.6e-3 から 6.4e-4 に下がった。
- **理論的な説明**: 反復回数が有限なので、最適化が終わった時点で残差は完全には0にならず、端の値は目標値と少しずれる。そのずれを無視して目標値で履歴を進めると、履歴と実際の計算結果が食い違っていく。最適化が不完全であることを前提に、実際の値を使うべきである。
- **支え方**: 部分的。条件が残差の行として入ることと、有限回の反復では目標が完全には満たされないことの説明は完全である。しかし、境目の目標値の作り方そのもの(初期の版で隣の値に直接合わせたところ、誤差が時間とともに蓄積して350倍悪化したこと)は、時間方向の整合性の問題で、この文書の範囲外である。

## 後半7. 学習型の担当計算機でナッジングが効かなかったこと

- **根拠となる箇所**: 第2節、第9節(罰則つきの見方)。
- **実装**: ナッジング(観測点の値を観測値へ割合 γ で引き寄せる操作)を、学習型の担当計算機では「前の時刻の分布 u_prev の観測点での値を書き換え、次の時刻の最適化にそれを目標として使わせる」形で実装した。
- **支える結果**: 部分観測の計算で、ナッジングなしの最大誤差 0.504 に対し、ナッジングありでは 0.534〜0.720 と改善せず、わずかに悪化した。
- **理論的な説明**: u_prev の1点を書き換えると、その点の残差1つだけが観測値の方へ引かれる。一方、隣接する評価点の残差は、書き換えでできた人工的な折れを均そうとする。最小二乗の解は全残差の二乗和で決まるので、観測の情報は多数の残差に薄められ、実質的な引き寄せは γ よりはるかに弱くなる。
- **提案**: 観測を独立した残差の成分「重み × (u_θ(観測点) − 観測値)」として加える。重みを観測ノイズの分散の逆数にとると、これは重みつき最小二乗法で、観測と予測の確からしさを釣り合わせる標準的な方法になる。
- **支え方**: 部分的。効かなかった理由の説明と改善案の根拠にはなるが、提案は未検証である。

## 後半8. 機能を保ったまま中間層の幅を広げること

- **根拠となる箇所**: 第1節(式の形)、第3節(ヤコビ行列)。
- **実装**: 中間層の幅を8から16に広げる際、新しく加える項 c_k · tanh(a_k x + b_k) の係数 c_k を0で初期化する。
- **支える結果**: 幅を広げる前後で、全格子点の値がビット単位で一致した。
- **理論的な説明**: c_k = 0 なら新しい項は u_θ(x) に何も加えないので、関数は厳密に変わらない。さらにヤコビ行列を見ると、新しい a_k と b_k についての列は c_k が掛かるので0になり、c_k についての列だけが0でない。したがって広げた直後の最適化では、まず c_k だけが動き始める。
- **支え方**: 関数が変わらないことについては完全。広げた後の学習の進み方については、最初の一歩の向きが分かるだけで、それ以上は解析していない。
