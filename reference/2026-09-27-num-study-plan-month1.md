## 第2週: 熱方程式を合意制御として見る

### 読む順番

- [ ] 東 2.2.1〜2.2.3(グラフ、グラフラプラシアン)
- [ ] 東 2.2.4(ペロン行列)、2.2.5(重み付きグラフ)

- [ ] 金子 第I部 2.1〜2.3(熱方程式の導出、拡散、ブラウン運動): 浸透深さ √(αt) の由来

### 押さえるべき対応関係

- 経路グラフのラプラシアンを L とすると、離散時間合意 x ← (I − εL)x は熱方程式の陽解法(r = ε)と同じ式。I − εL がペロン行列。
- 経路グラフの次数は2なので、ペロン行列の非負条件 ε ≤ 1/(次数の最大値) は **r ≤ 1/2** になる。
- zero_grad(片側差分=ゴーストに端点値)は平均への合意。鏡映ゴースト版は端の辺の重みが変わる重み付きグラフ。
- u=0 固定端は、値0のリーダーがいる合意問題。
- この問題では「フォン・ノイマンの条件」「固有値の条件」「ペロン行列の非負条件」がすべて r ≤ 1/2 で一致する(一般のスキームでは一致しない)。

### 到達判定(3つとも満たしたら第3週へ)

- [ ] 陽解法の更新行列がペロン行列 I − rL であることを式で確かめ、r ≤ 1/2 が非負条件と一致することを説明できる
- [ ] zero_grad=平均への合意、u=0=リーダー付き合意を、以前のシミュレーション(固定端と断熱端の比較)の挙動と対応づけて説明できる
- [ ] V = Σu² が各ステップで増えないことを示し(エネルギー法)、これが**境界条件込み**の安定性の証明であること(フォン・ノイマン解析ではできないこと)を説明できる

### 理論課題2: 境界条件と同化をエネルギー法で統一する

- [ ] (a) zero_grad と u=0 でのエネルギー法の証明、T7/T9の境界条件を合意制御の言葉で書き直す
- [ ] (b) N11の定理(γ ≤ 2 なら観測点の配置によらず安定)を、作用素ノルム ≤ 1 の合成として自分で証明し直す
- [ ] (c) 発展: 採用済みの透過境界がエネルギー的に安定であることを、境界流束の作用素の受動性から示す
