- 置き場所: theory/guarantee/(決定19「保証の理論のコードはこのリポジトリ内の独立したディレクトリに置く」に従う)。

## 1. 何を作ったか

構成を JSON で宣言的に書く(区画の並び=格子型アクター(差分法、前進オイラー法)か学習型アクター
(時間離散化したPINN(物理情報ニューラルネットワーク、物理方程式を満たすよう学習するNN))か、区画ごとの格子点数、α、h、
両端の境界条件(温度固定・ゼロ勾配・透過・線形外挿)、透過境界の離散化方式、ナッジングのγと観測点)。
検証器はこれから**誤差の1ステップの線形写像**を単位ベクトルを1本ずつ通して行列にし、

- スペクトル半径(固有値の絶対値の最大)→ 安定/不安定の判定と余裕
- 行和ノルム(行ごとの係数の絶対値の和の最大)→ 1以下なら「誤差の最大値は毎ステップ増えない」(十分条件)
- 安定限界 r*(粗い走査のあと二分法)、ナッジングの安定境界 γ*

を返す。

### 理想化の仮定(theory/acute.py と reference/2026-10-03-learned-stability-region.md 第3.1節に揃えた)

- 格子型アクター: 全点を u + r(左 − 2u + 右) で更新。界面の点は隣の端点の前の時刻の値をゴースト点に使う。
- 学習型アクター: 最適化が毎ステップ完全に収束し、任意の値の並びを表現できると仮定。
  - 界面に接する端点(と透過境界の端点)は、格子型と同じ陽的な式で作った目標値になる
    (heat1d-pinn-actor の界面条件の方式1=既定、透過境界の目標値と同じ作り方)。
  - それ以外の点は後退オイラー法を厳密に解く。陽的に決まった端点の新しい値を境界値に使う。
    温度固定の端は0、ゼロ勾配の端は鏡映(u₋₁ = u₁)で連立に入れる。
  - 区画が1点だけのときは陽的な目標値そのものとする(縮退した場合の約束)。
- ナッジングは1ステップの計算の後。透過境界の補助変数は theory/tbc.py と同じ指数和で状態に含める。
- 界面の点の扱いは、格子型どうし・格子型と学習型・学習型どうしで同じ(どちらも隣の前の時刻の端点値
  1つだけを使う陽的な式)。したがって混在の写像は「陽的に決まる点の集合」と「後退オイラー法で解く点の
  集合」の組み合わせとして一様に書ける。

## 3. 新しい結果: 混在構成

### 3.1 十分条件(証明つき): r ≤ 1/2 なら、どんな混ぜ方でも誤差の最大値は増えない

r ≤ 1/2 のとき、陽的な式の係数(1−2r, r, r、ゼロ勾配の端は 1−2r, 2r)はすべて非負で和は1以下。
後退オイラー法の係数行列(対角 1+2r、隣 −r)は対角優位で非対角が非正なので、逆行列の成分はすべて
非負(M行列の性質)。全点が1のとき後退オイラー法の解も1になる((1+2r) − 2r = 1)。よって1ステップの
写像は非負の係数で、各行の和は1以下 → 行和ノルム ≤ 1。ナッジングは観測点の行を (1−γ) 倍するので、
0 ≤ γ ≤ 2 ならこの性質を保つ。**格子型と学習型の並べ方・区画の大きさ・分割数によらない**
(温度固定・ゼロ勾配の端。透過境界は補助変数があるので対象外)。
test_checker.py で乱数の構成20通り×r=0.1/0.3/0.5 を確認済み。

これは「混在させても全体を格子型の r ≤ 1/2 で運用すれば学習型が安定性を律することはない」
(reference/2026-10-03-learned-stability-region.md 第7節、未解析とされていた点)の、理想化の範囲での証明になる。

読み取り:

1. 格子型が1区画でもあれば、限界はほぼ1/2で、不安定な成分は格子型の区画に乗る(割合0.9〜1.0)。
   学習型の界面の限界0.719は、格子型がない構成でだけ効く。**混在構成の安定性を律するのは格子型の区画**。
2. 混ぜても限界は1/2を下回らない(3.1の十分条件と整合)。混ぜることで限界が下がる構成は見つからなかった。
3. 学習型に挟まれた**小さな格子型の区画**は、限界が1/2より上がる(1点で0.6024)。周りの後退オイラー法が
   鋸歯状の成分を吸収するため。この値は全体の格子点数によらず(65点と129点で4桁一致)、k だけで決まる
   局所的な量。k = 1 の値は第3.5節(learned-stability-region)と同じ方法で閉じた式にできる:
   格子型の点の値 c、両隣の学習型の端点 a、内部へ a μ^m と置き、固有値 −1 を代入すると
   c = r a/(r−1)、端点の式 2 − 2r + rμ − r²/(1−r) = 0、内部の式 μ + 1/μ = 2 + 2/r
   (|μ| < 1 の根)。これを解くと r ≈ 0.60241(検証器の0.6024と一致)。
4. 実用上の含意: 運用の保証には十分条件 r ≤ 1/2(3.1)を使えばよく、余裕は小さい(固有値の限界も1/2の
   わずか上)。r を1/2より上げたい場合は、格子型の区画を小さくして学習型で挟む構成でしか得がない。

## 4. 注意点(この予測の限界)

- **最適化の完全収束と、任意の値の並びを表現できること**を仮定している。実測では学習型の分割の境界が
  理論の0.719より上にあった(幅16・4分割で 1.0 < r* ≤ 1.5)。表現力の不足が細かい成分を落とすため、
  と解釈されている。混在構成でも同じ向きのずれがありうるが、上の結果では不安定な成分は格子型の側に
  乗るので、ずれは小さいと予想する(**予想。未確認**)。
- 実装の学習型アクターは端点にも方程式残差を課し、目標値との最小二乗で折り合う。理想化はこれを無視して
  端点を目標値に一致させている。
- 16分割で見られた緩慢な劣化(最小二乗の解の不定な方向への漂い)は固有値の議論の範囲外で、検証器では
  扱えない。
- 透過境界の指数和の係数は theory/tbc.py のもの(時間範囲0.2、55〜56項)で、実機の25項・係数とは異なる。
- 行和ノルムの十分条件は透過境界を含む構成には適用しない(検証器も「参考値」とする)。
- ゼロ勾配の学習型の端は「鏡映で後退オイラー法」と理想化した(実装は u' = 0 を損失に課す)。

## 5. シミュレータとの照合について(未実施)

dyne-sim は `--wasm` で1種類のアクターしか積めず、格子型と学習型を混ぜた構成は動かせない
(2026-11-08確認。dyne-sim は今回変更していない)。照合には次のどちらかが要る。

- dyne-sim にノードごとのアクター指定(例: `--wasm-node 2=heat1d_pinn_actor.wasm`)を足す。
  界面の受け渡しは格子型・学習型とも同じ「隣の端点の前の時刻の値」なので、ホスト側の変更は
  ノードごとに読み込むモジュールを変えるだけで済む見込み。
- 照合の最初の候補: 学習型|格子型k点|学習型(k = 1, 2, 4)で r を 0.50〜0.65 に掃引し、
  予測 0.6024 / 0.5603 / 0.5285 の前後で判定が変わるか。理想化の効果(表現力のフィルタ)で
  実測の境界が上にずれるかも同時に見られる。

## 6. E4 に向けた次の作業

1. dyne-sim のノードごとのアクター指定(上記)と、混在構成の掃引 → 理論と実測の照合表。
2. 稼働中の組み替え: 1ステップの写像は「どの区画がどの種別か」で決まるので、組み替えの前後で
   別々の行列になる。各構成で r ≤ 1/2 なら行和ノルム ≤ 1 が保たれ、**切り替えの順序によらず誤差の
   最大値は増えない**(行和ノルム ≤ 1 の行列の積も ≤ 1)。固有値の条件(スペクトル半径 < 1)だけでは
   切り替えの列の安定は保証されないので、組み替えを含む保証は行和ノルムで述べるのがよい。
   検証器に「構成の列」を与えて積のノルムを調べる機能を足すのが次の拡張。
   (ただしこれは格子が共通で、組み替えが「各点をどの種別で更新するか」の変更だけの場合。区画の
   引き継ぎで値を写し直す・学習型を温め直す処理が入るなら、その写像も行和ノルム ≤ 1 か確かめる必要がある)
3. 実機16台または32台: 同じ構成を実機で走らせ、シミュレータとの全桁一致で「理論・数値の誤差」と
   「実機・通信の誤差」を切り分ける。
