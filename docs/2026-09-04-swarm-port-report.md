## 1. 何を作ったか

生物の群れの再現デモ(タスク4b)を、Dyneの土台(WASMアクター+ワイヤ形式v2+
仮想ネットワーク+離散イベント)へ移植した。個体の規則はWASMアクターに閉じ、
ホストは環境(温度場・電波の到達・配送・仮想時刻)だけを担う。

### 1.1 crates/swarm-agent-actor(新規、WASMアクター)

- 個体1体ぶんの規則(solo / follow / consensus / gossip の4種)を no_std で実装。
  判断ロジックは参照実装 crates/dyne-swarm の step() と同一の式・同一の分岐。
- 差込口は汎用メッセージバッファ方式(設計書§5)。受信箱・送信箱は固定長、
  メッセージはワイヤ形式v2(POSITION / HEARSAY)そのもの(二重定義の禁止)。
  あふれは破棄+計数(dyne_dropped で累計を返す)。
- 乱数はアクター内蔵の xorshift64*(整数演算のみ)。個体シードはホストが
  derive_seed(大域シード, 個体ID) で導出し dyne_cfg(CFG_SEED_LO/HI)で注入。
  ネイティブテストで dyne-core::rng とのビット一致を照合済み(二重実装の
  ドリフト防止)。
- センサ雑音は個体が内蔵乱数で加える(毎ステップ必ず消費 → 近傍数や
  混沌注入に系列が影響されない)。

エクスポート一覧(確定版。設計書§5に反映済み):

```
swarm_init(id, x, y, t0) -> i32       個体の初期化
dyne_cfg(key, val)                    パラメータ・シード注入(キーは dyne-wire::abi の CFG_*)
swarm_sense(temp)                     知覚+送信箱の作成(temp=自位置の真の温度)
swarm_step()                          受信箱を消費して判断・移動
swarm_x() / swarm_y() -> f64          現在位置(ホストの記録・場計算用)
dyne_msg_buf() / dyne_msg_cap()       転送用スクラッチ領域の位置と容量
dyne_inbox_write(ptr, len) -> i32     ホスト→アクター(0=受理/1=一部あふれ/-1=不正)
dyne_outbox_read(ptr, cap) -> u32     アクター→ホスト(使用バイト数を返す)
dyne_dropped() -> u64                 あふれ破棄の累計
```

### 1.2 dyne-wire::abi(新規モジュール)

dyne_cfg のキー(CFG_MODE〜CFG_SEED_HI)と個体規則の番号(MODE_SOLO〜MODE_GOSSIP)を
crates/dyne-wire/src/abi.rs に一元定義し、ホストとアクターの双方が依存する形にした
(メッセージ形式と同じ「二重定義の禁止」を差込口の定数にも適用。小さな実装判断、事後報告)。

### 1.3 crates/dyne-swarm-sim(新規、ホスト)

- dyne-core(イベントキュー・仮想ネットワーク・乱数)の上に構築。個体数ぶんの
  WASMインスタンスを持ち、温度場(参照実装と同一の式)・近傍決定(半径内の
  近い順k個体)・配送・記録を行う。
- 1ステップ=2位相: 知覚位相(全個体が swarm_sense →送信箱をメッセージ束として
  回収→近傍へ発送)と判断位相(全個体が swarm_step)。仮想時刻で1ステップ=
  --step-ms(既定100ms)、判断は周期の3/4の時点。既定(損失・遅延0)では配送は
  知覚+1µsに完了し、参照実装と同じ情報タイミングになる。遅延がステップの3/4を
  超えた便は次ステップ以降の判断に自然に回る。
- 混沌注入: --loss / --lat-ms / --lat-jitter-ms(dyne-simと同じ流儀)。
- 乱数は3系統に分離: 初期配置(大域シード)、個体内蔵(derive_seed(seed, id))、
  ネットワーク(derive_seed(seed, u64::MAX))。
- 出力は参照実装と同一形式の traj.csv / metrics.csv / field.csv / summary.txt
  (summaryに net 統計行を追加: 発送数・喪失数・アクター側破棄数)。

## 3. 定量帯の検証で判明したこと(限界レポート級の知見)

### 3.1 実測

基準シナリオ(complex場、N=60、半径0.15、k=6、800ステップ)の gossip 到達率:

| シード | 42 | 1 | 2 | 3 |
|---|---|---|---|---|
| 旧(参照実装) | 93.3% | 96.7% | 98.3% | 96.7% |
| 新(本移植) | 63.3% | 98.3% | 78.3% | 56.7% |

新実装は指定4シードで 93〜98% に入らない。原因調査として両実装をシード21本
(42, 1〜20)で比較した:

| | 平均 | 標準偏差 | 中央値 | 90%以上の本数 |
|---|---|---|---|---|
| 旧(参照実装) | 84.5% | 15.6 | 93.3% | 12/21 |
| 新(本移植) | 85.9% | 14.2 | 91.7% | 12/21 |

旧実装自身がシード4〜7で 81.7 / 63.3 / 85.0 / 73.3% を出す(=93〜98%帯は
シード42, 1〜3の「当たり」だった)。両実装の分布は実質同一である。

### 3.2 解釈

- 旧レポート(docs/2026-08-29-swarm-report.md)の「gossip 93〜98%」は、
  たまたま選んだ4シードが全て当たりだった標本の偏り。真の姿は
  「中央値≈92%、ただし2〜3割のシードで群れの一部(主に罠の丘Cへ向かった
  部分集団)が孤立して6割前後に落ちる」二山型の分布。
- 移植で乱数の消費順が構造的に変わる(設計時に合意済み)ため、新実装は
  同じシード番号でも別の実現値を引く。分布が同一である以上、これは移植の
  欠陥ではなく、受け入れ基準の側が標本の偏りの上に設定されていた。
- 判断ロジックは式・分岐とも参照実装と同一に移植してあり、非gossipモードの
  同一シナリオ比較(seed 42)は consensus 58.3%(旧45.0%)、follow 61.7%
  (旧53.3%)、solo 58.3%(旧46.7%)と同水準〜上振れ。

### 3.3 ユーザーに提示する選択肢(基準④の扱い)

- 案a: 基準を「シード21本の平均・中央値・90%以上到達本数が旧実装と同水準
  (例: 平均±5ポイント以内)」に改訂し、本結果をもって合格とする。
  旧レポートの93〜98%表記も注記で訂正する。
- 案b: 分布一致の検定を増やして(シード50本など)から判断する。
- 案c: 指定4シードでの93〜98%を維持し、不合格として原因をさらに追う
  (ただし分布が一致している以上、これは「旧実装の当たりシードを新実装でも
  引き当てるまで乱数の細部を弄る」ことに近く、推奨しない)。

推奨は案a。

→ **決着(2026-09-06、ユーザー指示)**: 案aの方向で基準を「事前固定したシード
50本の分布比較(平均±10pt・中央値±10pt・90%以上到達本数の差8本以内)」に改訂
(設計書§6と改訂履歴に記載)。基準を先に確定してから50本の実験を実行し、
**3条件すべて合格**(§7)。旧レポート docs/2026-08-29-swarm-report.md の
93〜98%記載には訂正注記を追加した(元の記述は残置)。

## 7. 基準④の改訂と再判定(2026-09-06 検収指示2)

### 7.1 改訂した基準(データ取得前に確定)

設計書§6に2026-09-06付で書き込み(改訂履歴に理由を記載)。事前固定したシード
50本(42および1〜49)で新旧両実装を既定シナリオ(complex場、N=60、半径0.15、
k=6、800ステップ、gossip)で実行し、到達率の分布が
(i) 平均の差±10ポイント以内、(ii) 中央値の差±10ポイント以内、
(iii) 90%以上到達したシード本数の差が50本中8本以内、をすべて満たすこと。

注記: 指定の「42および1〜49」は42が1〜49に含まれるため、50実行のうち異なる
シードは49本(42は重複実行で、決定論により同値)。判定は文言どおりの50行と
重複除去後の49本の両方で行った(結論は同一)。

### 7.2 判定結果: 3条件すべて合格

| | 平均 | 中央値 | 標準偏差 | 90%以上の本数 |

| 旧(参照実装) | 85.6% | 93.3% | 14.5 | 28/50 |
| 新(本移植) | 84.5% | 91.7% | 14.7 | 26/50 |

| 条件 | 実測差 | 閾値 | 判定 |
|---|---|---|---|
| (i) 平均 | 1.1ポイント | ±10 | **合格** |
| (ii) 中央値 | 1.6ポイント | ±10 | **合格** |
| (iii) 90%以上の本数 | 2本 | 8本 | **合格** |

(重複除去の49本では: 平均 85.5 vs 84.9、中央値 93.3 vs 91.7、90%以上 27 vs 26。
