# 波動方程式の計算部品の収束次数の確認 — 解析解の定在波との比較(2026-11-16)

> barye リポジトリ(physical-edge-native/barye@760cd20)から移した(2026-11-16、Issue #43)。コマンド名・パスは Dyne での名前に置き換え、Issue 番号は barye のもの(physical-edge-native/barye#N)と明記した。本文の「Barye」は移す前のプロジェクト名。
> 用語: この文書の「区画」は各ノードの担当区間(合意済みの用語の「区画」と同じ)、「境目」は界面(ノードとノードの区画の境目)を指す。

作成: Claude Code(下書き。メンテナーの編集前)。関連: Issue physical-edge-native/barye#9(Convergence-order check of the wave
solvers against analytic solutions)。内部向けの作業記録。

ビット一致(分割しても結果が変わらないこと)は、結果が方程式の正しい解であることまでは示さない。ここでは、
2次元・3次元の波動方程式の計算部品(リープフロッグ法 + 5点・7点のラプラシアン。どちらも空間・時間とも2次の精度の
はず)が、格子を細かくしたときに誤差が h² に比例して減ることを、解析解との比較で確かめる。

## 1. 問題と測り方

- 2次元: 単位正方形、外周は値固定 0、解析解 `u = sin(πx)·sin(πy)·cos(ωt)`、`ω = cπ√2`。
- 3次元: 単位立方体、外周は値固定 0、解析解 `u = sin(πx)·sin(πy)·sin(πz)·cos(ωt)`、`ω = cπ√3`。
- c = 1、格子の間隔 h = 1/(N−1)(N は1辺の点の数)、**クーラン数 ν = cΔt/h = 0.5 で固定**(3次元の安定条件
  1/√3 ≈ 0.577 の内側)。初速度 0(計算部品の最初のステップは初速度 0 を前提にしている)。
- 時刻 T = 0.5 で比べる。ステップ数は `round(T/Δt)`(この設定では N−1)、解析解は実際に進めた時刻
  `ステップ数·Δt` で計算する。sin(ωT) が 0 に近い時刻(誤差の主要項が消えて次数が見かけ上上がる)を避けた:
  2次元で sin(ωT) ≈ 0.80、3次元で ≈ 0.41。
- 誤差: 全格子点(外周を含む)での `e = 数値解 − 解析解` の最大値ノルム `max|e|` と、
  離散 L2 ノルム `sqrt(h^d · Σ e²)`(d は次元。連続の L2 ノルムの近似)。
- 解析解の値は純 Rust の数学ライブラリ libm で計算する(どの OS でも同じビット)。数値解は単一区画で解く
  (分割しても同じビットであることは別のテストで確かめている)。
- 格子: 2次元 N = 17, 33, 65, 129, 257。3次元 N = 9, 17, 33, 65。
- 観測した次数: 隣り合う2つの格子の比 `p = log(e_粗 / e_細) / log(h_粗 / h_細)` と、log e を log h に対して
  最小二乗で直線に当てはめた傾き。

## 2. 合格の幅とその根拠(確認の前に書いた)

**合格の条件: 判定に使う格子(2次元 N ≥ 17 のすべて、3次元 N ≥ 17 のすべて)について、隣り合う格子の
組ごとの次数と、最小二乗の傾きが、最大値ノルム・L2 ノルムの両方で [1.9, 2.1] に入ること。**
3次元の N = 9 は表には載せるが、判定には使わない。

根拠:

1. **誤差の主要項の見積もり**。値固定 0 の正方形・立方体の正弦の定在波は、離散ラプラシアンの固有ベクトル
   そのものなので、空間の形の誤差はなく、誤差は振動の位相のずれだけになる。離散の振動数 ω_h は
   `cos(ω_h Δt) = 1 − 2ν² Σ_d sin²(k_d h/2)`(k_d = π)から決まり、展開すると
   `ω_h = ω(1 + δ)`、`δ = h²(ν²K⁴ − Σk_d⁴)/(24K²) + O(h⁴)`(K² = Σk_d²)。
   ν = 0.5 で δ ≈ −0.206h²(2次元)、−0.103h²(3次元)。誤差は
   `e ≈ −sin(ωT)·ωT·δ · (正弦の積)` なので、最大値ノルム(中央の点、N が奇数なので正弦の積がちょうど 1)は
   約 **0.363 h²(2次元)、0.114 h²(3次元)** と見積もられる。L2 ノルムは、離散の和 `h·Σ sin²(πih) = 1/2` が
   ちょうど成り立つので、最大値ノルムの (1/2)^{d/2} 倍(2次元 1/2、3次元 約 0.354)。
2. **h² からのずれの大きさ**。次の項は (a) δ の O(h⁴) の項(相対的に約 (πh)²/10 程度)、(b) 位相のずれの2次の項
   (相対的に `ωT·|δ|·|cos ωT|/(2|sin ωT|)`)。h = 1/16 で (a) は約 0.004、(b) は 2次元で約 0.0007、3次元で約 0.0011。
   次数のずれは log₂(1 + 相対的なずれ) 程度なので 0.01 以下と見込む。h = 1/8(3次元の N = 9)ではこれが約4倍に
   なるので、判定から外した(見込みでも幅の内側だが、判定に使う範囲は漸近的な範囲に限るという方針のため)。
3. **丸め誤差**。最も細かい格子でも誤差は 2次元で約 5.5×10⁻⁶(h = 1/256)、3次元で約 2.8×10⁻⁵(h = 1/64)で、
   丸め誤差の積み重ね(ステップ数 × 10⁻¹⁶ 程度、10⁻¹³ 以下)より何桁も大きい。丸めが次数を乱すことはない。
4. **幅 ±0.1 の意味**。上の見込み(0.01 以下)の10倍の余裕を取った。一方で、1次の誤差(例えば最初のステップの
   式の誤り、境界の1点ずれ)なら次数は 1 付近になり、幅の外に大きく外れるので見逃さない。

## 3. 結果

再現: `cargo run --release --bin dyne-native-wave2d -- convergence`、`cargo run --release --bin dyne-native-wave3d -- convergence`。
「次数」の列は1つ粗い格子との比から求めた値。「fit」の行は判定に使った格子での最小二乗の傾き。

### 3.3 読み取り

1. 観測した次数は 2 から最大 0.005(判定に使う範囲)、表示のみの 3次元 N = 9→17 でも 0.017 しかずれず、
   §2 の見込み(h ≤ 1/16 で 0.01 以下、h = 1/8 でその約4倍)と合う。合格の幅 ±0.1 は十分に広い。
2. 誤差の定数(最大値の誤差 / h²)は、2次元 0.3634〜0.3643、3次元 0.1143〜0.1161 で、§2 で位相のずれから見積もった
   **0.363(2次元)と 0.114(3次元)にほぼ一致**した。誤差がほぼすべて離散の振動数のずれから来ていることの確認になる。
3. L2 ノルムの誤差は最大値ノルムのちょうど 1/2(2次元)、約 0.354 倍(3次元)で、§2 の見込みどおり(空間の形の誤差がない)。
   このため、2つのノルムの次数は表示した桁で同じになる。
4. この確認は正弦の定在波・値固定の境界に限る。ゼロ勾配・吸収境界、ガウス型の山のような多くの波数を含む初期値の
   精度は確かめていない(吸収境界は1次の条件なので、反射の量は別の確認が要る)。

小さな実装判断(エージェントが決めたもの):

1. 確認の計算は、テストと道具の両方から使えるようにライブラリのモジュール(`convergence.rs`)に置き、道具には
   新しい動作 `convergence` を足した(新しいプログラムは作らない)。
2. 誤差は外周の点も含めた全格子点で測る(外周は値 0 に固定で、解析解は丸めで約 10⁻¹⁶。影響はない)。
3. ステップ数は `round(T/Δt)` とし、解析解は実際に進めた時刻 `ステップ数·Δt` で計算する(T/Δt が整数でない
   設定でも、時刻のずれを誤差に混ぜないため)。
4. 実行時間: リリース版で2次元・3次元あわせて 0.1 秒未満、デバッグ版のテストでも数秒以内(CI の3つの OS で問題のない大きさ)。
