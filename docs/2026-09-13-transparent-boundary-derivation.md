# 半無限透過境界(候補d)の導出と数値検証(docs\2026-09-13-transparent-boundary-derivation.md)

作成日: 2026-09-13。境界条件整理(2026-09-06提案、F1向け)の追補資料。
未観測領域との境界を「境界近傍と同じ材質が無限に続く」と想定して閉じる
**半無限透過境界**の理論根拠・実装方式・数値検証を記録する。

## 1. 浸透深さ √(αt)

- 次元解析: 熱方程式 ∂u/∂t = α ∂²u/∂x² の物理定数は α [m²/s] のみ。
  時間 t と組んで作れる長さは √(αt) だけであり、拡散のあらゆる長さスケールは
  係数を除きこれに一致する。
- 確率論的裏付け: 拡散はランダムウォークの連続極限で、変位の2乗平均は
  ⟨x²⟩ = 2αt。典型到達距離は √t で伸びる。

## 2. 階段応答の厳密解と時間減衰Robin係数

半無限媒質 x > 0、初期温度 0、境界温度を t=0 に U₀ へ階段的に上げる問題
(Carslaw & Jaeger の古典問題)の厳密解:

    u(x,t) = U₀ · erfc( x / (2√(αt)) )

erfc'(z) = −(2/√π)e^{−z²} を用いて境界勾配を評価すると

    −∂u/∂x |₀ = U₀ / √(παt)

Robin形式(流束 = β × 境界温度)で読むと

    β(t) = 1/√(παt),  実効熱抵抗 1/β = √(παt)

すなわち抵抗が浸透深さと同じ速さで成長する。t→0 で Dirichlet(u=0)側、
t→∞ で断熱端側へ漸近し、両極端の嘘を物理法則に沿って補間する。

## 3. 一般の温度履歴への拡張(厳密な透過境界)

境界温度が任意の履歴 g(t) の場合、ラプラス変換で
û(x,s) = ĝ(s)·e^{−x√(s/α)}(有界解)より

    −û_x(0,s) = √(s/α) · ĝ(s)

√s は時間域の 1/2 階微分に対応し、逆変換すると

    −u_x(0,t) = (1/√(πα)) ∫₀ᵗ g'(τ) / √(t−τ) dτ

これが半無限媒質の厳密な Dirichlet-to-Neumann 写像(透過境界条件)。
時間非局所(過去の履歴の畳み込み)であり、g が階段関数のとき §2 に帰着する。
必要な入力は**自ノードの境界温度の履歴のみ**——隣の観測・割当表・未観測領域の
長さ L はいずれも不要(ノード局所で閉じる)。
参考文献系: Carslaw & Jaeger; 人工境界条件法(Han–Huang, Givoli)。

## 4. 1/√t 核の指数和近似

畳み込みの素朴な実装は毎ステップ O(履歴長)。回避の鍵は厳密な積分表示

    1/√t = (1/√π) ∫₀^∞ λ^{−1/2} e^{−λt} dλ

(核は指数関数の連続重ね合わせ)。λ = e^{2x} と変換して対数軸の台形則で
離散化すると、節点 λ_j = e^{2x_j}、重み w_j = (2/√π)·h·e^{x_j} により

    1/√t ≈ Σ_{j=1}^{M} w_j e^{−λ_j t}   (t ∈ [Δt, T] で一様)

- 下限が Δt でよい点が重要: 離散スキームは Δt 未満の時刻差の核を評価しない
  ため、t→0 の特異性の近似は不要。
- 必要項数は M = O(log(1/ε)·log(T/Δt))。最適化された構成
  (Beylkin–Monzón の指数和近似、Jiang–Greengard の熱ポテンシャル高速評価、
  López-Fernández–Schädle の等高線積分法)は同精度をより少ない項数で達成する。

## 5. 補助変数の漸化式(実装形)

指数関数の半群性 e^{−λ(a+b)} = e^{−λa}e^{−λb} により、補助変数

    y_j(t) = ∫₀ᵗ e^{−λ_j(t−τ)} dg(τ)

は直前値と当ステップの境界温度変化 Δg のみで更新できる:

    y_j^{n+1} = e^{−λ_j Δt} · y_j^n + e^{−λ_j Δt/2} · Δg^n
    流束^n ≈ (1/√(πα)) Σ_j w_j y_j^n

(中点補正 e^{−λ_jΔt/2} は当ステップ内の変化を区間中央で数える近似。)
直感: 忘却率 λ_j の異なる「漏れバケツ」M 個の分業で √t 型の長い記憶を演じる。
速い λ が直近を、遅い λ が遠い過去を担当する。

## 6. 数値検証(基準設定 Δt = 1e-4、2000 ステップ、T = 0.2)

核近似の項数と精度(対数台形則、素朴な構成):

| 刻み h | 項数 M | 相対誤差(最大) |
|---|---|---|
| 1.0 | 20 | 2.0e-2 |
| 0.8 | 24 | 5.9e-3 |
| 0.6 | 32 | 7.7e-4 |
| 0.4 | 48 | 3.9e-5 |
| 0.3 | 64 | 3.1e-5 |

漸化式の検証: g(t) = sin(20t) に対し、全履歴を舐める直接畳み込みと
M=48 の漸化式を比較し、**相対差(最大)9.1e-6 で一致**。
演算量: 直接 O(n²) ≈ 2.0e6 回相当に対し漸化式 O(nM) = 9.6e4 回。
メモリ: 境界1つあたり float × M 個。

結論: 実用精度(0.1〜1%)なら M ≈ 20〜30、高精度でも数十個。
「補助変数を数個」という当初の見積もりは楽観的で、**正しくは十数〜数十個**
(2026-09-13 訂正)。M は時間範囲に対して対数的にしか増えない。

## 7. 適用上の仮定と限界

- 仮定1(材質の連続): 境界の先に観測領域と同じ拡散係数の媒質が続く。
- 仮定2(初期状態): 発動時点で外側の温度が境界近傍と同程度から始まる
  (外側が最初から極端に熱い/冷たい場合の情報は履歴からは得られない)。
- §3 は厳密なので、準静的近似(β=1/L Robin が必要とした「ゆっくり」の仮定)は
  不要。速い過渡にも理論的に有効。
- BSP の論理ステップ同期と両立。学習型ノードでは流束目標として損失に
  組み込める形。

## 付録: 検証スクリプト(要点)

```python
import numpy as np
dt, T = 1e-4, 0.2

def soe(h, c1, c2):                      # 指数和の節点と重み
    xlo = 0.5*np.log(1/(c1*T)); xhi = 0.5*np.log(c2/dt)
    xs = np.arange(xlo, xhi, h)
    return np.exp(2*xs), (2/np.sqrt(np.pi))*h*np.exp(xs)

lam, w = soe(0.4, 1e9, 2e4)              # M=48
n = 2000
g  = np.sin(20*np.arange(0, n+1)*dt)     # 境界温度の履歴(検証用)
dg = np.diff(g)

F_direct = np.zeros(n)                   # 直接畳み込み O(n^2)
for k in range(1, n+1):
    ages = (k - np.arange(k) - 0.5)*dt
    F_direct[k-1] = np.sum(dg[:k]/np.sqrt(ages))

y = np.zeros(len(lam)); F_rec = np.zeros(n)   # 漸化式 O(nM)
decay, half = np.exp(-lam*dt), np.exp(-lam*0.5*dt)
for k in range(n):
    y = decay*y + half*dg[k]
    F_rec[k] = np.sum(w*y)
# max|F_rec - F_direct| / max|F_direct| = 9.1e-6
```
