## 1. 系のモデル(抽象化)

- **群**: 物理空間の領域Ωを重複なしにN分割し、各部分領域Ω_iを1つの
  **アクター**(独立した計算主体。小さなNNまたは古典数値解法)が担当する。
- **界面**: 隣接する担当領域の境目。アクターは毎ステップ、界面ごとに少数の
  境界量(現行: 端点の値と勾配)を隣とだけ交換する。大域的な情報共有・中央の
  調整者は存在しない。
- **動的オペレータ**: 実行中の群に適用できる操作。
  ADD(新領域と担当アクターの参加)/REMOVE(離脱)/GROW(アクターのNNの幅を
  拡大)/SHRINK(縮小)。適用時の評価軸は「乱れ(直後の誤差の跳ね)」
  「回復時間」「コスト」。
- **アクター抽象**: 差込口(初期化・1歩進む・境界量の出し入れ・状態の読み書き)は
  全アクター共通で、中身(数値解法かNNか、NNの構造)は問われない。

## 2. 確立事項の実験的裏付け(理論ノートE1〜E5の原典)

- **E2(GROWの機能保存)**: 幅8→16に拡大する際、新ニューロンの出力側の重みを
  0で初期化すると、NNの表す関数は構成的に厳密不変。実測でも拡大前後の
  全評価点の出力が**ビット単位で一致**した。
- **E3(場の標本=知識の通貨)**: アクターの可搬状態を「担当領域の格子点上の
  物理量の標本」に限定すると、構造の異なるモデル間(数値解法↔NN、幅違いの
  NN間)で状態を移送できる。移送→別実体で再開、が中断なし実行とビット一致
  することを実測済み(数値解法アクター)。
- **E4(交換可能性)**: 同一の差込口の背後で、数値解法アクターとNNアクターの
  差し替えが通信・プロトコル変更ゼロで成立(N=1〜8で同水準の精度)。
- **E5(残差駆動適応)**: 界面残差(界面両側の勾配の食い違い)を各ノードが
  局所監視し、移動ベースライン比の閾値超過で隣接ノードをGROWさせる自動
  トリガーが動作(平常時の誤発火ゼロ、ADDイベント時のみ発火、発火後15ステップ
  以内に収束)。

## 3. 群れ実験の事実(予想A6の原典。2026-08-29実施)

- 設定: 2次元温度場。構成要素は、最適スポット3つ(合計で面積の2.1%)、
  **局所最適の丘**(温度が最適に近いが真の最適ではない、個体を引き寄せて
  留めてしまう領域。実験報告では俗称「罠の丘」)、**低温の帯**(温度が低く
  群れの移動経路を分断する領域。俗称「冷たい谷」)。以下、俗称は使わない。個体N=60を全域に一様ランダム散布。各個体は**自位置の
  温度(雑音つき)と、半径内の近い順k=6個体からのメッセージだけ**を知覚できる
  (場の式・最適位置・他個体一覧は参照不可能なことをコード構造で保証)。
- 共有情報を段階的に増やした4規則の比較(800ステップ、シード42):

| 規則 | 最適域内の割合 | 平均|T−T_opt| | 90%到達 |
|---|---|---|---|
| solo(通信なし) | 46.7% | 3.12℃ | 未到達 |
| follow(温度共有) | 53.3% | 1.97℃ | 未到達 |
| consensus(勾配の合意) | 45.0% | 2.15℃ | 未到達 |
| **gossip(合意+最良地点の伝聞)** | **93.3%** | 0.85℃ | 346ステップ |

- 別シードでもgossip 96.7/98.3/96.7%(90%到達178〜229ステップ)、
  consensus 53〜70%。伝聞(良い場所の又聞きを隣から隣へ多段に運ぶ。
  古い伝聞は破棄)の追加だけが、局所最適の丘と低温の帯を越える性能差を生んだ。
- 通信なしでも45〜58%到達するのは、800ステップの乱歩が面積2.1%の
  最適域に達しうるため(ベースラインとして重要)。

## 4. 関連する先行研究の要点(リサーチ済み)

- **AB-PINNs**(2025-26): 学習中に部分領域を動的に変形・追加(残差の大きい
  場所へ)。単一計算機・学習時のみ。追加時の乱れを観察するが**定量指標なし**。
  新部分領域は乱数初期化(重み引き継ぎなし)。
- **ADD-PINN**(2026): 残差誘導の分割+親→子の重み引き継ぎ(親の予測値を
  教師に約200エポックの出力合わせ)。オフライン2段階。「分割すべきでない
  問題では分割を抑制」のネガティブコントロールあり。
- **Multi-Scale DT+PINN**(2026): デジタルツイン応用。中央のサーバ(A100)で
  学習2.5時間。幅64≒幅256の精度、tanh必須という小型化の知見。
- 共通の空白: **分散した機器・実行中・資源制約つき**の再構成は未踏。
- Physical AI文脈: 全域自己注意型モデルは空間分割が原理的に困難。
  座標入力型(PINN/INR)は定義域分割が可能——群が担うのは「空間側の知能」。

## 5. この壁打ちで扱いたい未解決問題(予想A1〜A8の背景)

- **A1 GROWの学習動力学**: 機能保存でも最適化の軌道は変わる(0初期化の
  新パラメータが勾配流に入る)。収束が速くなる/悪化する条件は。
  対称性の破れ・初期化理論・NTK的な視点で何が言えるか。
- **A2 部位分散の状態空間削減**: ロボットを部位ごとのモデル+界面(力・位置・
  トルク交換)に分けると学習が容易になるという仮説の定式化。分散制御・
  階層制御・モジュール型強化学習の既存理論との接続。
- **A3 群の集合的地図**: 各個体の局所知覚(将来: 周囲n×n)を界面整合で
  つなぎ、群全体として一貫した場の推定を得る条件。分散推定・センサー
  フュージョン・分散カルマンフィルタの理論との接続。
- **A4 SHRINKの損失上限**: 縮小後の誤差増は縮小後の幅の最良近似誤差で
  下から抑えられ、温め(自分の縮小前予測を教師にした再学習)はそこまで
  回復させるか。近似理論(幅と表現力)で評価できるか。
- **A5 異種混在**: 数値解法アクターとNNアクターの混在クラスタの一貫性。
- **A6 局所知覚群の創発**: 3章の実験(特にgossipの決定的優位)を、群知能・
  合意形成・伝聞プロトコルの理論で定式化できるか。「伝聞が効く条件」
  (罠の構造、伝聞の鮮度管理、kと半径)の理論化。
- **A7 分割の尺度則**: N分割で1ノードの計算量・メモリ・電力が~1/N、学習の
  条件数も改善、という尺度則の定式化(計算量側は数値解析の会話と重複可)。
- **A8 符号つき距離関数による形状アクター**: 座標→最寄り壁面距離のNN表現は
  定義域分割・界面整合(距離値+法線)と両立するか。複数ノードの測距の融合。

## 6. 学習の地図(キャッチアップすべき既存理論)

機能保存変換(Net2Net系)と成長するNN / NNの初期化と対称性の破れ・
学習動力学(NTK視点を含む) / 普遍近似と幅・深さの表現力(A4) /
Mixture-of-Experts(空間的な専門家分割との類推と相違) /
分散推定・センサーフュージョン・分散カルマンフィルタ(A3) /
gossipプロトコルと合意形成の理論(収束速度、情報の鮮度)(A6) /
群知能(boids以降)と創発の定量化 / モジュール型・階層型強化学習、
分散制御(A2) / split computing・連合学習(何が違うかの整理用)。

## 7. 用語対応と注意

アクター=部分領域担当の計算主体(標準語では特になし。agentに近いが
強化学習のagentとは別物) / 界面=subdomain interface / 温め=warm start /
乱れ・回復時間=イベント直後の誤差スパイクと減衰時間(本プロジェクト定義) /
伝聞=gossip protocol。
