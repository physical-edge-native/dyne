## 0. 全体の地図(1枚で)

1. 出発点は熱方程式。格子に区切って「1ステップでどう値を更新するか」の式にする(第1節)。
2. 計算が壊れるかどうかは「誤差が増えるかどうか」で決まる。誤差は行列 G を掛けることで1ステップ進む(第2節)。
3. 誤差が増えないことを示す道具は2つ。
   - **固有値(スペクトル半径)**: G を何回も掛けたときの長期の振る舞いが分かる(第3節)。
   - **行和ノルム**: 「各行の係数の絶対値の和が1以下なら、最大値は増えない」。一度も増えないことまで言える(第4節)。
4. これで示したこと:
   - 差分法は r ≤ 1/2 で安定(第3・4節)。境界条件を変えても同じ(第5節)。
   - 後退オイラー法の形(学習型を1台で動かす場合)は r によらず安定(第6節)。
   - 学習型を分割すると境目に安定限界が現れ、理想化すると r = (7 − √17)/4 ≈ 0.719(第7節)。
   - 観測値の取り込み(ナッジング)は r ≤ 1/2 かつ 0 ≤ γ ≤ 2 なら誤差を増やさない(第9節。定理)。
   - (新)差分法と学習型を混ぜても、r ≤ 1/2 なら誤差の最大値は増えない(第10節)。

記号: u(x, t) は温度、α は熱の伝わりやすさ(熱拡散率)、h は格子の間隔、Δt は時間刻み。
**r = αΔt/h²** が全体を通して主役になる量(時間刻みが格子に対してどれだけ大きいかの指標)。

## 1. 出発点の式: 熱方程式を格子の更新式にする

熱方程式は

  ∂u/∂t = α ∂²u/∂x²

区間 [0, 1] を間隔 h の格子点 x_j = jh に区切り、時刻も Δt ごとに区切る。u_j^m を「格子点 j、
m ステップ目の温度」とする。

**2階微分の近似(テイラー展開から)**: u(x + h) と u(x − h) をテイラー展開して足すと、
1階と3階の項が打ち消し合い

  u(x + h) + u(x − h) = 2u(x) + h² u''(x) + O(h⁴)

よって u''(x) ≈ (u_{j−1} − 2u_j + u_{j+1}) / h²(誤差は h² に比例 = 2次精度)。

**時間の近似(前進オイラー法)**: ∂u/∂t ≈ (u^{m+1} − u^m)/Δt。2つを代入して整理すると

  **u_j^{m+1} = u_j^m + r (u_{j−1}^m − 2u_j^m + u_{j+1}^m)**   …(★)

これが差分法の担当計算機が毎ステップ行う計算。右辺は**前の時刻の値だけ**なので「陽的」という。
並べ替えると u_j^{m+1} = r·u_{j−1} + (1 − 2r)·u_j + r·u_{j+1}、つまり両隣と自分の重み付きの和。

**分割しても全桁一致する理由**: (★) は自分と両隣の前の値だけで決まる。区間を分けても、境目の計算機が
隣から前の値を1つ受け取れば、1台で計算するときとまったく同じ式・同じ順序で同じ数を計算する。
だから浮動小数点の丸めまで同じになり、ビット単位で一致する(数学の定理ではなく、演算の手順が同一であることによる)。

---

## 2. 安定とは何か: 誤差の更新式

(★) は u について線形(足し算と定数倍だけ)。正しい解 u* も同じ式に従うとすると、誤差 e = u − u* も

  e^{m+1} = G e^m

に従う。G は「(★) を全格子点まとめて書いた行列」で、内部の各行が (… , r, 1 − 2r, r, …) の三重対角行列。
両端の温度を0に固定すると、両端の行は (1 − 2r, r) のように片側が欠ける。

**安定 = G を何回掛けても誤差が増えない**こと。m ステップ後の誤差は G^m e^0 なので、G^m が大きくならないかを調べればよい。

---

## 3. 道具1: 固有値とスペクトル半径

### 3.1 なぜ固有値を見るのか

G の固有ベクトル v(Gv = λv)に G を何回掛けても、λ 倍されるだけ: G^m v = λ^m v。
誤差を固有ベクトルの和に分解すれば、各成分は λ^m 倍になる。したがって

  **すべての固有値の絶対値(の最大 = スペクトル半径 ρ(G))が1以下なら、長期的に増えない。1を超える固有値が1つでもあれば、その成分が指数的に増える。**

(注: 固有値がちょうど1で重なる場合などは、途中の一時的な増大までは固有値だけでは分からない。それは第4節の道具で補う。)

### 3.2 熱方程式の G の固有値を実際に求める

成分が sin(jθ)(θ = kπh、k = 1, 2, …)のベクトルを試す。三角関数の加法定理

  sin((j−1)θ) + sin((j+1)θ) = 2 cos θ · sin(jθ)

を使うと、(★) の右辺の括弧の中は

  sin((j−1)θ) − 2 sin(jθ) + sin((j+1)θ) = (2cos θ − 2) sin(jθ) = −4 sin²(θ/2) · sin(jθ)

となり、元のベクトルの定数倍に戻る。両端 sin(0) = sin(π k) = 0 で温度0の条件も満たす。よって固有値は

  **λ_k = 1 − 4r sin²(kπh/2)**

これは連続の世界の「sin(kπx) が e^{−α(kπ)²t} で減衰する」(変数分離法)の、格子版にあたる。

### 3.3 r ≤ 1/2 が出てくる

sin² は 0 と 1 の間なので、λ_k は区間 [1 − 4r, 1] に入る。|λ_k| ≤ 1 となるには 1 − 4r ≥ −1、つまり

  **r ≤ 1/2**

いちばん危ないのは k が最大の成分(sin² ≈ 1)で、そのベクトルは隣り合う格子点で符号が交互に変わる**鋸歯状**の形。
r > 1/2 だと λ < −1 となり、この鋸歯が**1ステップごとに符号を反転しながら大きくなる**。
差分法が壊れるとき解がギザギザに振動するのはこのため。

### 3.4 固有値を直接計算できないとき

学習型や透過境界のように G を式で書き下しにくい場合でも、「i 番目だけ1のベクトルを1ステップ進めた結果を
i 列目に並べる」と G が作れる(1ステップの計算が線形なら)。あとは数値計算で固有値を求め、ρ(G) = 1 になる r を
二分法で探す。0.719 や透過境界の限界はこの方法で得た数値を、式でも確かめたもの。

## 4. 道具2: 行和ノルム(最大値が増えないことの直接の証明)

**定義**: ベクトルの最大値ノルム ‖e‖∞ = max_j |e_j|。行列の行和ノルム ‖M‖∞ = 「各行の成分の絶対値の和」の最大。

**性質(三角不等式から1行で出る)**:

  |(Me)_i| = |Σ_j M_ij e_j| ≤ Σ_j |M_ij| · max|e_j| ≤ ‖M‖∞ ‖e‖∞

よって ‖Me‖∞ ≤ ‖M‖∞ ‖e‖∞。さらに積についても ‖MN‖∞ ≤ ‖M‖∞‖N‖∞。

**熱方程式に使う**: G の内部の行は (r, 1 − 2r, r)。**r ≤ 1/2 なら3つとも0以上**なので、絶対値の和は
r + (1 − 2r) + r = 1。端の行は 1 − r ≤ 1。よって ‖G‖∞ ≤ 1 で、誤差の最大値は**一度も増えない**。

固有値の議論より強い(途中の一時的な増大もない)うえに、固有値を計算しなくてよい。
直感的には「新しい値は、前の値の重みが0以上で合計1以下の平均」なので、最大値を超えようがない。

**ゲルシュゴリンの定理**(同じ考えの固有値版): 固有値は、各行について「対角成分を中心、残りの成分の絶対値の和を半径」
とする円のどれかに入る。G では中心 1 − 2r・半径 2r の円なので、固有値は [1 − 4r, 1] に入る(第3.3節と同じ結論)。
対称でない行列や、端の行を変えた行列にもそのまま使えるのが利点。

---

## 5. 境界条件を変えても r ≤ 1/2 は変わらない

計算機を置いていない区間との境目の扱いを変えると、G の**端の行だけ**が変わる。

| 境界条件 | 端の行 | 係数の和 | 結論 |
|---|---|---|---|
| 温度0固定 | (1 − 2r, r) | 1 − r | ≤ 1 |
| 断熱(外側に内側の値を鏡に映して置く) | (1 − 2r, 2r) | 1 | ≤ 1 |

どちらも r ≤ 1/2 なら係数は0以上で和は1以下 → 第4節の議論がそのまま通る。

- 断熱では固有値にちょうど1が現れ、その固有ベクトルは一様な温度(総熱量が保存され、平均値で平らになる)。
- **線形外挿**(外側に端と内側1点の延長を置く)は、端の括弧の中が恒等的に0になり、端の値が永久に動かない
  (凍結)。だから採用しなかった。
- 透過境界は過去の履歴を覚える補助変数が加わるので、第4節の行和の議論はそのままでは使えない。補助変数込みの
  行列の固有値を数値で計算し、採用した方式(半陰的)の限界が 0.500 で r ≤ 1/2 を狭めないことを確かめた
  (他の方式では 0.319、0.438 に狭まる)。

## 6. 後退オイラー法: 学習型の計算機を1台で動かすと r によらず安定

学習型の計算機は、新しい時刻の温度分布をニューラルネットワークで表し、

  (新しい分布 − 前の分布)/Δt − α × (新しい分布の2階微分)

が0に近づくように学習する。2階微分を**新しい**分布で評価しているので、これは**後退オイラー法**

  u_j^{m+1} − r(u_{j−1}^{m+1} − 2u_j^{m+1} + u_{j+1}^{m+1}) = u_j^m

と同じ形(新しい値どうしの連立方程式 = 陰的)。行列で書くと (I − rL)u^{m+1} = u^m(L は (1, −2, 1) の行列)、
固有ベクトルは第3.2節と同じ sin で、固有値は

  1 / (1 + 4r sin²(kπh/2))

分母が1以上なので、**どの r でも0と1の間** → 無条件に安定。さらに細かい成分(sin² ≈ 1)ほど強く消す。
(仮定: 学習が毎ステップ十分に収束すること。実験でも1台なら r = 2.0 まで安定だった。)

## 7. 学習型を分割すると安定限界が現れる: 0.719 の導出

### 7.1 なぜ陽的な部分が入るのか

区間全体を後退オイラー法で解くと、新しい値が全区間で連立し、計算機どうしが1ステップの中で何度も通信して
連立方程式を一緒に解く必要がある。それを避けるため、**境目の格子点だけは前進オイラー法(★)で目標値を作り**、
内部はその値を端の値として後退オイラー法で解く。「内部は陰的、境目だけ陽的」の混合構造になる。

### 7.2 理想化

1. 学習が毎ステップ完全に収束する。 2. ネットワークは格子点のどんな値の並びも表せる。
この仮定で1ステップは線形写像になり、行列 G が作れる。数値で ρ(G) を計算すると、2〜8分割で限界 r ≈ 0.7192。

### 7.3 式で求める(等比数列の仮定と2次方程式)

不安定な成分は境目に集まり、境目の両側で逆符号だった(数値計算で確認)。そこで1つの境目に注目し、
境目の右側の点を位置0、内側へ 1, 2, … と番号を付け、

  右側の位置 m の値 = a·μ^m(|μ| < 1 で内側へ減衰する等比数列)、左側は同じ大きさで逆符号

と仮定する。1ステップで全体が g 倍(g = 固有値)になるとする。

- **境目の点(前進オイラー法)**: 左隣 −a、自分 a、右隣 aμ を (★) に入れて
  g = 1 − 3r + rμ   …(1)
- **内部の点(後退オイラー法)**: 新しい値は g 倍されているので、両辺を aμ^m で割ると
  g[(1 + 2r) − r(μ + 1/μ)] = 1   …(2)

安定の境目は g = −1(鋸歯が符号反転しながらちょうど増えも減りもしない)。
(1) に g = −1 を入れると μ = 3 − 2/r。(2) に入れて整理すると μ = r/(4 − r)。2つを等しいと置くと

  r/(4 − r) = (3r − 2)/r  →  r² = (3r − 2)(4 − r)  →  **2r² − 7r + 4 = 0**

  **r = (7 − √17)/4 ≈ 0.7192**(もう一方の解は |μ| > 1 で不適)

このとき μ ≈ 0.219(内側へ1点進むごとに約1/5)。境目から2〜3点で消えるので、各計算機の内部点が数点あれば
分割数によらず限界はほぼ一定。16分割では内部点が2点しかなく 0.7073 に下がり、32分割では全点が陽的になって
前進オイラー法そのものの 0.5 に一致する。

### 7.4 実測とのずれ(予想を含む部分)

実験の発散の境界は理論より上(4分割で 1.0〜1.5、8分割で 0.8〜1.0)。ネットワークの幅を広げると下がってくる。
「小さなネットワークは鋭い鋸歯を表現しきれず、不安定な成分を勝手に削っている」という解釈だが、**未確認**。
16分割だけに出るゆっくりした誤差の増大は、この理論(固有値)の範囲外で、仕組みは未解明。

## 8. 発散した計算から増幅率を読む(べき乗法)

行列を何度も掛けると、絶対値最大の固有値の成分だけが生き残る(べき乗法)。シミュレーションそのものが
べき乗法になっているので、

- 発散直前の誤差の形 = 最大の固有値の固有ベクトル(鋸歯がどこに集まっているか)
- 1ステップあたりの拡大率 ≈ スペクトル半径。誤差の対数のグラフの傾きから exp(傾き) で読む。

これで、式で書けない学習型の1ステップについても、理論の予測(ρ と不安定の形)を実験と照合できる。

## 9. 観測値の取り込み(ナッジング)の定理

観測点で、計算値 u を観測値 y へ割合 γ で引き寄せる: u ← u + γ(y − u)。誤差で書くと観測点の誤差が (1 − γ) 倍される。
観測点だけ1の対角行列を P とすると、誤差の更新は

  e^{m+1} = (I − γP) G e^m + (観測の雑音の項)

**定理**: r ≤ 1/2 かつ 0 ≤ γ ≤ 2 なら、観測点の数・位置・観測の周期によらず、誤差の最大値は増えない。

**証明**: 第4節の積の性質を使う。‖G‖∞ ≤ 1(第4節)。I − γP は対角行列で、成分は 1 または 1 − γ。
0 ≤ γ ≤ 2 なら |1 − γ| ≤ 1 なので ‖I − γP‖∞ ≤ 1。よって ‖(I − γP)G‖∞ ≤ 1·1 = 1。■

- γ = 2 は改善できない境界(全点を観測すると、γ がわずかでも2を超えれば不安定)。
- γ > 2 では観測点の配置に依存し、固有値を数値で計算して境界を出した(r = 1/3 付近で最も高く約7.5、
  r → 1/2 で 3.41)。実験の60通りすべてと、予測が分かれる2通りの判別実験で、固有値の予測どおりだった。
- r = 1/3 で境界が最も高くなる理由(更新式が3点の単純平均になる)は直感的な説明で、証明はしていない。

## 10. (2026-11-08 の新しい結果)差分法と学習型を混ぜた構成

出典: docs/2026-11-08-stability-checker.md、theory/guarantee/。第7.2節と同じ理想化を置いた**理論の予測で、
シミュレータ・実機とはまだ照合していない**。

### 10.1 十分条件: r ≤ 1/2 なら、どう混ぜても誤差の最大値は増えない

1ステップの計算は、次の2段に分けられる。

1. **陽的な点**(差分法の区画の全点と、学習型の区画の境目の点): (★) で前の値から計算。r ≤ 1/2 なら
   係数は0以上・和は1以下(第4節)。
2. **学習型の区画の内部**: 1 で決まった境目の新しい値を端の値として、後退オイラー法の連立方程式
   B u_内部 = u_内部^前 + r·(境目の新しい値) を解く。B は対角が 1 + 2r、隣が −r の行列。

鍵になる事実(線形代数): B は**対角成分が正、それ以外が0以下で、各行で対角が他の絶対値の和より大きい**
(対角優位)。このような行列の逆行列は、**成分がすべて0以上**になる(M行列の性質。証明の筋: B = (1 + 2r)(I − N)
と書くと N の成分は0以上で ‖N‖∞ < 1 なので、(I − N)^{−1} = I + N + N² + … が収束し、各項が0以上)。
さらに、全部1のベクトルに対して B·(1, …, 1) を計算すると、右辺の「前の値 + r·境目の値」がちょうど釣り合う
(定数の温度分布は後退オイラー法でそのまま保たれる)。

したがって内部の新しい値は「前の値と境目の新しい値の、0以上の重みで合計1の組み合わせ」になる。
1段目も「前の値の0以上・合計1以下の組み合わせ」なので、2段を合わせても、新しい値はすべて**前の値の
0以上・合計1以下の重み付き平均**。よって最大値は増えない(第4節と同じ理屈)。

- 混ぜ方・区画の大きさ・分割数によらない。ナッジング(0 ≤ γ ≤ 2)を加えても成り立つ(第9節と同じ積の議論)。
- 透過境界を含む構成は対象外(補助変数があるため)。
- 稼働中の組み替え(計算部品の入れ替え)の保証にも使える見込み: どの構成も ‖·‖∞ ≤ 1 なら、その積も ≤ 1 なので、
  切り替えの順序によらない。ただし格子が共通で、値の写し直しが入らない場合に限る(未検証)。

### 10.2 r > 1/2 側の限界(固有値の数値計算)

| 構成(65点、端は温度0) | 限界 r |
|---|---|
| 差分法 \| 学習型 | 0.5011 |
| 差分法 \| 学習型 \| 差分法 | 0.5024 |
| 交互に16区画 | 0.5281 |
| 学習型だけを分割(参考) | 0.7192 |

差分法の区画が1つでもあれば限界はほぼ 1/2 で、不安定な成分は差分法の区画に乗る。0.719 が効くのは
学習型だけの構成。

### 10.3 学習型に挟んだ小さな差分法の区画は限界が上がる

差分法の区画が k 点のとき: k = 1, 2, 4, 8, 16 で限界は 0.602, 0.560, 0.529, 0.511, 0.504。
両隣の後退オイラー法が、差分法の区画の鋸歯を外側から抑えるため、と解釈できる。k = 1 は第7.3節と同じ
等比数列の仮定で閉じた式になり(式は docs/2026-11-08-stability-checker.md)、r ≈ 0.6024 で数値と一致する。
**シミュレータで最初に照合する候補**(k = 1, 2, 4 で r を 0.50〜0.65 に振る)。

### 10.4 (2026-11-25 追加)学習が残差を残すときの誤差の上限(証明済み)

出典: GitHub issue #159、theory/guarantee/residual_bound.py。第10.1節は「学習が毎ステップ厳密に収束する」
理想化を置いていた。実際の学習型の計算機は、毎ステップ小さな残差を残す。その場合の上限を示す。

- **設定**: Φ を理想化した1ステップ(差分法の点は陽的、学習型の区画の内部は後退オイラー法を厳密に解く)とし、
  実際の計算を u(t) = Φ·u(t−1) + ρ(t) と書く。ρ(t) は**1ステップのずれ**(学習型が出した値と、同じ前の値から
  厳密に1ステップ進めた値の差)。厳密な列は v(t) = Φ·v(t−1)。
- **主張**: ‖Φ‖∞ ≤ 1(第10.1節。r ≤ 1/2、温度固定・ゼロ勾配の端、0 ≤ γ ≤ 2 のナッジングを含む)で、
  毎ステップ ‖ρ(t)‖∞ ≤ δ なら、‖u(n) − v(n)‖∞ ≤ ‖u(0) − v(0)‖∞ + n·δ
  (一般には δ の代わりに実際のずれの和 Σ‖ρ(t)‖∞)。
- **証明**: u(t) − v(t) = Φ·(u(t−1) − v(t−1)) + ρ(t) なので、誤差の最大値は1ステップで高々 ‖ρ(t)‖∞ しか増えない。
  帰納法で足し合わせる。
- **ずれと学習の残差の関係**: 学習型の区画の内部では、厳密な値 w* は B·w* = b、計算した値は B·w = b + q
  (q は格子点での後退オイラー法の残差)を満たす。よって w − w* = B⁻¹·q。B の各行は対角が他の和より
  ちょうど 1 大きいので ‖B⁻¹‖∞ ≤ 1。区画の端で目標値として取る点は、そのずれがそのまま加わる。
  よって ‖ρ(t)‖∞ ≤(端のずれの最大)+ ‖q‖∞。
- **これ以上は改善できない**: ゼロ勾配の端では Φ が一定の温度分布を保つので、全点に +δ のずれが毎ステップ
  入ると誤差はちょうど n·δ になる。**誤差が残差の足し算より速くは増えない**ことを言うもので、
  **誤差が小さいままでいる**ことは言わない。
- **確かめたこと**(scripts/ci-check.sh の23番目):
  - 理想化した写像で、混ぜ方5通り × r = 0.1, 0.3, 0.5 について ‖Φ‖∞ ≤ 1 を確かめ、200ステップ、大きさ δ 以下の
    ずれ(乱数・一定)で上限を超えないこと。一定のずれ(学習型1区画、ゼロ勾配、r = 0.5)で上限に届くこと
    (0.2031 対 0.2097。差は初めの誤差のうち減衰した分)。
  - シミュレータ(dyne-sim)で学習型の計算部品(heat1d-pinn-actor)を1台(17点、温度固定の端、r = 0.0256)で
    39ステップ動かし、同じ初期の場から始めた厳密な後退オイラー法の列との差が、測った1ステップのずれの和の
    範囲に収まること(0.037 対 0.153)。各ステップのずれが「端のずれ + 格子点の残差」以下であること。
- **まだ**: 学習型を複数台にした構成のシミュレータでの照合(シミュレータの境目の点の扱いと理想化の写像の対応が
  未確認)、波動方程式、透過境界。

## 12. 用語の対応(発表・論文で使うときの一般的な呼び名)

- 担当計算機・区画 → 領域分割(domain decomposition)の部分領域
- 前進オイラー法 / 後退オイラー法 → explicit / implicit Euler(陽解法 / 陰解法)
- スペクトル半径 → spectral radius。行和ノルム → ∞ノルム(maximum row sum norm)
- 「係数が0以上で和が1以下」→ 離散最大値原理(discrete maximum principle)、単調スキーム
- 逆行列の成分が0以上の行列 → M行列(M-matrix)
- ナッジング → データ同化の最も単純な方法(Newtonian relaxation)
- 学習型の計算機 → 物理情報ニューラルネットワーク(PINN)を時間刻みごとに解く方式
