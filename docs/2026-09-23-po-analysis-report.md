# 部分観測比較runの追加分析(周期・トレンド分解+同化なし対照) レポート (docs\2026-09-23-po-analysis-report.md)

2026-09-23実施。数値計算の理論側の提案を受けた、部分観測比較run
(docs/2026-09-22-n7-verify-exp1-po-report.md §B)の追加分析。
(1)=既存リハーサルデータの再解析、(2)のみ新規実行。

## 1. 周期・トレンド分解 — 両キーの差は**周期成分に集中していない**(トレンド成分に集中)

**分解方法(実装側で設計)**: 保留ノードのイノベーション時系列 d(t) を最小二乗で

  d(t) ≈ a + b·t + A·sin(2πt/T) + B·cos(2πt/T) (T=駆動周期600s)

の4パラメータに当てはめ、水準a+b·t̄・傾きb(トレンド)、√(A²+B²)(周期成分振幅)、
残り(残差RMS)に分ける。外部依存なし(4x4正規方程式のガウス消去)、
scripts/exp1_report.py の `--decompose`(--period/--step-dt/--compare)として実装。
`--compare` は2本のCSVの差 d₁−d₂ を分解する——**同一シードなら観測ノイズ y が
両runで同一のため相殺され、差は純粋なモデル差 u₂−u₁ になる**(ノイズフリー)。

結果(γ=0.3、保留node 1、warmup 200除外、n=180):

| 系列 | 水準 | 傾き[/1000s] | 周期成分振幅 | 残差RMS |
|---|---|---|---|---|
| zero_grad の d | −0.743 | −0.215 | 0.435 | 0.302 |
| transparent の d | −0.673 | −0.121 | 0.436 | 0.302 |
| **差 d_zg − d_tr** | **−0.070** | **−0.094** | **0.001** | 0.003 |

- **提案の問いへの答え: 差は周期成分に集中していない**。両キーの周期成分振幅は
  同一(0.435/0.436)で、差の周期成分は0.001と実質ゼロ。**差は水準・傾き
  (トレンド成分)に乗る**(transparentの方が水準・ドリフトとも小さい=§2の
  全体窓で差が開く観測と整合)。
- 差の残差RMS 0.003 はノイズ相殺の確認(設計どおり同一シードでyが共通)。
- 副所見: 周期成分振幅は3run(γ=0対照含む)とも約0.42で、**真値振動の
  node 1 観測点での振幅(amp·x/L = 1×0.39)にほぼ一致**。つまりこの設定
  (γ=0.3・観測周期10)では、モデルは周期駆動をどのキーでもほぼ追跡できて
  おらず、イノベーションの周期成分=未吸収の駆動そのもの。

## 2. 同化なし対照run(γ=0) — 両キーの差は**消滅**(縮む/逆転ではなくゼロ)

シミュレータは γ=0 を assert で拒否していたため、**--truth-grad 併用時のみ γ=0
(観測の記録のみ・適用なし)を許す最小改修**を実施(既定動作は不変、基本16ノード
回帰の標準出力が旧バイナリとバイト一致であることを再確認)。

同構成(--absent 0・保留node 1・γ=0)で zero_grad / transparent 各1run:

- **両キーのイノベーションCSVがバイト単位で同一**(cmp一致)。理由は幾何:
  一様初期値24℃+同化なしでは熱方程式の場が**厳密に定数のまま動かず**
  (勾配ゼロの場は拡散しない)、境界条件キーの適用結果に差が生じない。
  → γ=0.3 のときの差(全体窓 0.47 vs 0.43)は**すべて同化を経由して生じる**。
- **警告的所見**: γ=0 の定数場(=「モデルなし床」)の保留誤差は mean 0.515
  (比0.34)で、**γ=0.3 の 0.710/0.657(比0.47/0.43)より小さい**。この合成場
  では、暖側(node 2,3)の観測に引きずられて保留点の場が実際より暖まる
  (水準−0.7=場が観測より0.7℃高い)ため。実機解析では対照runを「床」として
  比較runの成績がこれを上回るかを必ず確認する(手順書に反映済み)。
