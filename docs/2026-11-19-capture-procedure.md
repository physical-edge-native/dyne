## 1. 何を撮るか

### 1.1 実験ごとに必ず撮るもの

| 番号 | 中身 | 撮り方 |
|---|---|---|
| P1 | 機材の全体(ノードの置き場所が分かる部屋の全景) | 部屋の角から、全ノードが入る広角で 1 枚。同じ位置から §1.2 の比較用も撮る |
| P2 | ノード 1 台の寄り(配線・センサ・サーボ・台) | 1 台につき 1 枚。配線の色が読めること |
| P3 | PC の画面: ノードの一覧(status が online) | 画面の写し(Win+Shift+S)。写真ではなく画面の写しにする |
| P4 | PC の画面: ツインのダッシュボード(room.html)・結果の表示(PASS の行など) | 画面の写し |
| P5 | 書き出したもの(room.usda を開いた画面、OpenFOAM・Isaac Sim に取り込んだ画面) | 画面の写し |

### 1.2 実際の部屋とツインを見比べる組(必須)

実際の部屋と、そこから作ったツインが**同じ向きで見比べられる**組を残す。発表と README の中心になる。

1. 部屋の **真上に近い位置**から全景を 1 枚撮る(脚立か、立って腕を上げて)。真上が無理なら、部屋の角から斜めに。
   撮った位置(どの角か、床からの高さ)をメモする。
2. 同じ時刻のツインの画面を写す:
   - 上から見た図: ダッシュボード(room.html)の部屋の形の図。部屋の写真と北・南(長い壁)の向きをそろえる
   - 斜めから見た図: room.usda を USD の表示の道具(usdview、Isaac Sim、Blender のどれか)で開き、
     1. の写真と**同じ角・同じ高さ**から見た視点にして写す
3. 寸法の目印を写す: 床にメジャーを伸ばして写真に入れ、ツインの画面にも同じ長さ(例: 長い壁の 3.6 m)が読める
   表示(格子の目盛り、または測った寸法の注記)を入れる。
4. 物を置いて形が変わる実験をするときは、置く前と置いた後の**両方**で 1.〜3. を撮る(実際の変化とツインの変化の対応が見える)。

ファイル名は同じ番号で組にする(§2 の `pair01-real.jpg` と `pair01-twin-top.png`・`pair01-twin-persp.png`)。

### 1.3 ノード 1 台が抜けたとき・戻ったとき(録画を推奨)

**今の実装でできること(正直に書く)**: 実機では、抜けたノードの仕事をほかのノードが引き継いで計算を続ける
「自己修復」はまだ無い。いまあるのは次の 3 つ:

- **検出と報告**: 抜けたノードの status が offline(遺言、MQTT の LWT)になる。波動の計算では、隣のノードが
  「この界面が来ない」を 10 秒ごとに報告し、止まって待つ(docs/2026-11-16-wave2d-cluster-runbook.md §4.4)。
- **ツインが最後の形を保つ**: 部屋の形のツインでは、PC はノードごとに最後に届いた区画を持ち続けるので、
  1 台が抜けても形は消えない。latest/status.json の perNode の ageS(最終受信からの秒数)が伸びていく。
- **復帰**: 電源を入れ直すと online に戻り、測距の区画がまた届き始める。波動の計算は、全台を再起動して
  からやり直す(GitHub issue #86 が直るまで)。

計算を続けたまま参加・離脱する仕組み(状態の移送)は、シミュレータでだけ確かめている(docs/STATUS.md の
M-S1a、`--handover`)。撮影のメモと発表では「検出・保持・復帰」と書き、「自己修復」と書かない。

撮るもの(スマートフォンの動画と、PC の画面の録画を**同時に**。PC は Win+Alt+R の録画、または OBS):

| 番号 | 場面 | 映すもの |
|---|---|---|
| V1 | 部屋の形のツインで、測距ノード 1 台の電源(USB)を抜く → 約 30 秒 → 挿し直す | 手元(抜く・挿す)、ノードの一覧の status(online → offline → online)、ダッシュボードの形が消えないこと、status.json の最終受信の時間 |
| V2 | 波動の 2×2 の実行中に 1 台の電源を切る(runbook §4.4)→ 電源を入れる | 手元、PC の STALL の行(10 秒ごと)、offline → online。その後の全台の再起動と、やり直しの PASS の行まで |

録画の始めに、時刻が分かる画面(PC の時計)を数秒映す。抜いた時刻・挿した時刻をメモする(記録の events.jsonl と
突き合わせるため)。

## 2. ファイル名

```
<日付>_<場所>_<実験>_<番号>[-<補足>].<拡張子>
例: 20261120_A_range6_P1.jpg
    20261120_A_range6_pair01-real.jpg
    20261120_A_range6_pair01-twin-top.png
    20261120_A_range6_pair01-twin-persp.png
    20261120_A_range6_V1-phone.mp4 / 20261120_A_range6_V1-screen.mp4
    20261120_A_wave2x2_V2-screen.mp4
```

- 場所: `A` または `B`
- 実験: `range6`(測距 6 台と部屋の形)、`wave2x2` / `wave4x2` / `wave4x4`、`imu`、`replay`、`openfoam`、`isaac`
- 1 つの実験のフォルダ(`<日付>_<場所>_<実験>\`)に入れ、同じフォルダに `notes.txt`(撮った位置、抜いた・挿した時刻、
  気づいたこと)を置く

## 3. 置き場所と手順

1. 撮影の当日は、PC のリポジトリの外の作業フォルダ(例: `Desktop\captures\`)に集める。
2. 場所 A: その日のうちに dyne-private の `slides/captures/<日付>_A_<実験>\` へ移す。公開リポジトリには入れない。
3. 場所 B: §4 の確認を通ったものだけを、公開リポジトリの `docs/demo/captures/` に入れる(Issue を立て、
   ブランチ・プルリクエストで。大きな動画はリポジトリに入れず、リリースの添付か外部の置き場所にする)。
   通らなかったもの・未確認のものは dyne-private に置く。

## 4. 公開の前の確認(場所 B、すべての写真・画面)

1 枚ずつ、拡大して見る。

- [ ] 人の顔・体が写っていない(写っていれば外すか、ぼかす)
- [ ] 住所・表札・郵便物・宅配の伝票・窓の外の景色(場所が分かるもの)が写っていない
- [ ] 私物(書類、写真、薬、画面に出ている通知)が写っていない
- [ ] PC の画面の写しに、Wi-Fi の SSID・パスワード、MAC アドレス、メールアドレス、ユーザー名の入ったパス、
      ほかのアプリの通知が出ていない(MAC は CLAUDE.md の規則で仮の値にする。写しなら写す前に窓を閉じる)
- [ ] 写真の付加情報(Exif の位置情報)を消した(スマートフォンの共有で「位置情報を含めない」、または
      PC で消す)
- [ ] 会社名・取引先の名前・他人の機器の名前が写っていない
