## 1. 基本の問題設定

- 対象: 1次元熱伝導方程式 ∂u/∂t = α ∂²u/∂x²、区間[0,1]、両端 u=0(Dirichlet)、
  初期条件 u(x,0)=sin(πx)。解析解は sin(πx)e^{−απ²t}。
- 基準の離散化: 格子65点(間隔h=1/64)、時間刻みΔt=1e-4、2000ステップ。
  空間2次中心差分+前進オイラー(陽解法): u_i^{n+1} = u_i^n + r(u_{i-1}^n − 2u_i^n + u_{i+1}^n)、
  r = αΔt/h²。安定条件 r ≤ 1/2(フォン・ノイマン解析)。
- 領域分割: 重複なしでN個の区間に分け、各区間を独立の計算主体(以下ノード)が
  担当。界面(区間の境目)では毎ステップ、**端点の値と片側差分の勾配**を
  隣接ノードと交換する。各ノードは受け取った隣の端点値をゴースト点として
  上記と同一の更新式に用いる。
- 重要な事実: この構成では分割解が非分割解と**ビット単位で一致**する
  (同一の演算列・順序になるため。N=2,16、通信の喪失・遅延・一時分断を
  注入しても、同期が論理ステップで固定されているため不変)。

## 2. 学習型ノード(領域分解PINNの変種)の定式化

一部または全部のノードを、差分法の代わりに小さなNNで置き換える。

- **時刻離散化(Rothe法)**: 時間を先にΔt刻みにし、各時刻の空間分布 u^n(x) を
  NN(1入力x→1出力u、隠れ1層×幅16、tanh、パラメータ49個)で表す。
- **1ステップの学習**: 前ステップの分布 u_prev を保持し、**後退オイラー型の残差**
  R(x) = [u_θ(x) − u_prev(x)]/Δt − α u_θ''(x) を残差評価点(既定は担当区間の格子点。
  オプションで格子中点も追加=sub=2)で評価、二乗和を損失とする。
- **界面条件(iface=1、現行既定)**: 自分の端点の「次の時刻の値」を、差分法と
  同一の陽的更新式(ゴースト点=隣の端点値を使用)で先に計算し、その値への
  一致を損失に加える。※初版(iface=0: ゴースト点の値そのものにNN出力を
  合わせる)は多ノードで誤差が時間蓄積し、350倍悪化した(時間整合性の問題)。
- **最適化**: Levenberg–Marquardt法(パラメータ49個の非線形最小二乗)、
  1ステップあたり5反復。初期化時のみ温め(20〜30反復で損失1e-9以下)。
  一次法(Adam/SGD)は u'' 項の硬さで収束せず不採用だった。
- **機能保存の拡張(GROW)**: 幅を8→16に増やす際、新ニューロンの出力側重みを
  0で初期化すると、NNの表す関数は厳密に不変(全格子点でビット一致を実測)。

## 3. 実験事実(理論が説明・予測すべきデータ)

- 精度(2000ステップ後の最大誤差、解析解比、iface=1):
  N=1: 2.5e-4 / N=2: 3.3e-4 / N=4: 6.1e-5 / N=8: 8.4e-5(差分法水準)
  / **N=16: 2.1e-2(約100倍悪化)**。N=16では1ノードの格子点が4〜5個
  (パラメータ49に対し残差評価点4〜5)。
- **残差評価点を中点追加で倍にする(sub=2)とN=16の劣化は解消**(2.1e-2→3.1e-5)。
  **sub=4(4分割)は逆に悪化**——原因未解明。
- ノード参加(ADD)イベント: 参加領域は不連続な初期値で始まる設定のとき、
  界面残差(両側の片側勾配の差)が平常値の66倍に跳ね、9〜14ステップで
  平常値の2倍以下へ回復、完全な落ち着きは67ステップ後。乱れは参加界面の
  近傍に留まり、遠方の既存界面はほぼ平坦(局所性)。
- 今後の変更予定: (1) 不在の隣に対する境界を u=0 固定から**外挿境界**
  (ゼロ勾配 or 線形外挿)へ、(2) 同期を「全員が同一ステップを待ち合わせる方式
  (BSP)」から**有界非同期**(隣の最新値が古ければ外挿して使い、待たない)へ。

## 4. この壁打ちで扱いたい未解決問題(理論ノートの予想の背景)

- **N1**: iface=1(差分法式で端点目標を作る)の下で、各ステップの最適化が
  不完全(有限反復・有限表現力)でも、誤差がステップ間・ノード間で増幅しない
  条件は何か。8ノードまでの実験は安定、16ノードの劣化は情報不足(評価点数)で
  説明された。ノード間の誤差伝播を「界面を介した反復」とみなす解析が可能か。
- **N3/sub=4問題**: 評価点を増やすほど良いはずが4分割で悪化する。最小二乗の
  重み付け・条件数・エイリアシングの観点で説明できるか。
- **N4**: 有界非同期(遅れdステップまでの隣の値を外挿して使用)の安定条件。
  遅延つき差分方程式の安定性、非同期反復(Chazan–Miranker)、
  Schwarz waveform relaxation あたりが足場になるはず。
- **N7**: 学習型ノードの「安定領域」。1ステップ写像(u_prev → u_θ)の摂動増幅率を
  どう定義・評価するか。
- **N8**: 分割数をさらに増やす(32,64)と、局所の評価点追加で解消しない劣化
  (大域情報の欠如による)が現れるか。領域分解法の「粗い空間」理論との関係。
  ただし**全域を見る中央主体は導入しない**制約下で考える(対策は物理の伝播に
  委ねるか、隣から隣への多段の情報共有に限る)。
- **A7(参考、モデル側)**: N分割による1ノードの計算量・メモリ・学習の
  条件数の改善を尺度則として定式化できるか。

## 5. 学習の地図(新しい会話でキャッチアップすべき既存理論)

フォン・ノイマン安定性解析と絶対安定領域 / Laxの同値定理 /
領域分解法の基礎(交互・加法Schwarz、重複なしの部分構造法:
Dirichlet–Neumann、Neumann–Neumann、Robin交換=最適化Schwarz) /
2レベル法と粗い空間(なぜNとともに収束が劣化するか) /
Schwarz waveform relaxation(時空間の領域分解。毎ステップ交換との関係) /
分割スキーム・共シミュレーションの安定性(陽的結合の安定条件) /
非同期反復の収束理論(Chazan–Miranker以降) / 遅延差分方程式の安定性。

## 6. 用語対応(プロジェクト語 → 標準語)

界面 = subdomain interface / 界面残差 = 両側の片側勾配の食い違い(flux jumpの
離散版) / ゴースト点 = ghost/halo point / 温め = warm start(前解への当てはめ) /
乱れ・回復時間 = イベント直後の誤差スパイクとその減衰時間(本プロジェクトが
独自に定義した評価軸) / BSP = bulk synchronous parallel(ステップ待ち合わせ)。
