# 形の変化への追従: 古い観測を忘れる仕組み(シミュレータ段、2026-11-11)

対象: 2週間計画(docs/2026-11-11-two-week-plan.md)の S5「形の変化への追従」、実験6「稼働中に段ボール箱を
動かし、形が数秒で追従して古い位置の跡が消える」、足りないもの G6「古い観測を忘れる仕組み」。
実機の前に、シミュレータ(dyne-sim2d)と形の格子型アクター(sdf2d-grid-actor)で確かめた。

## 0. 要約

- 今の統合のしかたでも、光線が通り抜けた空きの格子点は更新されるので、**古い位置の跡はいずれ消える**。
  ただし重みの上限 w_max = 50 のままだと、跡が消えるまで 2.8 秒、新しい位置が出そろうまで 4.9 秒かかる
  (センサ8個・15Hz・雑音 8mm・16ノード)。さらに、**どの光線も届かなくなった古い値**(新しい位置の箱の
  内側に残る「以前は空きだった」点、雑音で光線の先端だけが一度触れた孤立した点)は**いつまでも消えない**。
- アクターに3つの設定を足した(既定ではどれも働かず、従来とビット単位で同じ出力): 重みの減衰、
  重みの小さくなった点の忘却、新しい観測との食い違いの検出。
- 推奨の組み合わせ(**食い違いの閾値 0.1m + 減衰 0.9 + 忘却 0.3**)で、追従の時間は雑音 8〜40mm の
  どれでも **0.67 秒**(うち 0.47 秒は 16ノードの統合の遅れ)、静止した壁の誤差は既定とほぼ同じ
  (平均 7.0 → 7.6mm)、箱の内側の残りの跡も約3秒で消える。
- 分割解と単一ノード解のビット一致: 掃引の 48 実行と、損失・遅延・一時停止・分断を入れた 4 実行で、
  新しい設定を入れた状態ですべて PASS (bit-exact)。既定の設定では既存の出力 11 本がバイト一致。

## 1. 問題

実験6では、稼働中に段ボール箱を目印Aから目印Bへ動かす。求めることは2つ:

1. **新しい位置の形がすぐ出る**(データ同化(観測を取り込んで推定を更新し続けること)として、
   刻一刻と変わる形に追いつく)。
2. **古い位置の跡が消える**(「前にあった箱」が形と USD(3次元の場面記述の形式)に残らない)。

## 2. 今の統合のしかたで何が起きるか

### 2.1 仕組み(設計書 docs/2026-10-10-shape-grid-actor-design.md §1.2〜1.4)

各格子点は、切り詰め符号つき距離(TSDF: 表面の近く ±μ の帯の中だけで距離を持つ表し方)の値 d と、
統合の重み w を持つ。光線1本ごとに、原点から「測った距離 + μ」までの格子点へ、観測値
d_obs = clamp(r − 投影位置, −μ, +μ) を重み1で加える(重み付き平均)。w は w_max で頭打ち。

**表面の手前の格子点には d_obs = +μ(空き)が入る**ので、「光線が通り抜けた点を空きとして刻む」働きは
もともとある。箱を動かすと、古い位置を通っていた光線は奥の壁まで届くようになり、古い位置の点に
+μ が入り続ける。

### 2.2 どのくらいで変わるか(理論)

w が上限 W に張り付いた点では、新しい観測1回ごとに古い値との差が W/(W+1) 倍に縮む。

- 跡が消える(箱の表面のすぐ裏、d = −μ の点が正に変わる)まで: n ≈ ln2 / ln(1+1/W) ≈ 0.69 W フレーム
- 新しい表面が出る(空き d = +μ だった点のうち、表面から h 奥の点が負に変わる)まで:
  n ≈ ln4 / ln(1+1/W) ≈ 1.39 W フレーム

| W(重みの上限) | 跡が消えるまで | 新しい表面が出るまで | 雑音の残り(1回の観測に対する標準偏差の比、√(1/(2W+1))) |
|---|---|---|---|
| 50(既定) | 35 フレーム = 2.3 秒 | 70 フレーム = 4.7 秒 | 0.10 |
| 20 | 0.95 秒 | 1.9 秒 | 0.16 |
| 10 | 0.48 秒 | 0.97 秒 | 0.22 |
| 5 | 0.25 秒 | 0.51 秒 | 0.30 |

(15Hz = 1フレーム 1/15 秒。これに統合の遅れ L ステップが足される。16ノード(4×4)では L = 7 = 0.47 秒)

### 2.3 光線の刻みでは消せないもの

光線が届かない点は、観測が入らないので**古い値のまま残る**。実測で次の2種類を確かめた
(図: demo_out/dynamic_shape/follow_timeseries.png の青い線の、3秒以降に残る約8個)。

1. **新しい位置の箱の内側**: 移動前は光線が通って「空き(+μ、w=50)」になっていた点が、箱が来ると
   箱の前の面から μ より奥になり、どの光線も届かなくなる。裏側の帯(負)と古い空き(正)の間に、
   箱の内側に偽の表面ができ続ける。既定では最後まで 8 個の通過点が残った。
2. **雑音で光線の先端だけが触れた孤立した点**: 雑音 40mm では、「測った距離 + μ」の先端が雑音で
   伸びたときだけ触れる点に負の値が残り(w = 3 など)、二度と更新されない。古い位置の付近に残った
   ため、重みの上限を下げても食い違いの検出を入れても、跡が消えなかった(表3の「∞」)。

加えて、**新しい位置が古い位置を影にする**(移動先がセンサと古い位置の間)場合も、古い位置に
光線が届かないので同じく残る(今回の配置ではほかのセンサから見えていたため、個別には試していない)。

## 3. 足した仕組みと選んだ理由

アクターの設定(dyne_cfg のキー。dyne-wire の abi::sdf2d に追加)とシミュレータの引数:

| 設定 | キー | 引数 | 既定(=働かない) | 働き |
|---|---|---|---|---|
| 重みの減衰 λ | CFG_DECAY = 14 | --decay | 1 | 毎ステップ全格子点で w ← λ·w。見え続ける点は w ≈ 1/(1−λ) で釣り合う |
| 忘却の閾値 | CFG_W_FORGET = 15 | --w-forget | 0 | 減衰後の w がこれ未満の点を未観測(w = 0, d = 0)に戻す |
| 食い違いの閾値 τ | CFG_DISAGREE = 16 | --disagree | 0 | 統合のとき |d_obs − d| > τ なら、統合済みの重みを下の値まで下げてから加える |
| 食い違いのときに残す重み | CFG_DISAGREE_W = 17 | --disagree-w | 1 | 1 なら新旧を半々に混ぜる |

候補4つ(重みの上限を下げる、重みの減衰、光線に沿った空きの刻み、食い違いでの重みの引き下げ)の比較:

- **光線に沿った空きの刻み**は §2.1 のとおり既にある。足りないのはその「速さ」と「届かない点」。
- **重みの上限を下げる**だけでも速くなるが(w_max = 10 で 1.4 秒)、速さが上限に比例して決まるので、
  速くするほど全点の平均が弱くなる。また §2.3 の届かない点は消えない。
- **食い違いの検出**は、矛盾する観測が来た点だけ重みを下げるので、変わった所だけが速く変わり、
  変わっていない所は w_max = 50 の平均をそのまま使える。追従は「統合の遅れ + 約3フレーム」で、
  上限の値に依らない。弱点は、雑音が τ の半分を超えると静止した壁でも誤って働くこと(τ = 0.05m・
  雑音 40mm で静止した壁の誤差が 15.1 → 19.6mm に悪化。τ = 0.1m なら悪化なし)。
- **重みの減衰と忘却**は、観測の来ない点を時間とともに「分からない」に戻すので、§2.3 の届かない点を
  消せる唯一の候補。見え続ける点にとっては重みの上限 1/(1−λ) と同じ働き。

そこで、**速さは食い違いの検出で、届かない点の後始末は減衰と忘却で**受け持つ組み合わせを推奨する。

### 3.1 実装(どれも格子点ごとに閉じた計算・順序固定なので、ビット一致は保たれる)

- 1ステップの中の順序: 距離の反復 → 受け取った光線の取り込み → **重みの減衰と忘却** → 統合
  (設計書 §1.5 の 2 と 3 の間に1手順足した)。減衰はどのノードも自分の区画の全点に同じ式を当てるだけ。
- 食い違いは統合の中で判定する(統合済みの d と比べる。w を下げるだけで上げない)。
- 既定の設定では、減衰の処理は入口で戻り、食い違いの判定も行わないので、既定の計算は従来と同じ命令列。

### 3.2 誤設定の防止(小さな実装判断)

最初の掃引で「減衰 0.9 + 忘却の閾値 1」を試したところ、1回だけ観測した点(w = 1)が次のステップの統合の
前に 0.9 < 1 で忘れられ、**全点が w = 1 から育たない**(平均が効かない)ことが分かった(静止した壁の
誤差 9.3/35.7mm、既定は 7.0/29.8mm)。忘却の閾値は λ 未満でなければならない。アクターの初期化
(dyne_init2d)で、λ < 1 かつ 忘却の閾値 ≥ λ の設定を拒む(戻り値 −2)ようにした。

## 4. 実験の条件(シミュレータ)

- 場面: crates/dyne-sim2d/scenes/room6_move.txt(新規)。room6.txt と同じ6畳の部屋と家具(机・ベッド・
  本棚)。**測距付きのノード8台(1台に1個)**、床近くから部屋の中を向く(位置と向きは仮。実験4の手測りで
  置き換える)。段ボール箱(40×30cm)を 300 ステップ(20秒)目に目印A (0.9,1.0)-(1.3,1.3) から
  目印B (1.7,1.5)-(2.1,1.8) へ瞬間移動。room6_carry.txt は、持ち上げて(測距の面から消える)2秒運んで置く変種。
- 場面ファイルの書式の追加: `movebox 名前 x0 y0 x1 y1 [高さ]`、`move 名前 ステップ x0 y0 x1 y1`、
  `move 名前 ステップ off`。正解の形状(採点)も同じステップで切り替わる。
- センサ: VL53L5CX(距離センサ)の 8×8・15Hz を想定。使うのは1行 8区画、水平の視野 45°、
  雑音の標準偏差 8mm(評価記録 docs/2026-10-11-vl53l5cx-eval-log.md の 5.8〜7.9mm から)。悲観側として
  20mm・40mm も試した(区画の円錐が箱の縁にかかったときの中間の値などを、大きな雑音で代わりに見る)。
- 1ステップ = 1フレーム(--step-ms 66.667)。分割 4×4 = 16ノード(統合の遅れ L = 7 ステップ)。
  格子の刻み h = 5cm、切り詰め幅 μ = 15cm(既定)。600 ステップ。

### 4.1 採点(--track-csv。単一ノード解を毎ステップ、その時刻の正解の形状と比べる)

- 推定した表面 = φ のゼロ等値線(表示の scripts/twin_demo.py と同じく、観測済み w>0 で |φ|<2μ の
  隣り合う2点の間で符号が変わる所)の通過点。
- **幻の表面**: 正解の表面から 2h(10cm)より遠い通過点。**古い位置の跡**: そのうち箱の今でない位置から
  μ 以内のもの。
- **跡が消えるまで t_clear**: 移動から、古い位置の跡が最後に 0 になるまで。
- **新しい位置が出るまで t_appear**: 置いてから、箱の今の位置の表面の覆い率(間隔 h の標本点のうち、
  h 以内に通過点があるもの)が、最後の 50 ステップの平均の8割以上を保つようになるまで。
- **追従の時間** = max(t_clear, t_appear)。
- **静止した壁・家具の誤差**: 箱のどの位置からも 2h より遠い通過点の、正解の表面までの距離。移動前
  (200〜299 ステップ)の平均値の平均と 95%点の平均。
- 掃引: scripts/dynamic_shape_sweep.py(新規)。出力は demo_out/dynamic_shape/(git 管理外):
  summary.csv、各実行の track_*.csv、follow_timeseries.png、sweep_log.txt。

## 6. 実験6に推奨するパラメータ

| 設定 | 値 | 理由 |
|---|---|---|
| w_max | 50(既定のまま) | 変わっていない所の平均は強いままにする |
| 食い違いの閾値 τ | 0.1 m(= 2h、μ の 2/3) | 雑音 40mm まで静止した壁で誤って働かない。0.05 は雑音 40mm で悪化 |
| 食い違いのときに残す重み | 1 | 新旧を半々に混ぜる(1フレームの外れ値だけでは表面が飛ばない) |
| 減衰 λ | 0.9(1ステップ = 1/15 秒のとき) | 箱の内側の残りの跡が約3秒で消える。0.95 では約7秒 |
| 忘却の閾値 | 0.3 | λ 未満であること(§3.2)。見え続ける点(w ≈ 10)は約2.2秒見えなくなると「分からない」に戻る |

- λ はステップごとの値なので、実機のステップの周期がフレームの周期(1/15 秒)と違うときは、
  同じ秒数で忘れるよう λ_実機 = 0.9^(15 / ステップの周波数) に換算する。
- 統合の遅れ L はノード数で決まる(4×4 で 7 ステップ)。実機でステップがフレームより速ければ、遅れの秒数は縮む。

## 8. ノードのメモリと計算への影響

- 格子点ごとの状態は増えない(d・w・φ のまま)。設定値 4 個(f64、計32バイト)が増えるだけ。
  光線やメッセージの形式は変わらない(界面で運ぶ量も同じ)。
- 計算: 減衰は毎ステップ・区画の全点で掛け算1回と比較1回。16ノードなら1ノード約 250 点(73×55 / 16)。
  食い違いは統合する標本点ごとに引き算・絶対値・比較が1回ずつ。
- ESP32-C5 は浮動小数点演算器を持たない前提(f64 はソフトウェアで計算)で、f64 の掛け算1回を
  数十〜百数十サイクルと見積もると、減衰は1ステップ約 2.5〜5 万サイクル(240MHz で 0.1〜0.2 ミリ秒)。
  1フレーム 66 ミリ秒に対して小さい。**実機での計測はしていない**(bench-c5 で測れる)。
  整数・固定小数点への置き換えは今は不要と判断した。

## 9. 残っている課題

1. **実際のセンサの区画は幅のある円錐(約5.6°)**: 箱の縁にかかった区画は中間の距離を返したり、フレームごとに
   箱と壁の間を行き来したりする。食い違いの検出がそこで繰り返し働くと、縁がちらつく可能性がある。
   模擬のセンサは細い光線1本なので再現していない。実験5(静止)で縁のちらつきを見て τ を調整する。
2. **箱を運ぶ人**: 人の脚も動く物として映る。忘却が速いと、脚が一瞬映ってすぐ消える(正しい動作だが、
   録画では雑然と見える)。シミュレータでは扱っていない。
3. **覆い率が低い**: 静止した壁・家具の覆い率は移動前で 11〜13%(センサ8個 × 1行8区画)。箱は部屋の
   中央にあるので 93〜97% 見えるが、目印A・Bは2台以上のセンサから見える位置にする必要がある。
4. **影になった所は「分からない」に戻る**: 忘却を入れると、新しい位置の陰になった壁なども約2〜3秒で
   消える(古い値を残さない)。USD では、その部分の壁が消えて見える。
5. 移動先が古い位置を影にする配置は、個別には試していない(減衰と忘却で消える見込み)。
6. 採点の閾値(幻の表面 = 2h より遠い、出そろい = 最後の値の8割)は今回決めた定義。
7. 毎ステップの採点は単一ノード解で行った。分割解との一致は最後のステップで確かめている
   (決定論なので途中も同じはずだが、途中のステップは比べていない)。
8. 実機用の縮小版のアクター(G4)とファーム側の設定注入に、キー 14〜17 を入れる必要がある。

## 10. ユーザーに決めてほしいこと

1. **実験6で使う仕組み**: (a) 推奨の組み合わせ(食い違い 0.1 + 減衰 0.9 + 忘却 0.3。追従 0.67 秒、
   箱の内側の跡も約3秒で消える)、(b) 重みの上限を 10 に下げるだけ(追従 1.4 秒。最も単純だが、
   箱の内側に偽の表面が残り、雑音が大きいと跡が消えない)、(c) 食い違いの検出だけ(追従 0.67 秒、
   残りの跡は消えない)。推奨は (a)。理由は §3。
2. **見えなくなった所の扱い**: 減衰と忘却を入れると、見えなくなった所は数秒で「分からない」に戻り、

5. **目印A・Bとセンサの配置**: room6_move.txt のセンサ配置と目印は仮。実験4の手測りで置き換える。
6. scripts\check-sim2d.ps1 に、動く箱の場面と新しい設定のビット一致のシナリオを足すか(足すと確認の

## 11. 小さな実装判断(事後の明記)

- 場面ファイルの動く箱は「瞬間移動」と「測距の面から外す(off)」の2種類にした(途中の連続的な動きは扱わない)。
  動く箱は静止した遮蔽物の後ろに足すので、動く箱の無い場面の光線の計算は従来と同じ順序。
- 最後の採点(shape:)と --field-csv の正解は、最後のステップの形に対して出す(静止した場面では従来と同じ)。
- 減衰と忘却は「取り込み」と「統合」の間に置いた。忘却した点は d = 0、w = 0(未観測と同じ)。
- 食い違いは統合済みの d と比べ、重みを下げるだけ(上げない)。最初の観測(w = 0)では判定しない。
- 忘却の閾値 ≥ λ(λ < 1)の設定は初期化で拒む(§3.2)。
- 設定のキー 14〜17 は共通の dyne-wire(abi::sdf2d)に足した(定数の追加のみ)。
- 毎ステップの採点(--track-csv)は単一ノード解で行う(分割の実行の邪魔をしないため)。
- 出力先は demo_out/dynamic_shape/(.gitignore 済みの demo_out/ の下)。
