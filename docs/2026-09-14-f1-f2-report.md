## 1. 実装の要約

- `--unobserved-bc dirichlet[:値] | zero_grad | linear_extrap | transparent`
  (既定 zero_grad)。適用は不在隣接に接する面のみ。全域外縁 (x=0,1) は常に u=0。
  linear_extrap 選択時は端点凍結の警告 (理論ノートT8) を表示。
- `--absent n,n,...` (恒久不在ノード = 部分観測シナリオ、N10実験用。--add と排他)。
  部分観測では全域単一ノード解を基準に観測領域の誤差を報告する。
- `--join-init blank | warm` (既定 blank)。warm = 参加ノードが最初の界面交換
  メッセージ (両隣の値+勾配) から初期場を構成 (両隣あり=3次エルミート補間、
  片側=線形延長) してから参加。学習型は事前学習 (既定200反復) つき。
- transparent は指数和係数 M=32 (構成パラメータ固定、libm計算、総和順固定 =
  決定論)。補助変数は境界1つあたり float×M のノード内状態で、可搬状態 u[] には
  含めず、担当替え時はリセット (理論ノートT10・E3注記の規定どおり。
  設計書 §3 とコードコメントに明記)。
- 複合参照解は全キー・warm参加・補助変数リセットまで厳密に鏡写し →
  全キーで「PASS (bit-exact)」が成立する検証構造を維持。

### 実装中の重要な発見2件 (理論ノートへ反映済み)

1. **陽的結合の発散 (N10(ii) の予見どおり)**: transparent を素朴に陽的結合
   (前ステップの境界変化から流束を作る) にすると、1/√t 核の即時応答ゲイン
   ≈ (2/h)√(2αΔt/π) が既定シナリオ (r=0.41) で約1.02となり振動発散した
   (部分観測2000ステップで 5e255)。当ステップの境界変化のみ陰的に解く
   **半陰的結合** (漸化式は導出§5のまま、結合のみ変更。スカラー閉形式) で解消。
   r=0.49・8000ステップでも発散・増幅なし → **r ≤ 1/2 の条件はそのままでよい**。
2. **学習型の陽的流束目標も同じ硬さで乱れる**: u'(端)=±K の境界損失では
   学習型ADD (300ステップ) の複合参照解比 Linf が 1.5e0 に悪化。既存の界面条件
   iface=1 と同じ「差分法式で端点目標を作る」方式 (半陰的式で端点の値目標を構成)
   に揃えて 1.6e-3 に回復。

## 3. 検証 (i): 参加時の乱れ (N9実験、β型ADD)

シナリオ: `--nodes 4 --points 65 --steps 2000 --add 3@30000` (s06と同一、参加は
ステップ378)。参加界面 (iface 2) の残差と、参加前の既存界面 (iface 0,1) の定常残差:

| 境界条件 | 参加前の既存界面残差(中央値) | 参加ステップの残差 | 直後30step最大 | 全期間最大 | 回復時間(<2×自定常) |
|---|---|---|---|---|---|
| dirichlet(0) | 2.602e-1 | 2.8e-3 ※ | 1.06e-1 | 1.17e-1 | 641 steps |
| zero_grad | 1.187e-1 | 2.395e0 | 2.40e0 | 2.40e0 | 784 steps |
| transparent | 1.382e-1 | 2.222e0 | 2.22e0 | 2.22e0 | 779 steps |

解釈 (理論ノートN9を精緻化して反映済み):

- **「参加前からの解の歪み」は N9 の主張どおり確認**: dirichlet(0) の既存界面残差は
  zero_grad の 2.2倍、transparent の 1.9倍。u=0 の低温壁境界層が場を歪めている。
- **「参加時の乱れピーク」は白紙(sin)参加では境界条件でなく参加ノード側の未減衰
  初期場が支配する**。dirichlet(0) の見かけ上小さいピーク (2.8e-3) は、sin の端点
  勾配 (−2.22) と低温壁境界層の勾配が偶然ほぼ一致するアーチファクト (直後に
  1e-1 台へ増大していくことからも分かる)。zero_grad / transparent では existing 側が
  真の場に近いぶん、白紙 sin との勾配差 2.2〜2.4 がそのまま出る。
- 乱れピークの正しい削減手段は境界条件でなく **F2 ウォームスタート** (§5)。
  境界条件の優劣は「参加前の歪み」と「部分観測誤差」(§4) で判定するのが正しい。
- なお全キーで複合参照解とのビット一致 (PASS) は維持 (乱れの物理は同一規則の
  参照解が同じように辿るため、この実験の計測は界面残差で行った)。

## 4. 検証 (ii): 部分観測 (N10実験) と (iii) 安定性

シナリオ (実装側で設計): `--nodes 8 --points 65 --absent 0,1,6,7` — 全域 [0,1] の
うち中央 [0.266, 0.750] (32/65点、ノード2〜5) のみ観測。基準解 = 全域単一ノード解
(同一wasm)。観測領域の Linf を報告。α=1、Δt=1e-4、観測領域の左右にある
未観測区間の幅 ≈ 0.27 (ずつ)。

| ステップ数 (浸透深さ√(αt)) | dirichlet(0) | zero_grad | transparent |
|---|---|---|---|
| 100 (0.10) | 6.71e-1 | 2.35e-1 | **1.52e-1** |
| 200 (0.14) | 6.08e-1 | 3.15e-1 | **2.21e-1** |
| 400 (0.20) | 4.99e-1 | 4.27e-1 | **3.23e-1** |
| 800 (0.28) | **4.13e-1** | 5.84e-1 | 4.68e-1 |
| 2000 (0.45) | **1.39e-1** | 8.08e-1 | 6.77e-1 |

- **浸透深さ < 未観測区間の幅 の間 (〜400ステップ) は transparent が一貫して
  最良** — N10 の主張をこの適用域で確認。
- 800ステップ以降は仮定1 (半無限媒質) が破れ、たまたま真の遠方境界 (u=0 外縁)
  と一致する dirichlet(0) が逆転する。**優位性の成立条件は「浸透深さ < 未観測
  区間長」**であり、T10 の仮定の限界そのもの (理論ノートN10へ反映済み)。
- **(iii) 安定性**: transparent 部分観測 4000/8000ステップ (T=0.4/0.8 = 設計範囲
  T_ref の2〜4倍) で発散・増幅なし (Linf 7.51e-1 → 7.54e-1 の平坦域で有界)。
  r=0.490 (points 71) の8000ステップも発散なし。β型ADD+transparent の
  4000ステップは PASS (bit-exact)。通常条件 r ≤ 1/2 のままで安定 (半陰的結合。
  §1 発見1)。

## 5. F2: ウォームスタートの検証

同じ s06 シナリオで `--join-init warm` (参加ノードは左隣のみ → 線形延長):

| 構成 | 参加ステップの残差 | 直後30step最大 | 全期間最大 |
|---|---|---|---|
| blank + zero_grad | 2.395e0 | 2.40e0 | 2.40e0 |
| **warm** + zero_grad | **0 (厳密)** | **1.10e-1** | 4.70e-1 |
| blank + transparent | 2.222e0 | 2.22e0 | 2.22e0 |
| **warm** + transparent | **0 (厳密)** | **9.32e-2** | 4.07e-1 |
| warm + dirichlet(0) | 0 (厳密) | 2.81e-2 | 2.27e-1 |

- **参加ステップの界面残差は厳密に0** (線形延長が隣の勾配を厳密に引き継ぐため)、
  直後30ステップでも白紙比 **22分の1 (1〜2桁減)** → 判定基準「白紙参加より桁で
  小さい」を満たす。全期間最大でも5倍減 (残る山は線形初期場の曲率ゼロが真の
  曲率へ緩和する遅い過渡)。
- 学習型 (s12系、zero_grad): 複合参照解比 Linf が白紙 4.61e-3 → **warm 1.19e-3**。
- warm でも全キーで複合参照解との **PASS (bit-exact)** を維持 (両隣ありの
  3次エルミート構成も interior ADD で確認)。
- ダッシュボードでの目視: `scripts/dashboard.py` で blank / warm の2枚を生成し、
  参加時の段差が warm で消えることを確認できる (再現コマンドは §8)。
