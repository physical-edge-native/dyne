# F1 未観測領域境界の設定情報化 — 実装設計 (docs\2026-09-14-f1-boundary-design.md)

発注3 (2026-09-14 確定仕様) の F1 実装の設計記録。理論的背景は
docs\2026-09-13-transparent-boundary-derivation.md と理論ノート (数値計算) の
T7〜T10・N9・N10。F2 (ADDのウォームスタート) の実装設計も本書に含める。

## 1. 設定キーと適用範囲

境界条件はコードに焼き込まず、dyne-sim の実行時引数で指定する:

```
--unobserved-bc dirichlet[:値] | zero_grad | linear_extrap | transparent   (既定 zero_grad)
```

- **適用されるのは「不在の隣接ノードに接する面」のみ**。全域の外縁 (x=0, x=1) は
  問題設定そのものの境界であり、常に Dirichlet u=0 (F1 の対象外)。
- 不在は2種類: `--add node@t` の参加前 (一時的不在) と、新設の
  `--absent n,n,...` (恒久不在 = 部分観測シナリオ。--add と排他)。
- `dirichlet(0)` は現行挙動と**ビット同一** (回帰比較用に温存)。
- `linear_extrap` を選ぶと起動時に警告を出す (拡散系では端点が時間凍結する。
  理論ノートT8)。
- 学習型アクター自身の定義域外予測は候補に含めない (N7解決まで。2026-09-14仕様)。
- 既定の transparent への切替は行っていない (N9・N10 の実験結果を見てユーザーが
  判断。切替は設定変更のみでコード変更を伴わない)。

## 2. 境界条件コードとアクターABI

dyne-core::actor に定数を追加 (両アクター共通):

| コード | 名前 | 差分法アクターの離散化 | 学習型アクターの損失 |
|---|---|---|---|
| 0 | BC_DIRICHLET | u_end = 境界値 (既定0) | u(端) = 境界値 |
| 1 | BC_INTERFACE | ゴースト点交換 (従来) | 従来どおり |
| 2 | BC_ZERO_GRAD | 鏡映ゴースト u₋₁=u₁ | u'(端) = 0 |
| 3 | BC_LINEAR_EXTRAP | ゴースト u₋₁=2u₀−u₁ (端点凍結: T8) | u''(端) = 0 |
| 4 | BC_TRANSPARENT | 半陰的結合 (下記 §3) | u'(端) = ±K (流束目標) |

追加エクスポート (両アクター。ホストは dyne_init の**前**に呼ぶ):

- `dyne_set_bc_value(face, value)` … Dirichlet の値 (既定 0.0)。init をまたいで保持。
- `dyne_transparent_coef(j, decay, half, weight)` … 透過境界の指数和係数を1項ずつ
  注入。init をまたいで保持 (補助変数のみ init でリセット)。

## 3. transparent の実装 (導出 §4〜§6 の実装形)

### 係数の構成 (dyne-core::transparent、ホスト側で一度だけ計算)

- 対数軸台形則: x_j = x_lo + j·h_soe (x_j < x_hi)、λ_j = e^{2x_j}、
  w_j = (2/√π)·h_soe·e^{x_j}。
- **構成パラメータは固定** (決定論): h_soe=0.6、c1=1e9、c2=2e4、T_ref=0.2。
  x_lo = ½ln(1/(c1·T_ref))、x_hi = ½ln(c2/Δt)。既定 Δt=1e-4 で **M=32**
  (導出 §6 の表の h=0.6 の行。核の相対誤差 7.7e-4)。上限 M≤64 (静的確保)。
- アクターへ渡す係数: decay_j = e^{−λ_jΔt}、half_j = e^{−λ_jΔt/2}、
  weight_j = w_j/√(πα) (勾配換算の 1/√(πα) を畳み込み済み)。
- 数学関数は **libm (純Rust)** で計算し、OS間でもビット一致を保つ
  (std の exp/log はプラットフォームの libm 依存のため使わない)。
- **総和順の固定**: Σ w_j y_j は j 昇順の逐次加算。アクター・複合参照解とも同一。
- T_ref=0.2 より長い実行: λ_min = 1/(c1·T_ref) が極小のため打ち切り誤差は
  t=4·T_ref でも相対 1e-4 未満 (長時間実行 (iii) で発散なしを実測確認)。

### 差分法アクターの結合は半陰的 (2026-09-14 実装判断)

素朴な陽的結合 (前ステップの境界変化 Δg から流束を作り、2次精度ゴースト
u₋₁ = u₁ − 2hK で閉じる) は、1/√t 核の t→0 での大きさゆえに、境界の自己応答
ゲインが (2/h)√(2αΔt/π) となり **r=0.41 (既定シナリオ) で約1.02 > 1 → 振動発散**
することを実測した (部分観測2000ステップで 5e255 まで成長)。これは理論ノート
N10(ii) が予見した「記憶項による増幅」の実体である。

対処: 当ステップの境界変化 Δ 自身への応答だけを陰的に解く**半陰的結合**:

```
Δ·(1 + 2rh·S0) = r·(内側ステンシル: u_in − 2u_end + u_in) − 2rh·K_hist
K_hist = Σ_j w_j·(decay_j·y_j)   … 過去の変化の寄与 (1ステップ減衰済み)
S0     = Σ_j w_j·half_j          … 当ステップの変化への即時応答
y_j ← decay_j·y_j + half_j·Δ    … 漸化式そのもの (導出 §5 と同一)
u_end^{n+1} = u_end^n + Δ
```

補助変数の漸化式 (導出 §5) は不変で、**結合のみ**半陰的。スカラー1変数の線形
方程式なので閉形式で解け、毎ステップ O(M) のまま。分母 1+2rh·S0 (≈2) が硬い
即時応答を減衰させ、r=0.49・8000ステップでも発散・増幅なしを実測確認。
K=0 の極限は zero_grad の鏡映に (分母の減衰を除き) 一致する。

学習型アクターも当初は流束目標 u'(端)=±K の境界損失 (T10 §7 の字義どおりの形)
で実装したが、陽的な流束目標は同じ硬さで端点が乱れることを実測した
(学習型ADD 300ステップで複合参照解との Linf が 6e-3 → 1.5e0 に悪化)。そこで
既存の界面条件 iface=1 と同じ「**差分法式で端点目標を作る**」方式に揃えた:
上記の半陰的更新式を u_prev に適用して端点の値目標 u_prev[端]+Δ を作り、
u(端)=目標 を境界損失に課す (改修後 Linf 1.6e-3 に回復)。差分法と学習型で
式は同一・課し方 (直接更新 vs 損失) のみ異なる。
**追補 (2026-09-15 理論確認、条件付き承認)**: 値目標化は半陰的流束条件と同一の
線形式の読み替えで、等価性は3条件下で成立 (理論ノートT10実装注記)。実装確認で
条件(i)「補助変数の履歴更新は目標値でなく実際の出力端点値で行う」の違反を検出し
修正した——y の更新を目標導出時 (Δ_目標) から最適化後 (Δ_実出力 = 最適化後の
NN端点値 − 前ステップ端点値) へ移動。修正で学習型 transparent の基準シナリオは
Linf 1.562e-3 → 6.429e-4。M=64 でも下がらない (7.4e-4) ため指数和近似の床律速
ではなく、残余は学習側の最適化残差 (発注3追補レポート参照)。

### 補助変数のリセット規定 (理論ノートT10・モデルアーキテクチャノートE3注記)

- 補助変数 y_j (境界1つあたり float×M) は**ノード内状態**であり、可搬状態 u[]
  (E3) には含めない。**E3 の初の例外**。
- 担当替え (handover / ADD に伴う再init) では**リセット** = その時点で透過境界が
  発動し直す扱い (発動時仮定「外側温度が境界近傍と同程度」が再適用されるだけで、
  物理的に解釈可能な劣化)。
- 具体的なリセット発生点 (すべて複合参照解に鏡写し):
  1. dyne_init (初期配置・ADD参加・差分法の bc 切替再init・handover 復帰)。
  2. ADD で隣接ノードが再init されるとき、**反対側の面の補助変数も道連れで
     リセットされる** (差分法は再init+状態復元で bc を切り替えるため)。再発動と
     して解釈可能。学習型は dyne_set_bc の面内切替なので反対側の面は保持される
     (切り替えた面のみリセット)。
  3. handover 復帰 (新インスタンス)。ホストが (node, 有効ステップ) を記録して
     複合参照解へ渡す。

## 4. 複合参照解の鏡写し

複合参照解 (ビット一致検証の基準) はアクターの全境界条件の式・演算順・総和順を
厳密に鏡写しする。透過境界の補助変数 (ノード×面ごと) とそのリセット (§3) も
再現する。これにより **--unobserved-bc の全キーで「PASS (bit-exact)」が成立**
(検証で全キー確認済み)。

## 5. F2: ADD のウォームスタート

```
--join-init blank | warm    (既定 blank = 従来の白紙sin参加)
```

- warm のとき、参加ノードは**最初のステップの界面交換メッセージ** (= 両隣の
  ステップ S−1 完了時の境界の値+勾配。プロトコルが既に運んでいる情報) から
  自領域の初期場を構成してから計算に入る:
  - 両隣あり → **3次エルミート補間** (両端の値と勾配の4条件を厳密に満たす。
    「線形延長でよい」の仕様に対し、両側の線形延長の自然な接続として採用)。
  - 片側のみ → その側からの線形延長 (1回きりの初期化なので T8 の端点凍結は
    生じない: 2026-09-14 仕様の明確化どおり)。
  - グローバル外縁の Dirichlet 端は 0 に丸め落とす (init と同じ規則)。
- 送信順の入れ替え: 参加ノードは初期場の構成が済むまで自分の境界値を送らない
  (白紙の値を隣に使わせない)。受信→構成→送信→計算の順。BSP はこの遅延を
  そのまま許容する (再送・replay の治癒機構も従来どおり働く)。
- 学習型アクターは構成した場を dyne_set で標本として書き込み、参加前の温め
  (既定 **200反復**、--add-warm で上書き可) で場に適合させてから参加する。
  教師点は現行ABIどおり格子点標本 (ノードあたり9〜17点)。
  **設計判断 (2026-09-15 検収回答②)**: 高密度教師のためのABI拡張は行わない。
  仕様の「2,000点」はロードマップの見積もり値であり要件ではなく、格子点教師+
  200エポックで結果 (誤差 4.6e-3→1.2e-3、参加ステップ残差0) が出ているため。
  2次元化 (帯ペイロード) の際に教師密度が実際に不足したら再訪する。
- 複合参照解は編入時に同じ構成 (同じ関数 warm_field) を同じ入力で行う →
  warm でもビット一致が成立 (検証済み)。
- 旧 --add-warm 単独 (blank のまま温め回数だけ変える従来動作) は不変。
