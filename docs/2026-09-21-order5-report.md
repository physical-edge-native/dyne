## 1. 方法

- **基準シナリオ**: 既存の学習型検証と同一——65点・α=1・h=1/64固定・解析解
  (sin(πx)·e^{−π²αt})比較。Δt は r=α·Δt/h² に換算して報告(Δt=r·h²で掃引)。
  300ステップで判定し、境界セルは1000ステップで追確認(§4末尾)。
- **ホスト側の変更(最小)**: シミュレータの r≤1/2 assert は**差分法の条件**の
  焼き込みだったため、学習型アクターに限り警告に降格して掃引を許可
  (差分法では従来どおり拒否=回帰不変。判定はホストの Linf・非有限検出で行う)。
- **判定**(発注8の安定地図と同じ流儀+精度層の区別):
  非有限(RESULT: FAIL)または Linf≥10 → **不安定** / 0.1≤Linf<10 →
  **精度劣化**(発散はしない) / Linf<0.1 → **安定**。
- **掃引格子**(実装側の設計、計58構成):
  Map A(主地図)= r{0.25, 0.41, 0.50, 0.60, 0.80, 1.00, 1.50, 2.00} ×
  N{1, 4, 8, 16}(幅16・反復5・sub=1)。
  Map B(最適化資源)= 幅{8,16,24} × 反復{2,5,10}(N=4・sub=1、r{0.41, 1.00})。
  Map C(残差評価点)= sub=2 × r8値(N=16・幅16・反復5)。その他は既定
  (LM法・λ_b=1・シード既定42)。

## 4. 境界の特徴(報告項目(2))

1. **単体(N=1)は差分法よりはるかに広い**: r=2.0まで全構成安定(誤差もmilli級)。
   時刻離散化PINNの残差 (u−u_prev)−αΔt·u'' は u'' を新時刻の場で評価する
   **後退オイラー型**であり、陰解法の無条件安定性が単体では効いている。
2. **不安定は界面結合が持ち込み、rの大きい側から現れる**。界面条件 iface=1 は
   「隣の**前ステップ**端点値から差分法の陽解法式で端点目標を作る」ため、
   時間方向の陽性が界面にだけ残る。発散境界は N=4: 1.0<r*≤1.5、
   N=8: 0.8<r*≤1.0、N=16: 0.6<r*≤0.8 と**Nとともに差分法の r=1/2 へ単調に
   漸近**する(Nが大きいほど界面数が増え、かつノードあたり点数が減って陽的な
   端点が支配的になる。極限は陽解法そのもの)。
3. **幅(表現力)は不安定側に働く**: r=1.0・N=4 で幅8=劣化どまり(有界)、
   幅24=全反復で発散。小さいNNは界面から入る高周波擾乱を表現できないこと
   自体が暗黙のフィルタ(散逸)になる。**安定余裕の観点でモデルを太らせるのは
   タダではない**(A7=極小モデル+数の力と整合)。
4. **反復数は二次的・非単調**: 反復2は安定域内でも精度が2桁落ちる(〜2e-2)が
   安定は保つ。境界近傍では反復を増やしても救えない(2=発散、5/10=劣化)。
   安定性の主決定因は r×N(と幅)。
5. **subは精度を上げるが境界を動かさない**。ただし **r=0.25・sub=2 の劣化5.3**
   という低r側の例外セルがあり、低rでは物理項の重み(αΔt)が小さく細分点
   データ項とのバランスが崩れる、既知のsub=4病理(M-S1b)の同族と疑われる。
   この低r×高容量域は full432 補完測定(§8)で地図化する。
6. **差分法の r≤1/2 との関係(発注の問いへの答え)**: 全構成で r=0.5 は安定側
   =**学習型の安定域は差分法より広い**。ただし余裕は界面の陽性がNとともに
   食い潰し、大分割では r=1/2+ε 程度に漸近する。混在チェーンではFDMの
   r≤1/2 が律速であり、学習型が安定性の律速になることはない。
7. **境界セルの1000ステップ追確認**(scratchpad/n7/boundary1000.csv、
   2026-09-21生成): 300→1000ステップの Linf 推移は
   (r=0.80, N=8) 1.7e-1→**2.8e-1**、(r=1.00, N=4) 2.9e-1→**6.4e-1**、
   (r=0.60, N=16) 3.5e-2→5.4e-2、(r=0.25, N=16, sub=2) 5.3→**8.4**。
   すなわち「劣化」セルは有界に留まらず**単調に成長しており、遅い増幅
   (緩やかな不安定)と読むのが安全**。運用上は劣化帯も避け、安定側の実用上限を
   N≤8 で r≤0.6、N=16 で r≤0.5 とする(S3推奨= r≤1/2 運用には影響なし)。
   sub=2 低r病理も同様に成長型で、full432 補完測定(§8)で分布を確認する。
