## 追記提案1: T7 境界条件の分類と放物型での適定性(教科書的事実)

- **Dirichlet(値固定)**: 境界の温度そのものを与える。放物型では最大値原理が働き、
  存在・一意性・安定性のすべてが最も素直に成立。陽解法の安定条件 r ≤ 1/2 は不変。
- **Neumann(勾配固定)**: 境界の熱流束を与える。ゼロ勾配は断熱端(熱の出入りなし)。
  適定。ゴースト点を鏡映(u_{-1}=u_1)で置けば2次精度を保ち、r ≤ 1/2 も不変。
- **Robin(値と勾配の線形結合)**: ∂u/∂n + β(u − u_ext) = 0。ニュートン冷却則に対応し、
  Dirichlet(β→∞)とNeumann(β=0)を連続的に補間。β ≥ 0(放熱側)なら適定・安定。
  β < 0(流入増幅)は指数成長を許すため注意。
- **周期境界**: 両端を同一視する。適定。フーリエ解析がそのまま使え、安定条件も不変。
- **放射・吸収境界(無反射)**: 波が反射せず出ていく条件。本来は双曲型(波動)の概念
  (Sommerfeld条件)。放物型での対応物は「透過境界(人工境界)」で、厳密形は
  **時間について非局所**(半微分・畳み込みを含む)になることが知られる。
  局所的な境界条件で書ける候補(下記(a)(b)含む)はすべてその近似とみなせる。
- **流出境界(外挿)**: 境界近傍の内部値から外側を外挿して閉じる。PDEの適定性理論から
  導かれる条件ではなく**数値的な閉じ方**であり、安定性はスキームと外挿次数の組ごとに
  個別検証が必要。移流優勢の流れでは標準的だが、純拡散では「流出方向」が存在せず、
  理論的裏付けは弱い。

## 追記提案2: T8 線形外挿ゴーストは端点を時間凍結する(本設定での厳密な恒等式)

ゴースト点を線形外挿 u_{-1} = 2u_0 − u_1(端の値と片側勾配による1次延長)で置くと、
陽解法の更新式では端点の離散ラプラシアンが u_{-1} − 2u_0 + u_1 = 0 と**恒等的に消え**、
u_0^{n+1} = u_0^n。すなわち候補(b)は「発動時点の端点値を固定するDirichlet条件」に
厳密に帰着する(3行で証明可能な離散恒等式。安定だが、真の解が減衰する本問題では
端点だけ減衰せず、時間とともにモデル化誤差が単調に増える)。

## 本プロジェクトの界面条件の位置づけ(補足、T1の注記として)

隣接ノード間の交換は「隣の端点値をゴースト点に代入して全域と同一のステンシルを再現する」
もの。これは境界条件というより**内点の計算の分担**であり、だからこそT1の等価性
(ビット一致)が成立する。分類上あえて言えば毎ステップのDirichletデータ交換で、
C1(流束連続)は同一ステンシルの帰結として自動成立。交換している片側勾配は更新には
使われず、界面残差(flux jumpの離散版)の監視、すなわちTrig系の診断に使われている。

## 未観測領域との境界: 候補(a)(b)(c)の比較(F1判断材料)

| 候補 | 分類 | 安定性 | 物理的妥当性 | ADD時の段差の見込み |
|---|---|---|---|---|
| (a) ゼロ勾配 | Neumann(断熱端) | 古典的に保証(r ≤ 1/2 のまま) | 「未観測領域と熱の出入りなし」と解釈可能。誤差は実際の境界流束に比例し予測可能 | 端点値が場に追随して動くため、値のO(1)不一致が消える |
| (b) 線形外挿 | 形式は流出境界だが、T8により**凍結Dirichlet**に厳密に帰着 | 安定(端点は定数) | 発動直後は最良の延長だが、以後は場が減衰しても端点が動かず乖離が単調増大 | 発動時点では最小。時間経過とともに実質的に現行u=0と同種の問題(値の押し付け)が再発 |
| (c) 学習型の定義域外予測 | 古典分類に対応物なし(滑らかな延長の暗黙の押し付け) | 未証明。自分の外挿を自分の入力に戻すフィードバックを含み、N7の安定領域の議論に従属 | tanh基底の外挿は有界だがPDEの制約を受けず、制御不能 | 不明(実測要) |

**推奨**: 既定は**(a) ゼロ勾配**。理由: (i)古典理論の保証がそのまま使える唯一の候補、
(ii)端点値が時間発展し続けるため、(b)の凍結問題・現行u=0の押し付け問題の両方を回避、
(iii)誤差の大きさが「未観測領域との実流束」という物理量で見積もれ、実験で検証しやすい。
(b)は参加直後の初期化(新ノードの初期値生成)には有用だが、常時境界としては不適。
(c)はN7(学習型の安定領域)が解決するまで保留を推奨。将来の精度改良は、外挿次数を
上げる方向ではなく、減衰率に合わせたRobin条件(β調整)や透過境界の局所近似の方向が筋。
最終決定はユーザー。

## 現行 u=0(Dirichlet)が段差の主因になる理由

u=0 は未観測領域の真値と一般にO(1)で食い違う**値の押し付け**であり、既存ノードの端点
近傍に人工的な低温壁への境界層(急勾配)を作る。新ノード参加時、参加領域の初期値は
真の場の延長に近い側に置かれるため、既存側の「0に引かれた端点+急勾配」と値・流束の
両方で衝突し、これが界面残差66倍スパイクの初期不連続を与える。さらに低温壁は参加前の
期間ずっと熱を吸い続け、既存ノードの解そのものを境界近傍で歪めている(段差の片側を
恒常的に用意している)。対して外挿系(a)(b)は値を押し付けず「形の制約」だけを課すため、
参加時の不一致は O(1) の値ギャップから、勾配・曲率の推定誤差程度(格子幅と流束誤差の
オーダー)へ落ちる。これが段差縮小の理論的な根拠である。

## 追記提案3: T9 未観測領域境界のタスク別の目安(T6の境界版)

界面条件がPDEの型に依存する(T6)のと同様、未観測領域との境界条件も
「未観測領域の物理応答を何で代理するか」であり、適切な選択はPDEの型で決まる。

| タスク(センシング対象/PDE型) | 既定の推奨 | 理由と注意 |
|---|---|---|
| 熱・拡散(放物型) | (a) ゼロ勾配Neumann | 境界の嘘が指数減衰して染み込むため局所近似で実用十分。安定条件 r ≤ 1/2 不変。境界の熱交換率が既知ならRobin(β≥0)へ精緻化 |
| 振動・波動(双曲型) | 吸収境界(1次元はSommerfeld条件 ∂u/∂t + c∂u/∂x = 0 で局所かつ厳密) | ゼロ勾配は自由端、Dirichletは固定端で、いずれも**全反射**。減衰しない偽エコーが観測領域へ戻るため、熱の既定(a)の流用は不可 |
| 移流輸送(方向のある流れ) | 流入側=値指定(観測またはモデル)、流出側=外挿 | 方向非対称が本質。**T8の凍結は「線形外挿×拡散ステンシル」に固有**で、風上差分の移流更新では起きない——移流の流出側では外挿が標準かつ正当 |
| 移流拡散(混合) | ペクレ数で上2行を使い分け | 拡散優勢→熱の行、移流優勢→移流の行に従う |
| 定常場の推定(楕円型) | Neumann主体+どこか1点に値の錨 | 全Neumannは解が定数分不定(適合条件)。少なくとも1箇所のDirichlet的基準が必要 |
| 保存量のトラッキング(濃度等) | ゼロ流束Neumann | 総量保存と厳密に整合。未観測領域が吸い込みならRobinへ |

## 運用上の帰結(F1実装への要件、理論ノート外)

- 境界条件はコードに焼き込まず**設定情報**とし、デプロイ(タスク種別)ごとに指定可能に
  する。候補キー例: dirichlet(値つき)/ zero_grad / robin(βつき)/ absorbing(cつき)/
  outflow_extrap。現行の u=0 は dirichlet(0) として残し、回帰比較に用いる。
- 熱伝導タスクの既定は zero_grad(本提案の推奨、ユーザー決定 2026-09-07)。
- linear_extrap を拡散系タスクで選択した場合はT8(端点凍結)の警告を出すこと。
  移流系タスクでは正当な選択肢であり警告不要。
- (c) 学習型の定義域外予測は、N7(学習型の安定領域)解決までは設定候補に含めない。
