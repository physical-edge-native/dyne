## 確立している理論(根拠つき)

- **T1 分割の等価性(差分法アクターに限定)**: 重複なしの領域分割で、界面に
  おいて値の連続(C0)と流束/勾配の連続(C1)を課せば、分割問題は元の全域問題と
  等価(領域分解法・部分構造法の古典理論)。差分法での「単一解との全桁一致」は
  この等価性の離散版が厳密に成立している証拠。**学習型アクターへの適用はN1**
  (2026-09-01 適用範囲を明記)。
- **T2 陽解法の安定条件**: α·Δt/h² ≤ 1/2(フォン・ノイマン解析)。違反時の
  発散はM-S0で実測済み。マニフェスト検証に組み込む方針(仕様A-3)。
- **T3 ビット一致の成立条件**: (i)同一の演算列・順序、(ii)BSPによる「どの
  ステップの値を使うか」の論理固定、(iii)IEEE754準拠、の3条件下で環境に
  依らず全桁一致する。PC/シミュレータ/実機(M1)/無線越し(M2)で検証済み。
- **T4 時刻離散化PINN(Rothe法)の整合性**: 時間を先に離散化し各時刻の空間
  問題をNNで解く方式は古典的に正当。BSPステップ同期と両立する(M-S1b実装)。
- **T5 粗い補正なしの分割数劣化(一般理論としてのみ保持、本設定への適用は
  N8へ降格、2026-09-01)**: 反復型の領域分解法では、全域を見る粗い空間の補正が
  なければ収束がNとともに劣化する(標準理論)。当初は16ノードの精度100倍悪化を
  この理論の確認とみなしたが、**その劣化は残差評価点の追加(sub=2)だけで解消し、
  粗い補正は不要だった**(2026-08-26)。よって本設定で粗い空間の代償が出るか否かは
  未解決 → N8。
- **T6 界面条件はPDEの型に依存**: 放物型はC0/C1でよいが、双曲型保存則の
  衝撃波上ではRankine-Hugoniot条件が必要(ADD-PINNリサーチ記録)。現対象
  (熱伝導=放物型)では現行フォーマットで正しい。

- **T7 境界条件の分類と放物型での適定性**(2026-09-07追加、教科書的事実):
  Dirichlet(値固定)・Neumann(勾配固定。ゼロ勾配=断熱)・Robin(値と勾配の
  線形結合、放熱側β≥0)・周期境界は、熱伝導(放物型)で適定かつ陽解法の
  安定条件 r ≤ 1/2 を変えない。放射・吸収境界(無反射)は双曲型由来の概念で、
  放物型の厳密な透過境界は時間非局所(局所的な条件はすべてその近似)。
  流出境界(外挿)は適定性理論から導かれる条件ではなく数値的な閉じ方であり、
  安定性はスキームと外挿次数の組ごとに個別検証を要する。
  詳細: docs/2026-09-06-boundary-conditions-proposal.md。
- **T8 線形外挿ゴーストは端点を時間凍結する**(2026-09-07追加、離散恒等式):
  ゴースト点を線形外挿 u_{-1} = 2u_0 − u_1 で置くと、端点の離散ラプラシアンが
  恒等的に0になり u_0^{n+1} = u_0^n。すなわち線形外挿境界は「発動時点の端点値を
  固定するDirichlet」に厳密に帰着し、場が減衰しても端点だけ取り残されて
  モデル化誤差が単調増大する。この凍結は「線形外挿×拡散ステンシル」に固有で、
  移流の風上差分では起きない(移流の流出側では外挿が標準かつ正当)。
- **T9 未観測領域境界のタスク別の目安**(2026-09-07追加、T6の境界版。教科書的
  知識に基づく設計指針であり、各タスクの実装時に見直しうる): 未観測領域との
  境界は「未観測領域の物理応答を何で代理するか」であり、適切な選択はPDEの型で
  決まる——熱・拡散(放物型)=ゼロ勾配Neumann(境界の嘘が指数減衰して染み込む
  ため局所近似で実用十分)、波動(双曲型)=吸収境界(ゼロ勾配・Dirichletは
  全反射し偽エコーが戻る)、移流=流入側は値指定・流出側は外挿(T8の凍結は
  起きない)、定常場(楕円型)=Neumann主体+1点の値の錨(全Neumannは定数分
  不定)、保存量トラッキング=ゼロ流束Neumann。
  **運用決定(2026-09-07、ユーザー)**: 境界条件はコードに焼き込まず設定情報とし、
  デプロイ(タスク種別)ごとに指定可能にする。熱伝導タスクの既定=ゼロ勾配。
  現行u=0はdirichlet(0)として残し回帰比較に用いる。学習型アクターの定義域外
  予測はN7解決まで候補に含めない。
  **改定(2026-09-13、ユーザー)**: 精緻化の格上げ第一候補は transparent
  (半無限透過境界、T10)とし、設定キー候補に追加する。β=1/L型Robinは未観測
  区間長Lの集約(割当情報)を別途要するため、「その仕組みが他の理由で導入
  された場合のみ再検討」へ降格。
  **改定(2026-09-14、ユーザー、案1採用)**: 発注3のF1で transparent を含む
  4キー(dirichlet / zero_grad / linear_extrap / transparent)を実装する。
  既定は**当面 zero_grad のまま**とし、transparentへの既定切替は N9・N10 の
  実験結果を見てユーザーが判断する(切替は設定変更のみでコード変更を伴わない)。
- **T10 半無限透過境界(候補d)の厳密形と軽量実装**(2026-09-13追加):
  未観測領域を「境界の先に観測領域と同じ材質が無限に続く」と想定すると、
  境界流束は**自ノードの境界温度の履歴のみ**から決まる厳密な透過境界条件
  (Dirichlet-to-Neumann写像。1/√t核の畳み込み=時間の1/2階微分)になり、
  隣の観測・割当表・未観測区間長は不要(ノード局所で閉じ、中央主体を置かない
  設計原則と整合)。u=0と断熱端はこの条件の両極端(t→0でDirichlet側、
  t→∞で断熱端側へ漸近)。1/√t核は指数和で近似でき、忘却率の異なる補助変数
  (漏れバケツ)M個の漸化式により毎ステップO(M)の積和・メモリfloat×M個で
  実装可能。実用精度(0.1〜1%)でM≈20〜30、直接畳み込みとの相対差1e-5未満を
  数値検証済み。残る仮定は材質の連続と「発動時点で外側温度が境界近傍と同程度」。
  補助変数はノード内状態であり、可搬状態u[](モデルアーキテクチャノートE3)には
  含めない。担当替え(handover/ADD)時は**リセット**=透過境界の再発動として
  扱う(上記の発動時仮定が再適用されるだけで、物理的に解釈可能な劣化。
  E3の初の例外として管理、2026-09-14決定)。
  導出と検証: docs/2026-09-13-transparent-boundary-derivation.md
  (Carslaw & Jaeger、人工境界条件法)。
  **実装注記(2026-09-14、発注3 F1)**: 陽解法との素朴な陽的結合(前ステップの
  境界変化から流束を作る)は 1/√t 核の即時応答の大きさゆえ r≈0.4 で振動発散する
  ことが実測され(N10(ii)の予見どおり)、当ステップの境界変化のみ陰的に解く
  **半陰的結合**で解消した(漸化式は不変。r=0.49・8000ステップで発散なし)。
  学習型は同じ半陰的式で端点の値目標を作る(iface=1と同方式)。
  **値目標化の理論確認(2026-09-14、条件付き承認)**: 半陰的な流束条件と
  値目標化は同一の線形式の読み替えであり差は厳密にゼロ。半陰的と陽的の差は
  O(√Δt)で消える負帰還(散逸的)摂動であり、r ≤ 1/2 を締め付けない(実測と
  整合)。DtN写像の意味論は保存される。ただし等価性は3条件下でのみ成立:
  (i)補助変数の履歴更新は目標値でなく実際の出力端点値で行う、(ii)目標導出の
  係数と漸化式の係数が同一、(iii)目標導出の離散流束演算子がアクターの
  ステンシルと同一(iface=1がT1を借りたのと同条件)。
  追補の結果(2026-09-14): 等価3条件のうち(i)に違反(履歴更新を目標側Δで実施)
  があり修正、誤差は1.6e-3→6.4e-4(違反が約6割を占めた)。誤差床の切り分けは
  M=64で不変につき床律速を否定(既定M=32維持)。階段応答ベンチマークで、
  漸化式は区分一定入力に時間離散化誤差を持たず(半群性)、陽的と半陰的の
  軌道差は実測O(Δt)で縮む(理論上界O(√Δt)より速い。理論側で精緻化検討中)。
  詳細: docs/2026-09-14-f1-supplement-report.md。
  実装設計: docs/2026-09-14-f1-boundary-design.md §3。
