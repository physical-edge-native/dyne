# 片付けた6畳の部屋で、段ボール箱を持ち上げて運ぶ (2026-11-11、形の変化への追従の検証。room6_move.txt の変種)。
# 実験6 (docs/2026-11-11-two-week-plan.md) の条件に寄せる: 測距付きのノード8台 (1台に1個)、
# 床近くから部屋の中を向く。センサの位置と向きは仮のもの (実験4の手測りで置き換える)。
# ステップ = 測距フレームの番号 (VL53L5CX の 8x8・15Hz なら 1ステップ = 1/15 秒)。
# 箱は 300 ステップ (20秒) で持ち上げ (測距の面から消える)、2秒 (30ステップ) 運んで目印B に置く
room 0 0 3.6 2.7
box 0.0 0.0 1.1 0.55 0.72      # 机
box 2.6 0.0 3.6 1.95 0.45      # ベッド
box 0.0 2.35 0.9 2.7 1.8       # 本棚
movebox cardboard 0.9 1.0 1.3 1.3 0.3   # 段ボール箱 (40x30cm、高さ30cm)、目印A
move cardboard 300 off                  # 持ち上げる
move cardboard 330 1.7 1.5 2.1 1.8      # 目印B に置く
sensor 0 0.05 1.0 0 0.1        # 西の壁の前から東を見る
sensor 1 0.05 2.0 -15 0.1      # 西の壁の前 (本棚の手前) から東南東
sensor 2 1.3 0.05 75 0.1       # 南の壁の前 (机とベッドの間) から北
sensor 3 2.45 0.05 120 0.1     # 南の壁の前 (ベッドの脇) から北西
sensor 4 2.55 1.0 180 0.1      # ベッドの脇から西
sensor 5 3.5 2.6 205 0.1       # 北東の角 (ベッドの足元) から南西
sensor 6 1.6 2.65 -95 0.1      # 北の壁の前から南
sensor 7 1.0 2.65 -60 0.1      # 北の壁の前 (本棚の脇) から南東
