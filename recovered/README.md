# recovered/ — 会話記録から復元した実測データ

## 経緯

安定領域の掃引・補完測定などの実測CSV(セッション一時領域 scratchpad/ に出力)は、
OSの一時領域の清掃により**消失**した(2026-10-04に発覚)。幸い、実験実行時の
画面出力が Claude Code の会話記録(セッションの jsonl)に残っていたため、
そこからスクリプトで機械抽出して復元したのが本ディレクトリである(手転記ではない)。
再発防止のため .gitignore の `*.csv` の例外としてgitで追跡する。

## 各ファイルと完全性

| ファイル | 内容 | 完全性 |
|---|---|---|
| map58.csv | 主な掃引58構成(2026-09-20、発注5)。列: map(A/B/C), r, nodes, width, iters, sub, linf, verdict | **58/58 全セル**(発散セルの誤差実測値も含む) |
| full432_partial.csv | 補完測定432構成(2026-09-21)の部分復元。source列=出所(nonstable_list/slice/overlap) | 非安定46件は**全件**+断面12+重複確認24。**判定は補集合により432セル全て確定**。安定386セルの誤差値のみ欠測 |
| a4_width.csv | 幅32/64の発散境界(2026-09-22)。※幅64は実装上限32にクランプされ幅32と同値 | 18/18 全行 |
| a2_seeds.csv | NN初期値の乱数依存(2026-09-22)。kind=global(--seed、NN初期化に無効)/pinn(--pinn seed=) | 全行 |
| a3_nudge.csv | ナッジングの判別実験2セル(2026-09-22) | 2/2 全行 |

## 照合

発表資料用に手転記されていた transcribed/ の値と突き合わせ、実質的な食い違いは
「6e26(報告書の丸め)vs 6.257e26(実測)」の1件のみ(2026-10-04照合)。
boundary1000.csv(1000ステップ追確認)の生データは復元不能
(docs/2026-09-21-order5-report.md §4-7 の4セル×2値のみ現存)。
シミュレータは決定論のため、必要なら同一設定の再実行で完全なデータを再生成できる。

利用例: figs/ の図はここから生成している(figs/README.md)。
